# 路线图

本路线图记录项目机制和公开内容体系的改进计划，不代表对具体交付日期或维护承诺。已发布条目的状态是可验证的内容状态，不表示维护者认定绝对真理。

最后更新：2026-11-25

## 已实现

- [x] 建立项目理念和内容边界说明
- [x] 建立投稿、审核和讨论规则
- [x] 建立实验或代码投稿模板
- [x] 建立安全、隐私和行为准则说明
- [x] 建立想法与实验的目录说明
- [x] 建立双许可框架（代码与非代码内容）

## 进行中

- [ ] 发布第一批经审核的想法条目
- [ ] 发布第一批可复现的实验说明或示例
- [ ] 建立并核对状态标签
- [ ] 建立私密安全报告渠道或明确的平台报告流程

## 计划中

- [ ] 建立按主题浏览已发布内容的索引
- [ ] 为每篇发布条目提供变更历史与纠错入口
- [ ] 增加普通想法、批评和反例投稿模板
- [ ] 建立最低内容质量清单并用于审核
- [ ] 建立定期复核机制，及时修正过时或无法复现的结论

## 暂不计划

- [ ] 建立绝对真理或官方认证机制
- [ ] 未经验证就公开自动合并投稿
- [ ] 建立隐藏或不可解释的审核流程

每项计划会根据证据、风险、维护能力和社区反馈调整。
