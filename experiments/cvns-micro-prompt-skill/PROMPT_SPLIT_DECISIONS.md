# 提示词拆分决策 V1.6.0

## 不可拆的自然任务
- P06：全局 ExpressionTaskBook 矩阵。
- BASE：一个实体×维度的完整纵向轨迹。
- P09：一对实体的全部已签约变量线扫描。
- P11A：一个冲突的完整解释候选集；P11B：同一候选集的整体比较，不按候选逐个调用。
- P12B：一个故事范围内资产组合的边际价值与去重。
- P13B：一个范围内资产到事件机会组的完整分配。
- P14C0：一个章节事件集的去重与状态节点唯一归属。

这些任务输入/输出可能多条，但只回答一个不可拆的核心问题。

## 必须分开的任务
- 单条张力价值判断 P12 与同范围资产组合筛选 P12B。
- 资产注意力透镜 P13 与事件机会聚类 P13B。
- 单事件生成 P14A、单事件可行性 P14B、正文前单事件预检 P17A。
- 事件去重/节点归属 P14C0 与事件拓扑排序 P14C。
- 事件设计因果审计 P19D 与正文呈现因果审计 P19D2。
- 生产 Writer P18 与诊断渲染 P18D。
- 冲突解释生成 P11A、合理性比较 P11B 与确定性批准/物化/激活；提案不自行晋级为事实。

## 跳过而不是空调用
- 无语言样本不调用 P05C；无 VoiceCard 不调用 P19F。
- 无超自然机制不调用 P19B，宿主写 NOT_APPLICABLE。
- 没有值得资产化的张力，P12 返回 NO_ASSET；不要为了产量强制产生资产。
- P13B 可以 DEFER 或 NO_EVENT_IN_SCOPE；P14A 可以 NO_EVENT。
