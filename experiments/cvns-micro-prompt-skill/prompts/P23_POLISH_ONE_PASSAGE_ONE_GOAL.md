# P23 — 单段/单场景目标修订

**本轮唯一目标：** 根据 P19G 或其他审查结果，针对一个明确问题修订一段正文，在不破坏故事事实的前提下改善实际阅读体验。
**输入：** 一段已批准正文及必要上下文、事实/因果/POV/信息边界、一个指定问题及其文本证据、目标读者效果。
**只遵守本任务的限制：**
1. 一轮只解决一个主要问题，例如解释过量、人物声音趋同、情绪跳变、动作不清、节奏拖沓、潜台词不足、主角成长缺少代价、配角缺少自主行动、叙述声音模糊或战斗动作不可读；不得借机全面改写。
2. 先判断问题属于词句、段落、场景动作/反应、人物决策呈现、事件结构还是上游世界规则。若根因超出本段边界，输出 `NEEDS_UPSTREAM_REVISION` 或按合同中的最接近状态报告，不得用表面润色掩盖结构问题。
3. 可以调整句子、段落、动作与反应的呈现顺序、对话停顿和细节焦点；不得改变已批准事实、事件结果、人物知识、时间位置、关键道具归属、POV 或 payload 揭示顺序。
4. 不把“增加描写”当成通用修复。新增细节必须来自输入上下文或属于不改变事实的普通感知/动作衔接；不得新增关键证据、规则、期限、人物经历或情节前件。
5. 保留原文有效的独特表达和人物声音；不把所有人物改成同一种流畅、机智、诗意或冷峻的语言。避免同义词替换式伪润色、堆砌比喻、无意义扩写和过度解释。
6. 对人物弧线修订，必须明确补足的是“旧策略、压力、选择、代价、后续行为”中的哪一环；不得仅添加内心独白宣称角色成长。
7. 对配角自主性修订，只能恢复已批准的角色目标、行动和信息，不得为了立体化临时添加秘密、创伤或背叛。
8. 对修炼/战斗修订，必须使用已批准机制和技能状态；可增强动作可读性，不得扩大能力、削弱成本或改变胜负事实。
9. 修改后检查：目标问题是否实际改善；是否引入新事实/因果/POV/信息泄露；是否损害节奏、人物声音或上下文衔接。若改善不足或风险大于收益，保留原文并说明原因。
10. 输出修改稿及简洁差异说明，明确哪些句段改变、改善了什么、哪些内容刻意保留；不得宣称通过未执行的审计。
**交付：** 只输出 PolishedPassage，按随附字段合同组织。
