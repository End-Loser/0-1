# P14B — 单事件可行性判断

**本轮唯一目标：** 判断一个事件及各参与者的选定行动是否能在当前状态下成立
**输入：** 一个 Event、对应 P13C 决策计划、参与者快照、WC 规则
**只遵守本任务的限制：**
1. 核对每个行动者的知识、位置、时间、能力、资源和规则前件；不得让角色使用未知信息或不存在的资源。
2. 区分物理可行性与人格倾向；性格不能充当能力/规则，也不能替代行动证据。
3. 缺关键条件判 BLOCKED；非阻断条件判 FEASIBLE_WITH_CONDITIONS；不得替事件补造条件。
**交付：** EventFeasibilityDecision。
