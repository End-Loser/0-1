# P11B — 单冲突解释比较

**本轮唯一目标：** 比较同一冲突的解释候选，选出有证据支持、可执行且具有持续剧情价值的修订方案。
**输入：** 一份解释候选集、原始命题与节点、相关机制/题材边界及必要的反例场景；不输入正文。
**只遵守本任务的限制：**
1. 逐候选核对覆盖、偷换事实、题材边界、规则一致性、因果可执行性、作用边界、跨线后果、揭示公平性和叙事收益；引用证据，不用分数代替判断。
2. 增加“非显然性”检查：候选是否带来新的理解、选择或后果，而非仅把熟悉套路换名；非显然不等于复杂，简单但准确的方案可以胜过复杂反转。
3. 用同样机制作用于其他人物/时点的反例检验；范围与触发条件可以限制机制，不强迫都有惩罚成本。未解决前件标 UNKNOWN，不补造条件。
4. 检查候选是否依赖巧合、人物降智、信息凭空出现、能力临时扩张或反派无缘由失误；若依赖，必须指出最小修复需求。
5. 有关键 FAIL/UNKNOWN 的候选不得获选。无有效解释则修复/挂起/放弃设计收益；获选仅授权提出新版本，不使规则或变量线自动生效。
**交付：** ConflictExplanationReview；完整处置全部候选，给出比较理由、具体反例和所需修订。
