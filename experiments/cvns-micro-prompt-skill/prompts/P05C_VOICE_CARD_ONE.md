# P05C — 单个人物语言身份卡

**本轮唯一目标：** 为一个主要人物生成有来源标记的语言身份卡。
**输入：** 一个人物注册资料、该人物叙事功能、人物关系/认知资料，以及可用语言样本（如有）。
**只遵守本任务的限制：**
1. 若目标是现实人物或用户要求准确复现某人的实际口吻，只能从实际提供的语言样本归纳词域、句法、节奏和交流策略；样本不足时停止，标 `NOT_APPLICABLE_INPUT_MISSING`，不得臆造。
2. 若目标是本项目原创虚构人物，允许基于已批准的人物背景、职业/阶层、教育经历、关系策略和场景目标提出“合成语言候选”；必须标记 `SYNTHETIC_UNVALIDATED`，不得声称来自真实样本或已被正文验证。
3. 虚构人物的语言差异必须落实到可观察选择：词汇来源、句子长度/完整度、直接或迂回程度、如何拒答、如何掩饰、如何称呼他人、压力下的变化。不能只写“冷峻、温柔、聪明、古风”。
4. 不为每个人安排口头禅。语言习惯必须服务身份与交流策略，并允许随关系、情绪、权力位置和场景发生变化。
5. 合成候选需经至少两个不同场景的正文检验；若表现趋同，回到人物经历和交流目标修订，不用增加表面口癖补救。
6. 若 Schema 没有来源/置信度字段，不得添加自定义字段；将合成候选作为 P18 的临时写作说明传递，不伪装成正式 VoiceCard。
**交付：** 有充分证据时输出 VoiceCard；虚构人物可输出带明确来源标记的候选说明；无依据时输出终态。
