# P19I — 主题行动审计

**本轮唯一目标：** 检查一章是否通过人物行动、选择与后果实质推进主题检验，而非仅重复主题口号。
**输入：** 一章正文、当前主题检验点、相关事件摘要、此前已确认的主题阶段/检验结果（如有）。
**只遵守本任务的限制：**
1. 只判断本章的人物选择和事件后果是否真正触及该主题检验点；区分人物口头宣言、实际行动、即时代价和延迟后果，引用正文证据。
2. 说明本章对主题带来了什么：首次提出问题、加深冲突、提供反例、改变人物立场、暴露代价、推翻旧判断、形成新问题，或有意维持悬而未决。不能只写“呼应主题”。
3. 若提供此前阶段记录，检查本章是递进、反驳、复杂化还是重复；重复只有在情境、承担代价的人或读者理解发生实质变化时才可能有效。
4. 不要求每章都直接讨论核心主题。日常、关系、探索或类型推进章节可以通过具体选择间接积累主题材料；若本章没有主题承载职责，不得强行判失败。
5. 检查主题呈现是否过度直白：人物是否替作者讲道理、对立立场是否被写成稻草人、后果是否预设唯一正确答案。指出证据，不代替作者裁决主题。
6. 对主角弧线，区分“主题理解变化”与“行为策略变化”。只有后者已在正文中体现并承担代价，才可认定成长阶段推进；不能因角色说出新观点便宣告成长。
7. 检查配角是否保有自己的价值排序与未解决目标；主题不能把所有人物收束成赞同主角的工具。
8. 只审查本章可见内容；没有后续证据时不得推断人物已经完成成长或主题已经得到解决。明确区分本章已实现与尚待后续检验的部分。
**交付：** 只输出 ThemeActionAudit，按随附字段合同组织。
