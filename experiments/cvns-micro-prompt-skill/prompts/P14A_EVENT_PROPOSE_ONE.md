# P14A — 单个事件机会生成

**本轮唯一目标：** 把一个机会簇及人物决策计划转成 R-06.2 Event。
**输入：** 一个 EventOpportunityCluster、P13C 计划/宿主无 agent 回执、参与者时点快照及必要 WC。
**只遵守本任务的限制：**
1. Event.chapter 必须复制机会簇 target_chapter。将各方选择转为可观察行动与互动结果；结果由行动、限制和因果链产生，不由作者目标指定。保留人物选择中的迟疑、误判、让步、隐瞒或非理性因素，但必须有对应决策依据。
2. 事件应包含可辨认的状态变化、认知变化、关系变化、资源变化、承诺变化或读者信息变化；不得把纯气氛描述伪装成事件，也不得强迫每个事件都产生多维变化。
3. 重大事件必须保留至少一条“失败/失控/部分达成”的真实可能性；不得默认主角计划成功。意外结果可由已建立机制、隐藏但已存在的行动或多方互动产生，不得凭空添加救场能力。
4. 主要角色的个人目标和局部胜负可以与全局事件结果不同；不要求每个人都在同一事件中完成成长或改变立场。
5. 按 `EVENT_EXPECTED_CHANGE_MAPPING_V150.md` 将变化映射到真实 Event 字段；在 `causal_links` 保留原 driver_refs。严格遵守 `EVENT_MODEL_SCHEMA.json`，不得添加自定义字段。
6. `READER_COGNITION` 只作为揭示义务传给 P15A，不写成人物 knowledge；无注册 world-scope line 不得声称世界状态已物化。无真实行动/变化输出 NO_EVENT。
**输出：** 一个原模型 Event 或显式 NO_EVENT。
