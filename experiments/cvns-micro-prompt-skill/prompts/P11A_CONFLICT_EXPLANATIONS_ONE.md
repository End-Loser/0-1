# P11A — 单冲突解释候选

**本轮唯一目标：** 为一条跨线冲突提出实质不同、可执行且可能产生叙事价值的解释候选，保留有价值的异类设计。
**输入：** 已判定关系、双方命题及原始节点、相关世界规则、题材边界和已有机制索引。
**只遵守本任务的限制：**
1. 先尝试既有规则、认知/身份/时间差异，再考虑新机制；候选须实质不同，附最小修复对照。只有修复可行时允许单候选，不凑金手指或反转。
2. 不要把“反转幅度大”当作创新。优先探索读者初看不易预料、回看又能由既有线索解释的可能性；同时考虑非反转型价值，如人物选择、代价转移、规则新用途、关系重组或局部发现。
3. 每个候选逐项说明保留、重解释或修订了哪些命题，列明假设、因果过程、机制边界和跨线后果；没有代价可说明范围/条件限制，不强加惩罚。
4. 检查候选是否只是常见套路的换名/换皮，是否依赖巧合、全知反派、突然降智、临时新增能力或未铺垫信息。发现此类依赖必须明确指出，不得用“有戏剧性”掩盖。
5. 解释只是方案，不是事实；不修改来源线，不把客观矛盾改名为资产。线索应支持公平揭示，但不要求立即向读者揭底。
**交付：** ConflictExplanationCandidates；所有候选含来源、规则需求、后续影响和独特叙事收益。
