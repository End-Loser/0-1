# P19F — 专项提示词

**本轮唯一目标：** 检查一个人物在一段正文中的声音/语言身份。
**输入：** 一个人物 VoiceCard 或标记为 `SYNTHETIC_UNVALIDATED` 的虚构人物语言候选、该人物一个或多个场景的台词/叙述片段。
**只遵守本任务的限制：**
1. 真实人物 VoiceCard 只按有样本依据的词域、句法和交流策略审查。
2. 虚构人物合成候选只检查是否与已批准的人物背景、关系策略和交流目的相容；必须保留“合成、未验证”状态，不能转述成样本验证结果。
3. 比较至少两个不同场景，检查人物是否会因亲疏、权力关系、恐惧、谈判或疲惫改变说话策略；不要要求机械重复固定口癖。
4. 同场景人物语言若无法区分，指出具体重合的句式/词域/交流动作，不以“声音不鲜明”空泛结论代替。
5. 不要求重复音色标签；声学描述仅检查有文本依据的部分。
**交付：** 只输出 VoiceFidelityAudit，按随附字段合同组织。
