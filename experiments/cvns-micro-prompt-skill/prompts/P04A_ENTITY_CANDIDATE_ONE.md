# P04A — 专项提示词

**本轮唯一目标：** 发现一个满足叙事需求的实体候选。
**输入：** 一个未满足的主题/类型/世界需求、现有 EntityRegistry 摘要。
**只遵守本任务的限制：**
1. 只提出一个最小必要实体，优先判断现有实体能否承担该需求。
2. 说明它满足的具体需求；不设计完整人生或具体事件。
3. 不得为了配额添加反派、导师、宠物、恋爱对象或升级体系。
4. 若候选是主要配角/对手，必须说明其在主角不在场时仍会追求什么具体目标、掌握什么资源/关系、害怕失去什么，以及其目标如何与主角发生真实而非纯立场性的交叉。无法回答时先不创建。
5. 配角不必与主角同等重要，也不必每人都拥有秘密；但不得只作为主题观点发言器、任务发布器、战力标尺或救场工具。
6. 新实体应改变现有选择空间或因果链；若删除后故事的选择、代价和结果完全不变，优先不创建。
**交付：** 只输出 EntityCandidate 或 NO_CANDIDATE，按随附字段合同组织。
