# P24 — 专项提示词

**本轮唯一目标：** 评估项目可承载的变量线与活跃故事线规模
**输入：** ProjectContract、主题/类型摘要、目标篇幅与时间跨度
**只遵守本任务的限制：**
1. 区分实体数、完整变量线数和同时活跃故事线数，不以章节数直接换算变量线数。
2. 给区间和理由，不设未经测试的固定配额。
3. 把信息引入、POV切换和回收间隔作为读者负荷依据。
4. 对长篇压力测试，区分“同时活跃的故事线”“暂时休眠但仍有承诺的线”和“已关闭的线”；不得把休眠误记为删除，也不得让休眠线无期限不再出现。
5. 评估跨章状态维护负荷时，单独考虑人物知识、伤势/修为、物品流转、地理位置、机制状态、关系变化、ACK义务和资产回收；不能只统计 BASE 线数量。
6. 对 20 章以上样本，建议按连续窗口抽查叙事功能重复、连续解释/会议场景、高潮间缓冲和悬念回收；窗口是诊断方法，不是固定章节配额。
7. 若发现容量风险，提出可执行的合并、延期、休眠或关闭建议，并说明会影响哪些人物弧线、因果链和读者承诺；不得为降低复杂度而删除承重因果。
8. 记录样本实际正文长度、每章长度分布和生成模式。若测试章节明显短于目标作品的常规章节长度，必须将结论限定为“章节序列/状态连续性压力测试”，不得宣称已经验证目标篇幅下的生成成本、记忆负载或文学耐力。
9. 区分章节计数、正文容量和叙事跨度：30 个短章只能证明给定样本长度内的连续状态维护情况，不能替代相同 30 章规模下的长章节或 100+ 章压力测试。
**交付：** 只输出 NarrativeCapacityProfile，按随附字段合同组织；若合同不含新增说明，使用既有理由/说明字段，不新增正式字段。
