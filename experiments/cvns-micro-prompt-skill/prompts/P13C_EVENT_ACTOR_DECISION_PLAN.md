# P13C — 事件机会人物决策推演

**本轮唯一目标：** 推演一个机会簇内全部主要决策者为何、如何在当时条件下选择行动。
**输入：** 一个机会簇、参与者时点状态/知识、必要 P05E 卡、规则和资产阶段边界。
**只遵守本任务的限制：**
1. 只推演 primary_actors 中需决策者，列知识、动机、约束及 `profile_ref::tendency_id`；世界事实和他人状态不自动成为角色已知。倾向只影响偏好，不是硬规则；偏离倾向须有当时动态证据，不能只用“剧情需要”解释。
2. 对每个重要决策者，分别区分：客观处境、角色实际知道的内容、角色相信但可能错误的内容、明确目标/欲望、稳定倾向、当下情绪与压力、个人关系和长期利害。不得将这些层次混写。
3. 先建立“候选方案清单”，把机制上出现过的路径逐一标为 FEASIBLE、CONDITIONAL、INFEASIBLE 或 UNKNOWN，并给出对应规则/证据理由；再比较所有真实可行选项及收益/代价。不制造假二选一，可在可行时纳入不行动/拖延/部分合作。涉及重大不可逆后果时，不得遗漏规则允许的路径，也不得把理论上可想象但已越过承载上限的路径伪装成可行选项。仅一个可行选项须说明其他候选方案为何被排除。
4. 为主要角色列出“若选此项，自己具体失去什么”，至少区分即时、延迟、关系/身份、身体/修为或资源成本；不强求每次都出现不可逆代价，但不得用抽象的“承担责任”代替具体损失。
5. 人物不必总是理性最大化。可出现冲动、恐惧、羞耻、面子、疲惫、偏见、依恋、习惯、误判或自我欺骗；但须说明这些因素如何影响注意、判断或行动，且不得把“非理性”当作无因果的借口。
6. 区分人物当时真正驱动选择的因素、人物能够说出的理由，以及事后合理化；没有证据时不得替人物编造潜意识解释。
7. 记录最终选择、放弃理由、即时/延迟代价、对他人的影响、一致性、反事实和证据。反事实用于检验选择是否具有个体差异，不要求每个人都选择不同；若不同人物面对同一选项却得出相同结果，说明其各自理由。
8. 检查人物个性是否真正改变了选项排序、风险承受、信任判断或行动方式；若删去 P05E 倾向卡后决策完全不变，说明该倾向在本次决策中没有实际作用，不得为了引用 tendency_id 假称其发挥作用。
9. 对跨线事件，分别保留各行动者的目标和行动链；不得为了聚合成一个事件而抹掉某个角色独立的计划、隐瞒或后续行动。
10. 必需 profile 未批准即阻断。`unresolved_gaps` 只列影响本次选择/执行的缺口并说明影响；无关未知留 `unknown_facts`，不因假设倾向或案件未解自动阻断。真实条件不明标 CONDITIONAL/BLOCKED，不强迫 READY。
**输出：** EventDecisionPlan；意图不是事件结果。
