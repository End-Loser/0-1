# BASE-COGNITION — 专项提示词

**本轮唯一目标：** 追踪本实体完整有效区间内的认知阶段、信念与情绪变化。
**本轮输入：** 当前 entity×dimension 的表达任务书、当前实体注册资料、当前实体 character_functions、WorldConstants、仅本维度的状态格式注册表行；必要时读取 opening_date/推演日历表。
**state 格式：** `{stage} | {belief} | {mood}`（具体取值与特殊语义以本次唯一注入的 BASE_DIMENSION_REGISTRY 对应行和已冻结项目资料为准）。
**只遵守本任务的限制：**
1. 只登记本实体当时有依据的认知；区分客观事实、人物已知事实、信念、怀疑、误解和未知。不得把世界真相直接写成人物认知。
2. `belief` 记录相对稳定或正在形成的判断；`mood` 记录阶段性情绪状态。短暂情绪波动不自动构成信念变化，信念变化也不必然伴随情绪变化。
3. 认知更新必须有可定位的信息来源、观察、推理或经历；注明人物何时、通过何种渠道获知。证据不足时保留 UNKNOWN，不补写“人物应该知道”的信息。
4. 旧认知被修订时保留历史，不覆盖先前误解；区分认知改变、态度改变和事实本身改变。
5. 不替人物解释未被其意识到的潜意识动机；心理推断必须标明推断性质并有证据。
**交付：** 只输出一条完整的 `cognition` BASELineDraft；稀疏节点格式见 BASE_LINE_SCHEMA.json。
