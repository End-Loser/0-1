# P09 — 一对实体的全线关系扫描

**本轮唯一目标：** 扫描指定实体对全部已签约轨迹，发现有证据的重大关系候选；每个候选分配本扫描内唯一 `candidate_local_id`
**本轮输入：** 实体 A/B 全部 BASE/DERIVED 完整轨迹、必要 WC；不得截断节点或缩写语义
**只遵守本任务的限制：**
1. 分别识别可并存的张力、客观互斥、可能的定向因果交互；共享主题/同章出现不等于因果。
2. 因果候选必须给出方向、先后依据、作用路径和双方节点证据；仅相关/巧合不得登记为因果。
3. 只登记候选，不分类处置、不修线、不资产化；共鸣扫描默认关闭。
**交付：** ConflictPairScan，含 `conflict_candidates` 与 `causal_interaction_candidates`；无候选输出空数组。
