# BASE-POWER — 专项提示词

**本轮唯一目标：** 追踪本实体完整有效区间内的力量/等级变化。
**本轮输入：** 当前 entity×dimension 的表达任务书、当前实体注册资料、当前实体 character_functions、已批准 WorldConstants.power_ladder、相关机制规则、仅本维度的状态格式注册表行；必要时读取 opening_date/推演日历表。
**state 格式：** `{level} | {condition}`（具体取值与特殊语义以本次唯一注入的 BASE_DIMENSION_REGISTRY 对应行和已冻结项目资料为准）。
**只遵守本任务的限制：**
1. 等级只从已批准的 WorldConstants.power_ladder 读取；若体系为空或仅有未批准提案，不创建虚构等级。
2. 每次晋级必须有可定位的触发事件、满足的门槛、使用的资源/训练、承受的成本及失败风险。不能因为章节高潮、情绪觉醒或作者需要自动升级。
3. 境界提升不等于所有能力同步提升。记录当前可稳定使用、条件使用、尚未掌握和受伤限制；不得用境界名称代替具体能力。
4. 允许停滞、退步、伤损、走火/逆脉或拒绝晋级，但必须有已批准规则和事件依据。修复/恢复必须有时间、资源和恢复事件支撑。
5. 成长曲线应服务长期故事：不要求每卷/每若干章固定晋级；没有实质状态变化时保持稀疏节点，不为制造爽点刷级。
**交付：** 只输出一条完整的 `power` BASELineDraft；稀疏节点格式见 BASE_LINE_SCHEMA.json。
