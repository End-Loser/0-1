# P02C — 主题结局回应条件

**本轮唯一目标：** 定义全书主题如何通过人物选择、代价与后果逐步接受检验，并在结局得到回应。
**输入：** CoreThemeQuestion、已冻结的立场对、ProjectContract、可用的 SubTheme/Anchor 摘要（如尚未生成则明确缺失）。
**只遵守本任务的限制：**
1. 只规定结局必须回应的问题，不规定谁胜利、谁必须悔悟或人物必须接受什么答案；不得把主题写成作者训诫。
2. 将主题检验拆成可观察的阶段性压力：每一阶段说明哪种价值选择受到考验、选择会牺牲什么、后果由谁承担。阶段之间必须有递进或重新解释，不能只是重复同一道题。
3. 至少考虑：人物在低代价情境中的表态、利益受损时的选择、面对他人代价时的选择，以及最终无法回避的选择；不适用时说明原因，不为凑数量制造情节。
4. 允许人物改变立场、坚持立场、妥协或自我欺骗；变化必须由经历、证据、关系或代价支持，不得把“成长”预设为必然正确的方向。
5. 每项条件必须能通过后续行动、选择或后果观察；区分人物口头宣言、实际行动和行动造成的长期影响。
**交付：** 只输出 ThemePayoffConditions，按随附字段合同组织。字段合同不支持的细节不得擅自新增字段；可在既有说明字段中表达。
