# P05A — 专项提示词

**本轮唯一目标：** 确定全书抽象叙事弧线形状。
**输入：** ProjectContract、ThemeSpec、SubTheme/Anchor、主类型阅读期待、主要角色的起点困境/应对策略摘要。
**只遵守本任务的限制：**
1. 只给出宏观状态推进和张力走势，不写具体事件、人物行动或章节剧情。
2. 弧线必须回应主题检验点和主类型的阅读期待。
3. 对主角明确“起点误判/防御策略—反复受到挑战—承担不可逆代价—行为策略改变—新局限”的变化方向；不得把成长简化为更强、更善良或更懂道理。
4. 对重要配角至少标明其独立弧线是否变化、与主角弧线在哪里交叉，以及其是否可能拒绝主角的价值结论。
5. 宏观推进可采用多线并行、交错揭示、回溯或多 POV，但必须区分事件真实发生顺序与读者获知顺序；不得靠隐瞒 POV 本应知道的事实制造廉价悬念。
6. 若主类型承诺成长/战斗/探索，宏观弧线必须安排能力成长与代价、规则探索和实际行动的承载位置；不能只在设定层写出境界表。
**交付：** 只输出 NarrativeArcShape，按随附字段合同组织。
