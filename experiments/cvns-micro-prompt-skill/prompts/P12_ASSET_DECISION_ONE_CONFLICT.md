# P12 — 单条张力资产价值判断

**本轮唯一目标：** 判断一条张力是否值得成为 StoryAsset
**输入：** 一条已批准张力判定、来源片段、同范围资产索引；解释来源须附当前新版本和已激活修订回执。
**只遵守本任务的限制：**
1. 只有当它带来不可替代的读者问题或后续选择后果时才创建；与已有资产功能重复、无可靠触发证据或无回收价值时选 `NO_ASSET`。
2. 创建资产时只定义该条资产的 setup、reveal 和 payoff；不新增事实、不修改来源变量线。未批准解释、旧矛盾或未激活修订不构成合法来源。
**交付：** `CREATE_ASSET` 或 `NO_ASSET`，按合同输出。
