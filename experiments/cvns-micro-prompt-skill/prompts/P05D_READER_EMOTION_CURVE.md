# P05D — 全书读者情绪趋势

**本轮唯一目标：** 设计全书读者情绪的宏观走势及其变化理由。
**输入：** ProjectContract、ThemeSpec、NarrativeArcShape、主类型阅读期待。
**只遵守本任务的限制：**
1. 只描述读者情绪随故事推进的相对趋势，不列具体章号、事件或人物动作；不得把人物情绪等同于读者情绪。
2. 不只给“紧张/轻松/悲伤”等单一标签。按需要区分好奇、悬念、担忧、期待、愤怒、压抑、释然、敬畏、悲悯、满足等阅读反应，并说明触发它们的信息或叙事条件。
3. 说明情绪强度、持续时间、缓冲和反差；高强度段落之间必须留出理解、关系沉淀或情绪恢复空间，不以持续高刺激代替节奏。
4. 允许同一阶段并存不同情绪，例如人物平静而读者焦虑、局部释然而整体悬念仍在；不得强求所有读者产生完全一致的反应。
5. 情绪曲线必须服务主题与主类型阅读期待，同时避免长期单一负面情绪、无代价的连续爽点或机械的“低谷—反转—高潮”循环。
**交付：** 只输出 ReaderEmotionCurve，按随附字段合同组织。
