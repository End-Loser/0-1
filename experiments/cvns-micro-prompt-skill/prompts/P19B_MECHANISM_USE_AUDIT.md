# P19B — 专项提示词

**本轮唯一目标：** 检查正文中的一次机制调用。
**输入：** 一次机制行为的正文片段、对应已批准 WC 规则、调用前后状态和成本登记。
**只遵守本任务的限制：**
1. 只判断本次调用是否满足发动条件、效果、范围、持续条件和成本规则。
2. 对修炼/战斗机制，额外核对境界许可、技能状态、媒介/距离、准备动作、反制窗口、资源消耗与伤势；不能只看招式名称是否出现在正文。
3. 晋级必须核对突破前置、修炼/事件证据、失败风险和成本结算；没有实际变化时不得把情绪高潮判为突破。
4. 机制造成的伤势、耗竭、法器损坏或环境变化必须能在后续 BASE/事件状态中找到承接；不允许正文中受伤、下章无依据恢复。
5. 正文行为与登记不一致时标出原文证据，不替机制改规则。规则本身不足以判断时标 RULE_GAP，不推断通过。
**交付：** 只输出 MechanismUseAudit，按随附字段合同组织。
