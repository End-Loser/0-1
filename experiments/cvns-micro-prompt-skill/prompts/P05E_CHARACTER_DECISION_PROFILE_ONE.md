# P05E — 决策主体稳定倾向卡

**本轮唯一目标：** 为有下游消费者的重要主体生成有证据边界的稳定决策倾向 sidecar。
**输入：** 单个实体设计/背景、character_functions、主题角色及可定位依据；不读其他实体 BASE 线。新角色可提出待验证假设，但不得虚构经历。
**只遵守本任务的限制：**
1. 从价值排序、风险/不确定性处理、信任策略、冲突/压力反应和盲点推导行为机制；不得只写勇敢/善良等标签。稳定倾向须与临时情绪、信念、目标、欲望、关系区分，后者仍由既有 BASE 线承载。
2. 尽可能描述“形成经历/环境→触发条件→注意或解释倾向→行为偏好→可能代价”，但不得把人物写成固定算法。形成经历只有输入支持时才能标 ESTABLISHED；推断或新设定须标 SUPPORTED_INFERENCE/HYPOTHESIS。
3. 每项倾向给 profile-local `tendency_id`、触发条件、行为表现、边界/反例、可定位 `evidence_refs`，并标 `ESTABLISHED` / `SUPPORTED_INFERENCE` / `HYPOTHESIS`。假设不得伪装成事实；无证据时明确留空或标记不足。
4. 允许记录不体面、不理性或自相矛盾的倾向，例如冲动、回避、嫉妒、面子驱动、短视、过度控制；但必须有来源依据，不为追求“复杂”而给每个人强加创伤、秘密或心理疾病。
5. 区分人物真实驱动力、人物能够意识到的理由、人物事后对外/对内的合理化解释；只有资料支持时才记录后两者，不替人物诊断潜意识。
6. 对承担长期人物弧线的主体，指出一个可能发生变化的“应对策略/自我叙述”，但只描述起点和可检验的变化方向，不预定未来具体选择或结局。成长必须由后续选择、代价和新行为证明，不以口头顿悟代替。
7. 不预定未来具体选择，不把 tendency_id 当作 P13C 的强制行动规则；P13C 必须结合当时认知、欲望、目标、关系、资源、压力和可行选项重新判断。
8. 本卡不是 BASE 线或第12维，不预定未来选择；非决策主体输出 `NOT_APPLICABLE`，依据不足输出 `INSUFFICIENT_BASIS`，不得补造人格。
**输出：** CharacterDecisionProfile 或显式终态。
