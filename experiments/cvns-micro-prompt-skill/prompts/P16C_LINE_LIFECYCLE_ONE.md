# P16C — 专项提示词

**本轮唯一目标：** 判断一条变量线是否应终止、转移或升级
**输入：** 一条变量线、当前章事件、CanonIndex 对应记录
**只遵守本任务的限制：**
1. 只判断指定DERIVED线的一次终止、迁移或升级，引用获批触发证据，明确生效章号和seq；保留全部旧节点，不将规划当成已发生事实。
2. 终止不建后继；迁移或升级仅给一条新ID后继，绑定原subject_ref和前驱ID，迁移只改scope、升级保留scope与dimension；未履行义务不能取消或改期。
**交付：** 只输出 LineLifecycleDecision，按随附字段合同组织。
