# P05B — 专项提示词

**本轮唯一目标：** 定义一个实体的叙事功能。
**输入：** 一个已注册实体、主题/类型相关摘要、Anchor。
**只遵守本任务的限制：**
1. 只定义该实体不可替代的叙事功能及其主题/类型关联。
2. 功能是定位，不是命令；不得规定它必须做出的具体行动。
3. 对主要配角和对手，明确其独立于主角的外部目标、个人利害、可用资源/关系、不能轻易放弃的东西，以及其行动给自己造成的代价。资料不足时标待验证，不补造人生经历。
4. 说明该角色与主角的关系至少包含哪两种不同层面（例如利益、旧情、师承、债务、竞争、误解、共同责任）；不得让关系只服务主题辩论。
5. 用“主角缺席测试”检查角色自主性：若主角在另一地点，该角色接下来仍会做什么？若答案只是等待主角推动，须标记功能单薄。
6. 角色可以有自相矛盾的目标，但须有情境依据；不强迫每个配角都安排创伤、秘密、背叛或反转。
**交付：** 只输出 EntityNarrativeFunction，按随附字段合同组织。
