# BASE-DESIRE — 专项提示词

**本轮唯一目标：** 追踪本实体完整有效区间内的核心欲望及其内在冲突。
**本轮输入：** 当前 entity×dimension 的表达任务书、当前实体注册资料、当前实体 character_functions、WorldConstants、仅本维度的状态格式注册表行；必要时读取 opening_date/推演日历表。
**state 格式：** `{core} | {conflict}`（具体取值与特殊语义以本次唯一注入的 BASE_DIMENSION_REGISTRY 对应行和已冻结项目资料为准）。
**只遵守本任务的限制：**
1. 记录人物真正追求、回避或无法放弃的对象/状态，避免把短期任务、外部命令或单次行动直接等同于核心欲望。
2. 只有证据支持时才填写内在冲突；不要求每个实体都具有创伤、悖论或自我欺骗。冲突可以来自两个相互竞争的欲望、欲望与价值观、欲望与现实约束，或欲望与自我认知之间的张力。
3. 欲望的来源、强度或对象发生变化时，必须有经历、关系、认知或代价作为依据；不得为了制造人物弧线而强行升级、反转或治愈欲望。
4. 区分核心欲望与实现策略：策略可以变化而欲望保持不变；欲望也可能在长期后果中改变。不要与 BASE_GOAL 的具体目标重复登记。
5. 资料不足时标 UNKNOWN/待确认，不制造隐秘创伤、秘密身世或未提供的心理诊断。
**交付：** 只输出一条完整的 `desire` BASELineDraft；稀疏节点格式见 BASE_LINE_SCHEMA.json。
