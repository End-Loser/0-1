# P01F — 战斗规则与战术语法提案

**适用条件：** 主类型承诺战斗、斗法、宗门冲突或以能力对抗推动剧情。
**本轮唯一目标：** 定义能够反复生成清晰、有策略、有代价战斗的规则提案；不直接写入已生效 WorldConstants。
**输入：** 已批准或待审批的修炼体系提案、机制规则、场地条件、主要人物技能/资源、主类型阅读期待。
**只遵守本任务的限制：**
1. 战斗胜负至少由境界/能力、技能匹配、空间/地形、情报、先手/节奏、资源/体力、伤势/心理状态中的若干因素共同决定；不得只比较境界数字。
2. 每种主要能力明确发动条件、作用对象、距离/范围、持续时间、准备动作、资源成本、失效条件和已知反制。不得出现无边界全能招式。
3. 建立可读的战斗行动链：目标→站位/距离→发动→对手反应/反制→局势变化→成本/伤势。关键动作必须让读者知道谁在何处、做了什么、为何有效或失败。
4. 设计至少三类战斗胜利条件：击败对手之外，可包括守住/夺取位置、争取时间、救援、破坏装置、阻止仪式、迫使撤退或完成撤离。
5. 说明越级作战何时可能、需要哪些准备与条件、必须支付什么代价；禁止主角因愤怒/信念/临场喊话自动获得超出规则的力量。
6. 伤势、耗竭、法器损毁、环境污染和社会后果必须进入后续状态；不能战斗结束即无痕恢复。恢复有时间/资源/失败风险。
7. 对重要对手设计独立战术目标和可解释的强项/盲点；不得把对手写成等待主角展示招式的沙袋。
8. 输出标记 SOURCE_FACT / INFERENCE / PROPOSAL / RULE_GAP。与现有规则冲突时不得私自调和。
9. 本提案须经 P21A 审批后才能作为机制规则生效；若现有 Event/BASE Schema 无法表示承重状态，标 `BLOCKED_SCHEMA_GAP`，不增加自定义字段。
**交付：** CombatSystemProposal（提案，不是正式 WorldConstants）。
