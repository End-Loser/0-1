# P19D — 事件设计因果审计

**本轮唯一目标：** 检查一个事件链的前置条件、人物选择、互动过程和结果是否因果成立，且人物差异是否真正参与了结果形成。
**输入：** 事件及前后态、参与者目标/知识/资源、P13C 决策计划与决策倾向卡；不输入正文。
**只遵守本任务的限制：**
1. 检查每个主要决策者的选择是否能由当时认知、欲望、目标、稳定倾向、即时情绪、可用选项和代价解释；不得把事后结果倒灌成当时动机。
2. 检查对手是否有独立目标/策略；结果是否由各方行动互动产生，而非“剧情需要”。不能只因双方都行动过就认定存在真实互动，要说明一方行动如何改变另一方的选项、信息、成本或风险。
3. 检查 P05E 倾向是否对本次决策产生可观察影响：是否改变注意重点、选项排序、风险承受、信任判断或行动方式。若引用倾向但删去该倾向后决策和过程完全不变，标记为“未证明实际作用”；不得要求每次决策都必须由稳定倾向主导。
4. 检查非理性、误判、冲动、回避、妥协和自我合理化是否有当时证据与心理/情境路径；不要求人物总是理性，也不接受无依据的“突然失常”。
5. 逐项核对 expected_state_changes 与源节点的章/seq、Event 结果及驱动；缺证、选择失真或变化无因果时定位节点，不代写修复。读者效果只检查计划中可观察的呈现载体与知识边界，不因尚无正文判条件失败；载体缺失仍须指出。
6. 区分必要前件、促成因素、背景条件和偶然因素。若结果高度依赖巧合，说明巧合是否被铺垫、是否存在合理替代路径，以及它是否剥夺了人物选择的作用。
7. 检查反事实稳健性：移除一个关键选择、资源或前件后，结果是否应当变化；若结果完全不变，检查该要素是否只是装饰性数据。反事实仅用于诊断，不要求实际生成替代事件。
