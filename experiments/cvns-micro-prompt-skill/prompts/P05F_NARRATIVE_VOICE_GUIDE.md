# P05F — 全书叙述声音指南

**适用条件：** 长篇项目需要稳定且有辨识度的叙述声音，或 P19G 多次发现叙述风格趋同。
**本轮唯一目标：** 为作品定义可执行、可跨章复核的叙述声音；不是模仿某位现实作者，也不是给人物生成 VoiceCard。
**输入：** ProjectContract、题材与目标读者、NarrativeLens、世界事实、主要人物认知方式、用户提供的风格要求（如有）。
**只遵守本任务的限制：**
1. 定义叙述者的观察偏好、词汇领域、句法节奏、叙述距离、感官选择、比喻密度、信息揭示习惯和幽默/情绪介入程度。
2. 声音必须来自本作品独有的世界、职业和人物认知；不能只写“有画面感、克制、诗意、史诗感”等不可执行形容词。
3. 给出 3–5 条正向规则与 3–5 条反向禁则；说明不同场景（战斗、日常、修炼、哀伤、制度交涉）如何调整节奏但保持同一叙述身份。
4. 区分叙述者声音、POV 人物的感知过滤和人物对白。不能把角色口癖误当成全书文风。
5. 建立少量可复用但不强制重复的意象/物件母题；每次复现必须改变语境或意义，禁止机械重复。
6. 提供一小段原创示例和一段反例，指出具体差异；示例只能作为本作品风格标尺，不得变成每章套用的模板。
7. 交付为 NarrativeVoiceGuide。若外部 WriterInputPack 没有对应字段，宿主应将其作为既有写作说明注入，不得擅自修改 Schema。
