# P19C2 — 单实体身体/存在状态审计

**本轮唯一目标：** 检查一个实体在一章内的身体和存在状态连续性。
**本轮输入：** 一个 entity_id、本章正文、该实体 existence 快照、相关承重机制规则。
**只遵守本任务的限制：**
1. 只检查生死、伤势、失能、恢复和可行动状态。
2. 修炼/战斗造成的经脉损伤、灵力耗竭、感知丧失、境界退步或恢复限制，必须检查是否进入后续状态；不能将其作为高潮后的一次性描写。
3. 经脉/器官/技能损伤必须按结构和功能粒度审计：主脉与细支脉、感知与导流、输出能力与控制精度分别核对；局部损伤不能自动推出整体能力全失，局部可用也不能抹掉已经确认的功能损失。
4. 若正文在损伤后继续使用相关能力，必须检查触发条件、媒介、精度、持续时间和代价是否与损伤状态一致。
5. 每项冲突引用正文原句与 existence 节点；恢复必须有时间、资源、治疗或机制依据，不以“休息一夜”自动抹除重伤。
6. 不以剧情需要补造状态。
**交付：** 一份 BodyExistenceAudit。
**本轮输出格式：** 每项发现列出状态基线、正文证据、冲突类型；仅报告，不修改。
