# P13B — 单范围事件机会聚类

**本轮唯一目标：** 从已选资产阶段、已确认关系及输入中有依据的行动机会，识别可成立的真实事件机会。
**输入：** SELECTED 阶段需求、确认关系、相关人物状态及时间/地点窗口；仅使用本次输入中实际提供的实体目标、欲望、认知、世界规则和既有事件线索。
**只遵守本任务的限制：**
1. 机会来源不局限于显式冲突。可识别：目标追求、主动探索、偶然发现、日常事务产生的连锁后果、制度/环境变化、关系维护或破裂、信息差、规则试验、失误与意外；但每项必须有输入证据和可解释的触发路径，不得凭空造机会。
2. 仅在核心行动、互动决策、兼容结果及时空均相容时聚类；同地点/主题/章节不够。写明戏剧问题、目的、触发、行动者、预期变化与 driver_refs。
3. 不要求每个机会都升级为冲突或重大事件。小事件只有在改变认知、关系、资源、风险、承诺、读者问题或后续可选行动时才保留；没有实际变化时 DEFERRED/NO_EVENT。
4. 每簇只对应一个 `target_chapter`；资产阶段章必须逐字复制 P12B `phase_chapters`，不得改期或跨章聚类。每个 `asset_id×phase` 在本范围唯一分配/延期/不发生；同一资产可跨不同阶段；若同一事件承载同资产多个阶段，源目标章必须相同，且同一行动序列确实分别兑现各阶段而不越过 payload ceiling。每个 `candidate_ref` 唯一进入一个簇或有因由地列入 unassigned；禁止一资产/一关系机械一事件。
5. 只产机会簇，不生成 Event；BASE_LINE 目标逐项引用本章 proposed 源节点，不虚构或改写章/seq；状态变化必须引用本簇 driver_refs。不得为了凑章节密度制造空事件。
6. 聚类前先判断是否真有共同的行动序列；若只是同一人物、同一地点或同一主题下的独立事情，必须拆开。若合并会抹掉不同人物的独立选择或因果路径，必须拆开。
**输出：** EventOpportunityPlan；状态变化必须引用本簇 driver_refs。
