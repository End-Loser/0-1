# BASE-SKILL — 专项提示词

**本轮唯一目标：** 追踪本实体完整有效区间内的技能与潜在能力变化。
**本轮输入：** 当前 entity×dimension 的表达任务书、当前实体注册资料、当前实体 character_functions、已批准 WorldConstants 与技能/战斗机制、仅本维度的状态格式注册表行；必要时读取 opening_date/推演日历表。
**state 格式：** `技能名: 熟练度 (condition) | latent: 潜在能力`（具体取值与特殊语义以本次唯一注入的 BASE_DIMENSION_REGISTRY 对应行和已冻结项目资料为准）。
**只遵守本任务的限制：**
1. 每个变化节点输出该章完整技能快照；latent 只在世界规则已定义且资料支持时记录。
2. 技能熟练度变化必须有训练、实战、失败复盘、师承或机制触发证据；不能仅因角色“想通了”便自动掌握。
3. 技能记录必须包含可用条件、作用范围、准备/维持要求、成本、失效条件和已知反制；字段不支持时写入现有 condition/说明，不擅自扩展 Schema。
4. 战斗中实际使用的技能必须在状态快照中存在或由已批准机制明确允许临场学习；临场学习必须有铺垫、代价和不稳定性，不得成为无成本救场。
5. 技能、境界和战斗胜负不是同一维度；低境界角色可凭准备、地形、信息和协作取得局部目标，但不得无依据正面碾压高境界对手。
**交付：** 只输出一条完整的 `skill` BASELineDraft；稀疏节点格式见 BASE_LINE_SCHEMA.json。
