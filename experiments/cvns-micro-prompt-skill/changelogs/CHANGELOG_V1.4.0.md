# V1.4.0 更新记录

## 基于真实多变量线测试修复
- 新增 P12B 同范围资产组合筛选，避免所有张力自动变资产。
- 新增 P13B 事件机会聚类，修复一资产一事件导致同质事件爆炸。
- P14A 改为一机会组一事件，可承载多条资产。
- 新增 P14C0 事件去重与 BASE 状态节点唯一所有权分配。
- P14C 只排序有效事件；循环/冲突时阻断。
- P08 调整为 P14C 后运行，避免候选事件数与放行事件数不一致。
- P17A 使用固定决策枚举；仅 READY/CONDITIONAL_READY 进入后续。
- 新增确定性章节计划批准/稳定ID/冻结工具，禁止覆盖。
- P17C 强制完整依赖闭包与批准清单。
- P18 正式 Writer 与 P18D 诊断渲染分开。
- P19D 明确为设计层因果审计；新增 P19D2 审正文实际呈现。
- 缺语言样本时跳过 P05C；无 VoiceCard 时跳过 P19F。
- 更新输入包策略：精确 WC ID 引用、去重、纳入理由 manifest、仅传被选资产。
- 增加本次测试的数据使用/排除分析。
