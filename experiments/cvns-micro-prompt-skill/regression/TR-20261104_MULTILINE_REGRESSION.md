# TR-20261104-MULTILINE 回归案例 V1.4.1

以下失败案例不得从回归集中删除：

1. **资产过量接受：** 5条张力资产全部被P12接受；P12B必须允许并合理使用 NO_ASSET/DEFERRED/MERGED。
2. **同质事件生成：** 5条资产共享第6章档案室登记场景；P13B必须将同一场景机会聚类，P14A不得机械一资产一事件。
3. **节点重复归属：** 三个事件声称同一组 BASE 变化节点；P14C0必须阻断或生成明确唯一归属方案。
4. **因果循环：** 事件2与事件3互为前置；P14C必须 BLOCKED，不能给伪总序。
5. **P08候选数量污染：** P08提前读取5个候选，P14C后只剩3个；P08必须在最终事件序列后运行且不保存候选事件计数。
6. **P17C缺审批冻结链：** DRAFT和占位ID不能通过；宿主章节计划终结器必须拒绝不完整包。
7. **Writer强制草稿：** P17C BLOCKED 后不能调用生产 P18；测试只能使用 P18D 并标 DIAGNOSTIC_ONLY。
8. **输入依赖闭包：** 精确引用 WC-02 时，即使审计类型为 geography，也必须注入 WC-02；按 domain 过滤不合格。
9. **P05C空样本：** 无语言样本时不应发生模型调用。
10. **P19D输入错位：** 不含正文的 P19D 不能声称审正文因果；正文审计必须由 P19D2 接收正文片段。
11. **资产引用报告不一致：** P13 JSON 实际5条 asset_refs，报告不得写成3条；数据报告应以原始JSON为准。
12. **数据消费统计：** 报告必须区分直接消费、门禁/诊断、proposal-only、excluded、superseded、not-applicable，不把所有未进正文的产物叫丢弃。


## V1.4.1 新增数据流与输入包回归
13. **P04B重复调用**：候选实体已存在于 EntityRegistry 时，preflight 必须 SKIP，不能再花一次LLM调用重复审查。
14. **P19F无基线**：缺少批准 VoiceCard 时必须 SKIP；不得把段内观察报告冒充VoiceCard保真审计。
15. **Writer Pack三处重复**：P17C不得接收完整Writer Pack；P18只接收一次，顶层不得重复章纲。
16. **输入包超预算**：超过300 KiB必须有例外授权；不得把完整事件链/全部审计作为单事件输入。
17. **消费状态区分**：引用、选择、物化、渲染、验证、终态与SUPERSEDED必须分别登记。
18. **未采用不等于删除**：被BLOCKED/REJECTED/DEFERRED的候选保留证据与原因，不得计为最终正文采用，也不得自动删除源成果。
