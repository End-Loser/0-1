# V1.5.0 人物决策与事件合成回归集

| Case | 输入形态 | 预期处理 | 禁止的错误 |
|---|---|---|---|
| R150-01 | 林晚 goal=公开档案；desire=保护母亲；二者可同时为真但难以两全 | P09 产生张力候选，P10=TENSION_ASSET_CANDIDATE | 判为互斥或直接生成事件 |
| R150-02 | 同一时刻唯一档案同时由两人独占持有 | P10=MUTUALLY_EXCLUSIVE_ERROR，P11 提修复 | 包装成反转/悬念资产 |
| R150-03 | 周砚的行动导致林晚 cognition/relation 改变，有方向事件证据 | P09 因果候选，P10=CAUSAL_INTERACTION_CONFIRMED，可被 P13B 引用 | 仅因同章出现就确认因果 |
| R150-04 | 林晚线与县测绘局线只在主题上都涉及“真相” | 无实质关系或不输出候选 | 把主题相似当因果/冲突 |
| R150-05 | 林晚的性格是回避冲突，但当前认知/欲望和高风险处境发生变化 | P05E 提供倾向，P13C 仍按当前状态推演选择 | 把性格标签当固定动作命令 |
| R150-06 | 一个资产的 SETUP 在 ch2、REVEAL 在 ch6、PAYOFF 在 ch9 | P13B 分配到不同机会组或延期，各阶段唯一 | 一资产只能进一个事件簇 |
| R150-07 | 两条资产同一档案室，但要求不同动作/不同决策/不同状态后果 | P13B 分开聚类 | 因地点相同而强行合并 |
| R150-08 | 两条资产由同一场谈判行动兑现，参与者决策相互影响 | P13B 可同簇，P13C 分别推演各方选择 | 机械一资产一事件 |
| R150-09 | P13C 发现对手最合理选择会让预定反转无法发生 | 标记冲突/修订机会，不强迫对手犯蠢 | 以“剧情需要”覆盖人物决策 |
| R150-10 | 纯自然事件，没有有意行动主体 | P13C=NO_AGENT_DECISION_REQUIRED，P14A 按物理因果合成 | 虚构人物决策卡 |
| R150-11 | 重大决策人物没有有效 P05E/Profile 证据 | BLOCKED/CONDITIONAL 或先补 profile | 即兴补造人格 |
| R150-12 | 无资产、无已确认因果交互 | P13B NOT_APPLICABLE，不发起 LLM 调用 | 为提高事件数量生成空壳事件 |

`tools/validate_narrative_logic.py` 覆盖结构约束：阶段多对多归属、阶段唯一性、事件真实 driver、因果引用确认、主要决策者覆盖、选项选择与证据完整性。它不能判断人物是否“写得像活人”，也不能替代真实模型/读者审读。
