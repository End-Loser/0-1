## 实验目标

检验构想中的核心问题：在受控的封闭电磁结构中，多路编码电磁信号的组合能否通过物理演化形成**稳定、可重复、可编程的输入—输出映射**，并进一步承担加法、减法、乘法、逻辑或矩阵运算。

实验把总目标拆成可分别验收的子问题：

1. **数值层**：铜壁腔体的谐振频率、Q 值、端口响应和长时稳定性，能否在预先设定的误差内收敛并可重复。
2. **映射层**：线性加权、相位相减、固定矩阵乘向量等输入—输出关系，能否在仿真中保持定量一致。
3. **边界层**：非线性来源、真实端口与材料参数、器件模型、校准链和供能条件，如何限制上述结论。
4. **系统层**：把上述子项组合成一位 / 多位运算时，进位、级联、错误率和能耗是否仍可闭合。

本实验不把“某个子项通过”当作“整机完成”。七项整机验收门槛及其关闭条件见[全任务验收台账](ewc/EWC全任务验收台账.md)。

## 环境与复现步骤

### 软件与硬件环境

- 操作系统：Windows 11
- Python 3.11；NumPy 1.26.4、SciPy 1.17.1、Matplotlib 3.10.8
- 二维 FDTD：`flaport/fdtd 0.3.5`（MIT）
- 电路求解：`ahkab 0.18`（GPL-2.0）
- 三维电磁：openEMS（GPLv3）
- 器件与校准：ngspice 47（BSD-3-Clause）及厂商公开模型
- 计算资源：本机多核 CPU；长时算例曾按物理核绑定多进程运行

依赖清单见 [`开源FDTD验证/requirements.txt`](ewc/开源FDTD验证/requirements.txt)。openEMS、ngspice 和厂商模型需另行安装，仓库不分发这些组件。

### 复现入口

项目按验证方向组织，代表性命令如下：

```powershell
# 二维 FDTD 加法与基线验证
python 开源FDTD验证\run_stage2.py

# 三维 openEMS v1 仿真原型（20 例，四位码）
python openEMS验证\ewc_v1.py --out openEMS验证\EWC_v1仿真原型结果_复跑 --steps 30000 --workers 2

# 射频同轴端口基准
python 射频端口验证\run_coax_benchmark.py

# 介质材料适用性核查
python 材料验证\run_dielectric.py

# 校准时序与量化预算
python 校准验证\run_all.py
```

各子目录的报告给出了更细的命令、参数、预期输出和失败分支。建议先阅读对应报告的“结论 / 边界”小节，再运行脚本。

### 复现注意事项

1. **绝对路径**：原项目文档和部分脚本保留了原始 Windows 路径（如 `D:\work\...`、`E:\...`、`G:\...`）。复跑前需按本机目录调整；归档时未重新执行全部脚本。
2. **原始数据未入仓**：为控制体积并遵守第三方许可，`.npz`、`.csv`、`.cir`、`.raw`、日志、第三方数据手册 / PDF、厂商源码与可执行文件未纳入仓库。依赖归档波形或预计算锚点的 `verify_*` 脚本不能直接运行，需先用 `run_*` 脚本重跑生成。
3. **外部依赖**：部分器件验证依赖厂商 PSpice 工程、可执行模型或待审批工具；缺少这些输入属于“缺件”，不等于物理结论。
4. **长时算例**：六组 8 μs 长时窗算例需要数天到数周机时，归档时未全部完成。

## 实际结果、局限与已知反例

以下区分**事实**、**推断**与**未验证**。完整证据与逐项状态见[全任务验收台账](ewc/EWC全任务验收台账.md)；本节只做摘要。

### 事实（据归档记录，截至 2026-11-19）

- **v1 仿真原型**：20 例实跑（4 条单源基向量 + 全 16 组四位码，无抽样）。30000 步版的结果为：时域 16/16、频域 16/16 比特一致；时域最大解码残差 `2.55e-12`，频域最大解码残差 `6.17e-03`，跨域复尺度 `alpha = 1.06208 ∠ -88.77°`。12000 步版保留了步数敏感度对照（频域残差 `1.51e-01`）。
- **三维铜腔子项**：36×23×14 网格下，011 / 101 / 120 模式的频率与 Q 误差在 1% 内；011 细网格完整 8 μs 窗口通过 1% 判据（频率误差 0.188%、Q 误差 0.885%）。这些是**单个数值子项**，不是整机通过。
- **端口与边界反例**：9×9 理想响应矩阵满足互易、无源与功率闭合，但 50 Ω 端接时最好 `|S11| = 0.4409`，未达到匹配目标；柱高扫描走到 `nz-2` 仍未过零。
- **器件与校准缺口**：DAC 原库四种调用无波形；24 例 ADL 共模案例无合格 DC 点；PSpice for TI 申请待审；部分厂商模型不可执行。
- **整机状态**：七项主门槛 `full_system_gates_closed=0/7`，`goal_complete=false`。六组 8 μs 长时算例均未完成（归档记录时主例 25/80，两条 1.25 ps 各 8/80，两条 2.5 ps 各 4/80）。
- **硬件**：未制作样机，未进行实物测量。

### 推断

- 现有结果支持“受控电磁结构可以实现小规模、固定或可调的线性 / 模拟映射”，并给出了可复现的仿真路径。
- 现有结果**不支持**“已经实现通用数字计算机”，也不支持“比 CMOS 更快、更省电”这类系统级结论。
- 非线性、级联、进位恢复、扇出、存储与能效仍是未闭合环节。

### 未验证 / 未知

- 真实腔体、接头、介质批次和器件模型下的定量误差与重复性。
- 多输入级联后的错误率、延迟、抖动和整机能耗。
- 与数字基准在同任务、同精度、同输入输出口径下的对比。
- 长时窗与一般边界条件下，现有数值判据是否仍成立。

### 已知反例与边界

- 混合历史双窗 Q 差曾测到 `1.451% / 1.482%`，高于 1% 判据；四阶任意初态曾出现 `10.74% / 6.36% / 1.43%` 的偏差。这些失败记录保留在台账中，未通过事后修改阈值转为通过。
- v1 的“16/16”只说明在特定端口、负载、步数和离线判决下比特符号一致；不能外推为硬件可重复性或速度结论。

## 风险与局限

1. **研究阶段**：本项目是公开工作记录与仿真验证，不是经同行评议的结论，也不是官方认证或绝对真理。
2. **仿真—实物差距**：所有电磁结果均为数值结果；真实材料、加工公差、接头、温度漂移和测量链可能显著改变结论。
3. **可复现性边界**：原始波形与预计算锚点因体积未入仓；部分脚本依赖本机路径、openEMS、ngspice 和厂商模型。复现需要相应环境，不能只靠本仓库一键完成。
4. **文档性质**：归档包含内部执行记录、未发出的询证函草稿和未完成计划；它们用于保留证据与决策过程，不代表对外承诺。
5. **许可边界**：第三方依赖各自许可（含 GPL-2.0 / GPLv3）；再分发或商用前需自行核对。仓库不附带厂商模型、数据手册或工具安装包。
6. **误读风险**：子项通过、比特一致或局部 Q 误差达标，都不等于整机完成。引用时应同时引用边界与反例。
7. **安全与滥用**：本项目不涉及攻击、诈骗、破坏或绕过授权；若将电磁仿真用于其他目的，需自行评估合规与安全风险。
