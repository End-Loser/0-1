# 实验与复现说明

这里存放经审核后公开的实验、原型和复现说明。

提交前请阅读 [投稿与审核指南](../.github/CONTRIBUTING.md)，并提供：

- 对应想法或假设
- 目标、环境和硬件/软件依赖
- 数据来源、许可和脱敏情况
- 完整复现步骤与预期结果
- 实际结果、局限和已知反例
- 安全、隐私、偏差与滥用风险
- 作者、来源和适用许可

原型代码若独立维护，应在条目中提供稳定链接，并标明版本或提交号。

建议文件名：`topic-experiment-name.md`。
