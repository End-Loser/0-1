# 同轴端口归一化与参考面基准报告

日期：2026-11-18

## 1. 结论与范围

本线只写入 `射频端口验证/`，没有修改统一规划、openEMS、铜损耗、器件或介质线。
先读取了 `EWC真实材料与器件统一规划.md`、
`openEMS验证/物理端口基准与模型缺项后续报告.md` 和
`openEMS验证/电流分离与有限铜损耗基准报告.md`。

既有 50 Ω 是 PEC 平行板及 PMC 对称边界的 TEM 基础参考阻抗，不是 SMA 接头。
既有 25/50/100 Ω 电阻是线路中途的分流负载，不是本报告的终端负载。
历史贴边支路电流和铜薄片复数阻抗失败不被本线结果覆盖。

本批建立可执行的**数学均匀空气同轴**参考基准：

- 16 个径向静电 FEM 配置，14 个达到 C′/L′/Z0/v 的共同 1% 相对误差门槛，2 个粗网格失败保留。
- 复核器独立逐单元组装，完成另 16 次稀疏静电解，累计组装 1020 个径向单元。
- 287 个无损传输矩阵算例：7 个终端 × 41 个频点；每例 4 个参考面，共 1148 个参考面样本。
- 303 个原始 NPZ 文件哈希及数值证据复核通过，24 项测试全部通过，0 失败、0 跳过。
- 三维 3 GHz 馈电全波求解、铜损耗求解、实际 SMA 模型均为 **0**。

复核器的 16 次解是同一数学问题的独立组装交叉证据，不算新增物理配置；
测试内部的重复复核、参考面样本和哈希不累加成仿真次数。
`complete_physical_port_pass=false`：没有通过一般物理端口或真实器件联合验收。

## 2. 几何及材料假设标签

| 项目 | 定义 | 证据等级 |
|---|---|---|
| 内导体外半径 a | 0.500000 mm | 数学设计选择，不是厂商尺寸 |
| 外导体内半径 b | 1.151151858272 mm | 根据目标 50 Ω 设计，不是 SMA 实物 |
| b/a | 2.302303716544 | 均匀理想介质的数学比值 |
| 有限传输段长度 ℓ | 75 mm | 参考面示例，不是采购线缆 |
| 介质 | 理想均匀“空气”，εr=1、μr=1、σ=0，无损无色散 | **假设**，不是实际空气湿度/压力测量 |
| 导体 | 理想 PEC；不含导体内部电感、导电损耗及粗糙度 | **假设**，不映射 C11000 或任何牌号 |
| 同轴结构 | 完全同心、圆截面、轴向均匀，无接头过渡或开孔 | **数学基准** |

ε0=8.8541878128×10⁻¹² F/m，μ0=1.25663706212×10⁻⁶ H/m，
是脚本固定采用的 SI 常数数值；它们不是厂商材料参数。
未使用 PTFE、RT/duroid 5880、介质线的参数或其模型通过声明。
这里的“空气”只是 εr=1 的理想标签，不宣称实际介质模型已核查。

设计公式：

```text
η = sqrt(μ/ε)
b = a exp(2π × 50 Ω / η)
C′ = 2πε / ln(b/a)             [F/m]
L′ = μ ln(b/a)/(2π)            [H/m]
Z0 = sqrt(L′/C′)               [Ω]
v = 1/sqrt(L′C′)               [m/s]
```

解析值：C′=66.712819039629 pF/m，L′=166.782047599072 nH/m，
Z0=50.000000000000 Ω，v≈299792458 m/s。
通过阻抗公式选择 b 是设计，不是按 FEM 结果回调几何；FEM 不读取解析电势或 C′。
外导体厚度、内部支撑、螺纹和接缝未定义，不能导出可制造接头图纸。

## 3. V、I、方向及功率归一化

采用 `exp(+jωt)`、**峰值相量**。z=0 为源端，z=ℓ 为终端，
正电流为内导体沿 +z 向负载流动；外导体承担回流。
本报告所有截面 I 都保持此方向，不在负载处自动改为二端口“流入网络”方向。
以后形成多端口 S 参数时必须显式转换方向。

```text
V = φ(a)-φ(b) = ∫[a→b] Er dr            [V]
Er = -dφ/dr                             [V/m]
I = ∮ H·dl = 2πr Hφ                    [A]
Hφ = I/(2πr)                            [A/m]
P = 1/2 Re(V I*)                        [W]
P = 1/2 Re ∫[截面] (E×H*)·z_hat dA      [W]
```

磁场环路从 +z 方向观察为逆时针，在 a<r<b 内包围内导体、不包围外导体回流。
限定 TEM 下 Ez=0，横向截面位移通量为零，因此环量对应此轴向电流。
这不适用于接头过渡、有限面积支路探针或一般三维有纵向场的情况，
不能据此取消主线既有的位移电流分离。

实正参考电阻 R 下：

```text
V+ = (V+R I)/2,  V- = (V-R I)/2         [V]
a = (V+R I)/(2 sqrt(2R))                [sqrt(W)]
b = (V-R I)/(2 sqrt(2R))                [sqrt(W)]
|a|²-|b|² = 1/2 Re(V I*)                [W]
```

这里 a/b 是功率波，不是原有报告中单位 V·s 的脉冲傅里叶量。
若换成 RMS 相量应去掉分母中的 sqrt(2)，不能混用。
复参考阻抗的功率波定义不在本实现范围内，代码拒绝复数或非正参考电阻。

每个传输算例还使用静电 FEM 的分片 Er 和 TEM 的 Hφ 进行截面面积积分，
复核器逐径向单元重做 E×H 积分并与 VI 功率核对。
这是所选 TEM 场表示的归一化一致性，不是独立三维 Poynting 全波求解。

## 4. 独立径向静电 FEM 及 L′ 核对

解 φ(a)=1 V、φ(b)=0 V，内部无自由体电荷：

```text
∫[a,b] 2πε r φ′ w′ dr = 0
Ke = (2πε r_mid / Δr) [[1,-1],[-1,1]]
Q′ = 内边界离散反力                    [C/m]
C′ = Q′/(1 V)                          [F/m]
We′ = 1/2 Σ Ke_scalar (Δφ)²             [J/m]
C′ = 2We′/(1 V)²
```

运行器以三对角带状线性系统求解；没有把解析 log 电势填进内部节点。
复核器用单元 r 积分 `(r_right²-r_left²)/2` 重新组装稀疏全矩阵、
重新求解内部电势，并检查离散 Gauss、等量异号导体电荷、通量、电场线积分和能量。
解析电势只用于事后节点电势误差检查。

L′ 不用 `με/C′` 反推，而用 1 A 下的 Hφ 从磁能积分得到：

```text
L′ = ∫[a,b] μ |Hφ|² 2πr dr / (1 A)²
   = ∫[a,b] μ/(2πr) dr
```

运行器用端点梯形积分，复核器显式累加磁能密度端点权重。
Hφ 使用均匀理想同轴的安培解析表达式，所以这不是独立磁静态 PDE 求解器。
L′ 的积分误差与 C′ 的静电离散误差分别保留，再求 Z0/v。
静态 1 V/1 A 储能为 C′/2、L′/2；峰值正弦的时间平均储能则为 C′|V|²/4、
L′|I|²/4，不把静态储能直接当成平均功率。

两种网格：均匀径向网格，以及 `r=a+(b-a)t^1.5` 内侧加密网格。
各用 2/4/8/16/32/64/128/256 单元；完整结果和失败标志均存入 summary。
代表性相对误差如下，所有数值单位为 **%**：

| 网格/单元 | C′ | L′ | Z0 | v | 四量共同 1% |
|---|---:|---:|---:|---:|---|
| 均匀/2 | 1.618197 | 3.290641 | 0.819547 | 2.392369 | 失败 |
| 内侧加密/2 | 1.480072 | 2.998006 | 0.745122 | 2.187309 | 失败 |
| 均匀/4 | 0.422508 | 0.849106 | 0.212177 | 0.631567 | 通过 |
| 均匀/16 | 0.026827 | 0.053672 | 0.013418 | 0.040233 | 通过 |
| 均匀/64 | 0.001678 | 0.003357 | 0.000839 | 0.002518 | 通过 |
| 均匀/256 | 0.000104910 | 0.000209820 | 0.000052455 | 0.000157365 | 通过 |
| 内侧加密/256 | 0.000097410 | 0.000194820 | 0.000048705 | 0.000146115 | 通过 |

两个 2 单元例虽 Z0 单项通过，C′/L′/v 未通过，不按阻抗单项掩盖失败。
两种网格的四量误差随细化单调减小；这只表示一维径向基准收敛，
不代表三维接头网格、传播时间步或系统有效系数预算已收敛。
最大内部 Gauss 相对残差约 7.94×10⁻¹³ 是方程一致性，不是物理误差。

## 5. 终端、参考面移动及源功率

传输矩阵使用均匀/256 的**数值**参数：
Zc=50.000026227491 Ω，v_num=299791986.232654 m/s。
不是暗中改回解析 50 Ω 来消除数值失配。

源为 1 V 峰值理想 Thevenin 源，Rs=50 Ω；
负载为 25、50、100、50+j25、5+j100 Ω，以及开路、短路。
它们都是线段末端边界，不是分流元件。频点为 2.5～3.5 GHz 的 41 点，
只检查此离散频率集合，不声称连续全带或任意瞬态保证。
参考面位于 z=0、15、45、75 mm；75 mm 面采用终端的线路侧定义。

```text
β = 2πf/v_num
[V(z);I(z)] = [[cos βd, jZc sin βd],
               [j sin βd/Zc, cos βd]] [VL;IL],  d=ℓ-z
V(0)+Rs I(0) = Vs
ΓL = (ZL-Zc)/(ZL+Zc)
Γ(z) = ΓL exp[-2jβ(ℓ-z)]
Γ(z+Δz) = Γ(z) exp(+2jβΔz)
```

反射相位是往返传播，不能使用一次传播相位或错误符号。
开路 ΓL=+1、短路 ΓL=-1；不以除零电流来求开路阻抗。
复核器不调用运行器的传输矩阵，而用独立前后行波基底解 Thevenin 方程，
核对每面 V/I、反射幅度、往返相位、去嵌入及负载构成关系。

归档同时保存以 Zc 定义的特性功率波和固定 50 Ω 仪表功率波。
纯相位移动公式适用于特性波；若 Rref≠Zc，固定 50 Ω 的 b/a 不能无条件按纯相位移动。
测试另用 Zc=75 Ω 的数学负向对照显露这个错误，不能将此对照误称厂商模型。
50 Ω 源和负载相对 Zc 有约 2.62×10⁻⁷ 的反射幅度，不强行标为严格零反射；
严格 Zc=50 Ω 的匹配与零长度极限另有测试。

独立功率账目：

```text
Psource = 1/2 Re(Vs I(0)*)
PRs = Rs |I(0)|²/2
Pload = Re(ZL) |IL|²/2
Psource = PRs + Pload
Pavailable = |Vs|²/(8Rs) = 2.5 mW
```

无损线路各面净功率相同，负载功率非负且不超过可用源功率；
开路/短路净负载功率为零。50 Ω 终端的负载功率约 2.5 mW。
严格匹配源总生成 5 mW，其中 2.5 mW 在源串联电阻、2.5 mW 在负载；
理想源生成的 RF 功率不是放大器 DC 耗电或整机能耗。

独立复核最大值：ABCD 与行波 V/I 数值绝对差约 3.87×10⁻¹⁴，
反射参考面移动绝对差约 7.32×10⁻¹⁴，
波功率/源账目绝对差约 4.28×10⁻¹⁸ W。
V/I 混合数组差仅是数值一致性统计，不能赋予一个共同物理单位或解释为硬件精度。
上述机器精度结果不是系统 ±1% 的物理验收。

## 6. 厂商几何及后续缺项

按用户优先级，本批不搜索实物 SMA 模型，不因没有模型阻塞数学基准。

| 项目 | 当前标签 | 后续需要 |
|---|---|---|
| 实际 SMA 厂家/型号/版本 | 未选择、未取得 | 型号对应的正式尺寸及适用频率 |
| 内针/外导体/螺纹与配合参考面 | 缺失 | 完整截面、装配公差和厂商参考面定义 |
| PTFE/其他介质支撑及间隙 | 缺失，不能用本线 εr=1 填补 | 频率相关材料依据与实际几何 |
| 探针、焊盘、腔壁开孔及过渡 | 缺失 | 三维馈电模型、模式转换及辐射/互耦 |
| 厂商 STEP、全波几何或 S 参数 | 未取得、未仿真 | 来源、许可、版本、哈希及负载适用性 |
| 导体损耗与温度 | 本线明确不做 | 由铜损耗/材料主线处理及后续联合 |
| 一般端口与负载反馈 | 未通过 | 纵向场、位移电流、实际负载及因果联接 |
| 高阶模式和截止频率 | 未计算 | 不能将单 TEM 传输矩阵当成模态验收 |

静电 C′ 和单模无损线路的 3 GHz 参数计算**不等于** 3 GHz 馈电、辐射、
实际 SMA 性能或完整计算腔体验证。没有求解三维 Maxwell、高阶模式、
接头过渡、任意宽带瞬态、源启动及非线性器件反馈。
本线不采购、不冻结 BOM，也不报告硬件计算速度。

## 7. 文件、测试与复现

- `run_coax_benchmark.py`：径向 FEM、磁能积分和传输矩阵运行器。
- `verify_coax_benchmark.py`：独立稀疏组装、行波、面积功率及哈希复核器。
- `test_coax_benchmark.py`：24 项测试，包括 7 项证据篡改拒绝测试。
- `结果/summary.json`：几何、假设、常数、每例物理误差/标签和文件 SHA-256。
- `结果/verification.json`：独立复核计数、残差及数值差。
- `结果/tests.json`：测试数量、状态与源码/summary 哈希。
- `结果/radial_*.npz`、`结果/line_*.npz`：303 份可重新复核的原始数值归档。

环境：Python 3.11.9、NumPy 1.26.4、SciPy 1.17.1。
没有安装新依赖、修改系统策略或调用外部电磁求解器。
运行中间 NPZ 和测试篡改副本使用 `%TEMP%/ewc-coax-*`，
最终证据复制进本线目录；临时目录正常结束时清理，复核不依赖缓存存活。
使用 `-B` 不产生项目 Python 字节码缓存。

在项目根目录重建，再复核：

```powershell
python -B "射频端口验证/run_coax_benchmark.py"
python -B "射频端口验证/verify_coax_benchmark.py"
python -B "射频端口验证/test_coax_benchmark.py"
```

只复核现有交付时执行后两条命令即可。
运行器退出 0 表示计算和归档完成，不表示所有粗网格物理误差通过；
复核器退出 0 表示证据一致且失败标签真实保留，不表示失败被转为通过。
测试的 7 项证据负向对照分别拒绝：伪造粗网格通过、放宽阈值、
虚报完整端口通过、删除算例、原文件哈希变化、
改电流方向后重算哈希、改峰值功率系数后重算哈希。
源码更改后需重跑运行器，以更新 runner 的来源哈希。
