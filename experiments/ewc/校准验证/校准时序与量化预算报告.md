## 3. 8次读数、平均及暂停时序

基线假设一个ADC、8个不同的已知探测点，逐点顺序采集。
每点保留 `m` 次读数，可另丢弃 `d` 次；总转换数 `N=8(m+d)`。
8个探测点不是已验收的最终训练序列，也不意味着8个真值状态验收。
对不同探测点不能直接使用 `sqrt(8m)` 噪声平均收益；相同探测点仅按 `m` 平均。

吞吐下界按完整转换槽计数：`T_ADC=N/f_s`，不是用7个间距代替8次转换。
`f_s<=100000 Hz`；8次转换对应80 μs，为旧640 ns理想训练时间的125倍。

本批采用保守串行、不给SPI重叠收益的显式预算：

```text
T_pause =
  pause_ack + switch_cal
  + 8*(probe_settle + mux_settle)
  + 8*(m+d)*(1/f_s + adc_transfer)
  + solve
  + updates*(dac_transfer + 5us_candidate + gain_settle)
  + switch_run + restore
```

不是把最高100 kSPS当成真实前端必能达到的采集速度。
ADC串行时间独立相加可能比允许重叠的实际接口更保守，但没有证明相加后的示例一定足够；
真实启动、采样获取、参考建立、实际开关/滤波、负载、主机延迟仍需验收。
5 μs仅来自候选产品页，本预算不是厂家最坏时间边界。

### 显式时间假设

除 `unknown_lower_bound` 外，基础示例的假设如下，单位均为μs：

| 参数 | 值 | 参数 | 值 |
|---|---:|---|---:|
| pause_ack | 2 | switch_cal | 3 |
| probe_settle，每点 | 4 | mux_settle，每点 | 1 |
| adc_transfer，每转换 | 1.6 | solve | 6 |
| dac_transfer，每更新 | 2.4 | gain_settle，每更新 | 3 |
| switch_run | 3 | restore | 4 |

`updates=1`、`d=0`、`f_s=100 kSPS`。这些时间全部是合成设计输入，
不是已选MCU、开关、SPI帧或实际增益控制器的测量值。实际需要多少参数更新也未冻结。
`unknown_lower_bound` 的10项开销均为 `null`，仅为计算下界按零贡献，
输出仍保留全部缺项，不能升级为完整时序。

### 实际运行数值

`T_active` 表示两次校准之间真正计算的有效运行时间。
`P_start` 表示相邻校准开始时刻间隔；两个口径是独立配置，不把同一数值解释为同一种周期。

```text
暂停比例（有效运行口径） = T_pause/(T_active + T_pause)
暂停比例（开始到开始口径） = T_pause/P_start，仅当 T_pause<P_start
要求暂停比例 <= p 时：T_active >= T_pause*(1-p)/p
```

| 算例 | 转换数 | 暂停μs | T_active=10 ms的暂停比例 | P_start=10 ms的暂停比例 | 1%暂停所需T_active至少ms |
|---|---:|---:|---:|---:|---:|
| unknown_lower_bound | 8 | 85.0 | 0.842836% | 0.850000% | 8.4150 |
| assumed_m1 | 8 | 161.2 | 1.586427% | 1.612000% | 15.9588 |
| assumed_m4 | 32 | 439.6 | 4.210889% | 4.396000% | 43.5204 |
| assumed_m16 | 128 | 1553.2 | 13.443894% | 15.532000% | 153.7668 |
| discard_two_each_point | 24 | 346.8 | 3.351761% | 3.468000% | 34.3332 |

85 μs是80 μs采集加一次候选5 μs等待的“缺项下界”，不是保证值。
`short_recalibration_period` 的128次转换暂停1553.2 μs，超过1 ms开始间隔，
输出 `start_to_start_feasible=false`，对应比例为 `null`，不报告负有效运行时间或伪可行周期。
`synthetic_bounded_budget` 另设有效运行20 ms，暂停比例为0.799556%，仍是合成假设。
未计启动、故障恢复、监测读数占用与能耗，也未证明任何重校准触发间隔足以控制真实漂移。

## 4. 粗调舍入与细调必要条件

最近码舍入、0.5 dB理想步进的最坏半步为0.25 dB：

```text
正向幅度误差 = 10^(0.25/20)-1 = 2.920052719%
负向幅度误差 = 1-10^(-0.25/20) = 2.837204842%
```

仅粗调就超过±1%任意目标幅度舍入预算；这不是实测增益误差或逻辑误码率。
细调若分配相对幅度舍入预算 `epsilon`，其最大均匀dB步进必须满足：

```text
Delta_g_dB <= 40*log10(1+epsilon)
epsilon=1%：Delta_g_dB <= 0.1728549513 dB
epsilon=0.2%：Delta_g_dB <= 0.03470886125 dB
```

本次细调仅假设在整个控制范围内的仿射对数增益：
`g_dB(V)=k*(V-V_center)`，`k` 是显式输入的斜率幅值，不是任何器件的实际传递函数。
理想 `q_DAC=V_span/2^16`；最大码为 `V_span-q_DAC`，不把最大码当成满量程端点。
还需检查以中心电压为基准的两侧可达修正均至少0.25 dB。
分辨率合格但范围不够仍失败；真实非线性、单调性及相位耦合尚未知。

```text
细调最坏舍入 = 10^(k*q_DAC/40)-1
b_min = max(1, ceil(log2(V_span*k/[40*log10(1+epsilon)])))
```

| 合成输入 | 理想LSB | 舍入幅度误差 | 0.2%分配下最小位数 | 覆盖粗调残差 |
|---|---:|---:|---:|---|
| 2.5 V、1 dB/V、中心1.25 V | 38.146972656 μV | 0.000219592% | 7 | 合格 |
| 2.5 V、20000 dB/V | 同上 | 4.489700974% | 21 | 合格，但舍入失败 |
| 2.5 V、0.1 dB/V | 同上 | 0.000021959% | 3 | 不足，单侧约0.125 dB |

“7位/21位”仅是指定合成斜率和预算下的舍入必要条件，不是器件精度或采购建议。
首次测试误把陡斜率的预期写成20位，独立计算发现应为21位。
仅修正测试预期，公式/候选参数未改；原失败和原因保留在 `测试修订记录.json`。

## 5. ADC输入范围、噪声与有效系数传播

17项量化/误差参数均显式保存，未知为 `null`；不由16位或产品页SNR自动推导精度。
基础示例输入为2.5 V跨度、输入0.5～2.0 V、范围保护余量10 mV；
对单极性、单端且已完成调理的输入检查，保守上限为 `span-LSB`。
有符号IQ/差分转换、共模与实际参考范围仍缺，不能将负RF幅度直接接入这个单端范围假设。

| 参数组 | 基础合成示例 | 真实链路状态 |
|---|---|---|
| ADC跨度/输入最小最大/余量 | 2.5 V / 0.5～2.0 V / 0.01 V | 未冻结 |
| 单次噪声标准差sigma / 等相关rho | 1 mV / 0 | 未测量；rho仅覆盖0～1等相关假设 |
| 硬噪声边界 | 3 mV | 独立合成输入，不由“3sigma”生成硬保证 |
| ADC到相对有效系数敏感度 | 2 /V | 合成直接敏感度，实际训练传递/条件数未知 |
| DAC跨度/斜率幅值/中心 | 2.5 V / 1 dB/V / 1.25 V | 未验收实际增益传递 |
| 细调舍入分配 | 0.2% | 子预算，不是各环节均可用1% |
| ADC偏置/INL/参考输入等效误差 | null / null / null | 缺项 |
| DAC静态电压误差/其他有效系数误差 | null / null | 缺项 |

按相同探测点的等相关噪声假设：

```text
sigma_mean = sigma*sqrt([1+(m-1)*rho]/m)
理想ADC量化相对系数边界 = (span/2^16)/2 * sensitivity_per_V
硬噪声相对系数边界 = noise_bound_V * sensitivity_per_V
```

基础示例理想ADC半LSB传播为0.003814697%。
`m=1/4/16, rho=0` 时，平均标准差分别1/0.5/0.25 mV，
相对系数标准差分别0.2/0.1/0.05%。这是标准差，不是最坏保证。
`rho=1, m=16` 时仍为1 mV、0.2%；硬噪声边界均为0.6%，不因平均缩小。
没有假设抖动/独立量化误差，量化、偏置、INL及参考误差也不按sqrt(m)缩小。

`adc_overrange` 输入最大2.6 V，超出假设跨度，明确失败。
`small_signal_high_sensitivity` 设敏感度10000 /V，半LSB相对传播为19.073486%，
说明小信号与训练条件数可完全主导位数收益。该例未设ADC分配门槛，只输出传播数值，
不能以细调舍入通过或16位为理由认为采集误差合格。

另一个 `synthetic_bounded_budget` 显式人为补入ADC偏置10 μV、INL20 μV、参考10 μV，
DAC静态30 μV及其他有效系数0.2%。这些**不是器件规格或测量结果**。
以硬噪声边界、量化及这些输入做乘积上界传播，算得0.813607901%。
这只演示公式，绝不作为系统±1%通过证据；基础示例的综合边界仍为 `null`。
这里假设直接有效系数敏感度；真实校准的反演、比值、矩阵条件数和训练激励误差未实现。

## 6. 限定校准控制状态验证

正常事件顺序如下：

```text
RUN -> PAUSE -> SWITCH_CAL -> PROBE_SETTLE -> MEASURE
    -> SOLVE -> DAC_SETTLE -> SWITCH_RUN -> RESTORE -> RUN
任意状态可 fault -> FAULT；FAULT只能 reset -> PAUSE，再完成校准后恢复
```

运行态仅接受数据事件、校准请求及故障；程序参数版本只能在SOLVE的program事件更新。
测量数必须恰为8m；7次就求解、额外第9次读数、运行中编程、暂停中数据、
早于等待截止的建立/恢复、短于5 μs的候选DAC等待、故障后直接resume和时间倒退均拒绝。
拒绝事件不改变状态、参数版本、读数或时间。
两条归档名义轨迹覆盖m=1/4，测试另覆盖m=16与8个运行输入标签的冻结。
输入标签只是协议测试，不执行A+B、不按正确答案调参，也不是8真值全加器验收。

控制轨迹采用标量时间、一次初始探测等待和读数计数，与完整预算算例分开：
**不是161.2 μs串行预算的逐边沿硬件实现**。
尚未强制逐点开关/丢弃样本、ADC真实转换完成/SPI握手，也没有实际训练求解器；
名义读数间隔按10 μs单独核对，任意合法read事件的最短采集间隔尚未在控制类中强制。
状态版本是参数冻结代理，不是DAC寄存器、RTL、CDC、亚稳态、毛刺或复位电路模型。
