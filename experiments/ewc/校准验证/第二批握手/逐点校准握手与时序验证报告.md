## 2. 来源与显式时间

先读取统一规划、第一批时序量化报告及 `model.py` / `verify.py`。
本批 `provenance.json` 固化只读来源SHA-256，运行时仅读取本批文件；
整体目录可搬移，不要求第一批目录或主规划继续存在。
主规划后续被其他线更新不影响本批历史来源哈希，不在运行时重新绑定该文件。

复用第一批归档的官方产品页参数，没有新抓网页、下载数据手册或模型：

| 参数 | 本批用途 | 不代表 |
|---|---|---|
| ADS8866最高100 kSPS | `fs <= 100000`，请求至少分配完整10 μs槽 | 实际 `tCONV`、CONVST/DOUT波形或采样保持时序 |
| DAC80501候选5 μs | 对齐首批的显式 `dac_settle_ns=5000` 示例 | 指定负载、阶跃和误差带下的最坏建立保证 |

协议使用整数纳秒。对指定采样率：

```text
rate_slot = ceil(10^9 / fs) ns
effective_slot = max(rate_slot, adc_ready_ns)
```

`adc_ready_ns` 是另一个必须显式提供的软件完成等待输入，
示例10000 ns仅是合成服务时间，不是核对得到的真实ADS8866转换时间。
转换完成事件只能在整个分配槽结束后被软件接受；真实器件较早完成也不计重叠收益。
SPI等待从 `read_start` 起独立计时，不解释为任何已经冻结的SPI频率、帧长或主机时延。

对齐配置所有合成输入如下，单位μs：

| 输入 | 值 | 输入 | 值 |
|---|---:|---|---:|
| pause_ack | 2 | switch_cal | 3 |
| probe_settle，每点 | 4 | mux_settle，每点 | 1 |
| adc_ready，每转换 | 10 | adc_spi，每转换 | 1.6 |
| solve | 6 | dac_spi，每更新 | 2.4 |
| dac_settle，每更新 | 5 | gain_settle，每更新 | 3 |
| switch_run | 3 | restore | 4 |

`m>=1`、`d>=0`、`updates>=1`，默认 `m=1,d=0,updates=1,fs=100000`。
12项硬件相关时间都允许输入 `null`；预算仅将未知项按零贡献计算并保留缺项列表，
控制器拒绝执行任何含未知项的配置。不把“未知”默认为硬件零延迟。

## 3. 软件协议

正常流程：

```text
RUN --request--> PAUSE --ack--> SWITCH_CAL --cal_ready--> SELECT
对point=0..7逐点：
  select(point) --> SETTLE --settled--> READY
  每次转换：
    adc_request(point,token) --> ADC_BUSY
    adc_done(point,token) --> ADC_DONE
    read_start(point,token) --> READING
    read_done(point,token,value) --> READY或POINT_DONE
最后一点完成：
  solve --> PROGRAM
  每次参数更新：
    program(update,code) --> DAC_BUSY
    dac_done(update) --> DAC_WAIT
    dac_settled(update) --> 下一更新或SWITCH_RUN
  run_ready --> RESTORE --resume--> RUN
```

约束：

- 点号严格为0至7，不允许跳点、重选同点或回退。每个点都有独立的探测与mux串行建立等待。
- 每点恰好先丢弃 `d` 次，再保留 `m` 次。丢弃样本仍必须完成转换和SPI读取，计入时间。
- 只允许一个ADC事务在途。ADC请求使用全局单调递增token，故障/重校准不重置token。
- 完成、读取开始和读取结束必须匹配当前点及当前token；禁止无请求读取、提前读、重复完成和跨点旧样本。
- 样本为0至65535的整数码；保留样本分8个独立数组，不跨点平均。
- 最后一点完成且8个数组均具有 `m` 个样本后才能求解。此处只有求解等待，没有实际训练反演算法。
- 每次DAC更新必须经历完整SPI传输，再等待 `dac_settle + gain_settle`；多个更新完全串行。
- `parameters` 和版本只有在所有更新、切回及恢复完成的 `resume` 才提交。
  运行态仅允许输入标签、校准请求或故障，不能按输入另调参数。
- 拒绝非法事件不修改时间、截止点、样本、事务、状态、版本或参数。
- 故障使控制器进入 `FAULT`，清除采集样本、在途ADC与待提交参数；
  只能 `reset -> PAUSE` 后完整重校准才能恢复。故障不会回滚真实DAC硬件，本批也未建该硬件。

事件时间不能倒退，所有等待均接受“等于截止点”，拒绝提前1 ns。
允许合法事件较晚到达，实际暂停随之增加，不宣称固定预算是实测上界。
`data` 的0至7标签只测试运行参数冻结，不计算A+B，也不是全加器真值验收。

## 4. 名义事件与串行预算

预算直接对应事件时间：

```text
N = 8*(m+d)
T_pause =
  pause_ack + switch_cal
  + 8*(probe_settle + mux_settle)
  + N*(effective_slot + adc_spi)
  + solve
  + updates*(dac_spi + dac_settle + gain_settle)
  + switch_run + restore
```

名义轨迹的 `resume.time_ns - request.time_ns` 必须与独立预算精确相等。
不给跨点建立、ADC/SPI或DAC更新任何重叠收益。

默认名义轨迹的关键时刻，单位μs：

| 事件 | 时刻 |
|---|---:|
| request / ack / cal_ready | 0 / 2 / 5 |
| 点0 select / settled / adc_request | 5 / 10 / 10 |
| 点0 adc_done / read_start / read_done | 20 / 20 / 21.6 |
| 点1 select / settled / adc_request | 21.6 / 26.6 / 26.6 |
| 点7最后read_done / solve | 137.8 / 137.8 |
| program / dac_done / dac_settled | 143.8 / 146.2 / 154.2 |
| run_ready / resume | 157.2 / 161.2 |

| 配置 | 转换数 | 暂停μs | 与首批关系 |
|---|---:|---:|---|
| m1 | 8 | 161.2 | 相等 |
| m4 | 32 | 439.6 | 相等 |
| m16 | 128 | 1553.2 | 相等 |
| 每点丢弃2、保留1 | 24 | 346.8 | 相等 |
| m4、d2、3次DAC更新 | 48 | 646.0 | 扩展示例 |
| fs=33333 Hz | 8 | 321.208 | 向上取整槽30001 ns |
| adc_ready=20 μs | 8 | 241.2 | 显式较慢输入扩大暂停 |
| 全部时间未知 | 8 | 80.0下界 | 禁止执行 |
| 仅候选DAC等待5 μs，其余未知 | 8 | 85.0下界 | 与首批unknown相等，禁止执行 |

8次分配槽下界仍为80 μs，不使用7个间距替代8次转换。
1%暂停的有效运行口径为 `T_active >= 99*T_pause`；
默认配置对应至少15.9588 ms，不是重校准漂移可行性或硬件性能保证。
启动、监测占用、故障恢复、主机调度和完整供能不包含在周期暂停预算中。

## 7. 真实硬件缺项

尚缺ADS8866具体数据手册版本及适用模式下的获取/转换时间、CONVST脉宽、
SCLK频率与边沿、输出有效/建立保持、串行接口连接及跨时钟同步；
缺实际输入驱动、复用开关、滤波、参考稳定和历史残留测量。
必须测定所有显式输入，不能用100 kSPS自动补出这些细节。

尚缺DAC负载、阶跃、误差带、真实建立/增益恢复、SPI与锁存更新方式，
以及部分更新后发生故障时的硬件安全状态。
本批DAC事件不含跨周期事务token，也不模拟延迟中断重标时间后的硬件身份；
真实实现需增加更新代次/确认机制，不能直接把本软件事件搬成ISR或RTL。

尚缺实际训练公式、有效系数敏感度、细调传递/范围/相位、
真实采集误差、冻结寄存/电平接口、失锁/过载/超时检测与安全输出。
本协议的故障是外部显式输入，不是自动检测；无自动看门狗时限保证。
延迟或未到达事件不会自动恢复运行。

事件token只证明软件标签不跨点，不证明模拟前端没有跨点残留；
合法范围内的错误ADC值也不能被握手校验识别。
软件参数数组冻结不等同于真实DAC输出、RF幅相或硬件寄存器冻结。
RTL、CDC、毛刺、亚稳态、复位电路、真实器件模型和完整系统联合验收仍未开展。
