# EWC 系统实现可行性分析

分析对象：《构想.md》  
分析日期：2026-11-17  
定位：基于电磁学、材料与器件技术的工程评估，不是已经完成的实验验证或专利新颖性结论。

## 一、结论

**核心构想具有物理基础，但目前更接近“可编程电磁波模拟计算器或物理计算加速器”，尚不足以构成通用数字计算机的完整方案。**

最值得保留的是：让受控电磁结构直接实现输入到输出的计算映射，通过调节边界、材料或器件参数改变任务。最需要补足的是：编码定义、非线性来源、输出判据、存储与反馈、可编程自由度以及系统级成本。

具体判断：

| 目标 | 实现判断 | 必要条件 |
|---|---|---|
| 稳定、可重复的电磁输入输出关系 | 高可行性 | 相干输入、稳定边界、端口校准、温度控制 |
| 加权求和、减法、滤波、固定矩阵乘向量 | 高可行性 | 合适的传输函数、相位与幅度控制、相干检测 |
| 可编程的小规模矩阵乘向量 | 有明确技术路径 | 足够独立的调谐自由度，满足无源网络约束 |
| 两个动态输入的模拟乘法 | 有条件可行 | 混频器、非线性介质或其他双线性机制 |
| 单级布尔逻辑与小位宽加法 | 有条件可行 | 适当编码、判决、偏置或非线性，明确读出边界 |
| 大位宽精确数字算术、可靠级联 | 高难度 | 电平恢复、增益、扇出、进位、同步、低错误率 |
| 时序预测与分类 | 与构想较匹配 | 非线性储备池、短期记忆、训练后的读出 |
| 通用计算机及存储系统 | 当前方案不充分 | 存储、可寻址状态、指令控制、通信与纠错架构 |
| 比 CMOS 更快、更省电 | 不能由构想推出 | 必须比较同任务、同精度、含输入输出的实测结果 |

**建议第一步做微波实验平台，优先验证线性变换，再验证非线性；不建议把八位数字加法器作为首个核心突破目标。**

## 二、构想中的关键物理边界

### 2.1 波叠加不等于波之间发生非线性作用

原文第 16、66 行提到多波相互作用与非线性。需要把两个机制分开：

- 在线性、静态介质中，多个电磁场满足叠加原理。干涉改变场强分布，但不会仅凭“复杂腔体”产生新的频率或任意逻辑规则。
- 模式耦合可以是线性的，例如由边界或散射体造成的能量交换。
- 非线性需要场强相关的材料响应、非线性电路器件或受信号驱动的调制机制。

线性系统的一般形式是：

```text
y_i(t) = Σ_j ∫ h_ij(τ) x_j(t-τ) dτ
```

单频稳态下：

```text
b(ω) = S(ω, θ) a(ω)
```

其中 a、b 是端口复波幅，θ 是几何、偏置、开关状态等配置参数。改变腔体形状，可以改变 S，但不能因此突破线性。

因此，金属箱、空气和普通低功率线性介质的组合，天然适合线性计算，不会自动成为数字乘法器或进位网络。

### 2.2 探测器也可能承担非线性

平方律探测得到：

```text
I ∝ |E1 + E2|²
  = |E1|² + |E2|² + 2 Re(E1 E2*)
```

这里的交叉项可用于相关测量与特定逻辑编码。但非线性来自探测过程，而不是线性空间中的光波或微波自行改变了彼此。

这不是“无效计算”。关键是诚实定义计算边界：如果探测器参与平方、阈值判断或反馈，就应将它列为计算器件，而不仅称为透明读出。

频率不同的信号还需注意探测带宽：交叉项可能表现为拍频，也可能被时间平均消除。

### 2.3 “输出可重复”只是必要条件

固定滤波器、衰减器甚至一段电缆都有可重复的输入输出关系。要证明目标计算，还必须说明：

- 输入数据如何映射成波形；
- 输出物理量如何映射成结果；
- 结构是否固定，是否对每个输入单独调整；
- 是否覆盖足够大的输入域；
- 是否在独立测试集和扰动条件下有效；
- 外部软件是否实际承担了目标运算。

“复杂”和“计算能力强”不能画等号。几何上的波混沌通常是线性传播路径复杂化，不等于非线性材料动力学，也不意味着随机或不可重复。

### 2.4 封闭空间是可选架构，不是计算的必要条件

腔体实际需要输入端口、输出端口及控制引线，是受控的开放耗散系统，而非完全封闭、无损的空间。

屏蔽腔体的优点是抑制外界干扰、形成多径与共振；缺点是可能增加等待时间、残留状态和参数敏感性。波导网络、微带网络、干涉器网格也能实现同类计算，不必坚持所有功能都在一个封闭箱体中完成。

## 三、逐项运算能怎样实现

### 3.1 加法与减法：先区分模拟数值和数字位串

若输入 A、B 编成同频、同相的电场幅度，系统可以实现：

```text
y = k(A + B)
```

k 包括合路、耦合与损耗系数；无源合路器不能无条件复制输入能量。相位改变 180 度可实现符号反转，从而构造：

```text
y = k(A - B)
```

读取有符号结果需相干接收或其他保留符号的编码。只测功率会丢失符号。

原文的例子正确：

```text
01010101 = 85
01011001 = 89
85 + 89 = 174 = 10101110
```

但这个例子没有指定编码，因而无法确定其硬件要求。

**路线 A：整个整数对应一个模拟幅度。** 输入幅度对应 85、89，叠加后对应 174，ADC 输出二进制表示。此时目标求和确实可由波结构完成，ADC 负责量化与表示；不能简单断言它必须有内部逐位进位电路。不过它是模拟算术，精度随位宽增长会变得苛刻。

两个无符号八位输入的完整和域是 0 至 510，需要九位输出或明确约定模 256。若采用单幅度编码，要可靠区分 511 个结果等级，并将总误差控制在判决裕量内，不能只验证 174。

**路线 B：每一位对应独立时间槽、频率或端口。** 此时单纯叠加得到的逐位场响应不会自动成为带进位的结果，需要设计位间信息传递。

一位全加器需要：

```text
Sum = A XOR B XOR Cin
Cout = (A AND B) OR (A AND Cin) OR (B AND Cin)
```

这种路线适合研究真正的位级数字算术，但还需研究级联、时序和电平恢复。

### 3.2 乘法：固定权重乘法和双输入乘法不是一回事

线性传输中的 y = w x 可以完成“输入乘固定权重”。这正是矩阵乘向量的基础。

若 A、B 都是本次计算的动态变量，目标 y = A B 则不是关于联合输入的线性映射。可用微波混频器实现：

```text
v1 = A cos(ω1 t)
v2 = B cos(ω2 t)
v1 v2 = AB/2 × [cos((ω1-ω2)t) + cos((ω1+ω2)t)]
```

滤出和频或差频分量，其幅度在适当工作区间内与 AB 成比例。

工程上必须测量乘法线性度、偏置、端口隔离、寄生谐波与压缩效应。普通通信混频器不一定在任意输入范围都能当精密双变量乘法器，尤其当一个端口进入开关式强本振工作区时。

若用 B 实时调整权重再输入 A，仍可实现乘法，但 B 的写入时间、DAC 和控制电路必须计入，不能称为两个输入波在固定腔体内同时直接相乘。

### 3.3 逻辑：单级演示有路径，级联需要更多条件

可探索的机制包括相干干涉加阈值、二极管响应、双稳态谐振器及探测反馈。

例如，相等幅度的开关键控输入采用相反相位，差分端口的场可近似表示 A-B。平方探测后，01、10 为高，00、11 为低，可形成 XOR 判据。

这个例子依赖幅度匹配、相位稳定和判决器，并不证明腔体实现了通用逻辑。NAND、NOT 等还需要明确参考能量、偏置及输出编码。

要级联，需要验证：

- 输出是否能直接驱动下一单元；
- 输入小扰动是否被恢复，而不是逐层放大；
- 是否有足够的增益、扇出与级间隔离；
- 00 状态下需要高输出的门，其能量从何处来；
- 多级传播的总错误率与时序裕量。

布尔通用性并不要求严格的同一种非线性材料，但它要求整体系统存在足够的非线性判决和状态恢复。纯线性传播加纯线性读出不能完成一般布尔计算。

### 3.4 矩阵计算：最适合作为第一项核心任务

N 路相干输入与 M 路输出可实现：

```text
y_i = Σ_j W_ij x_j
```

复数权重由幅度与相位共同表示，负实权重可通过相位反转表示。

但“有多个端口”不代表“能编程任意矩阵”。无源结构在功率归一化下满足能量约束，完整散射矩阵满足 S†S ≤ I；互易结构的完整散射矩阵还满足相应对称关系。注意，输入到输出的传输子块不必自身对称。

任意矩阵可能需要缩放、额外损耗通道、衰减器或有源增益。可用 W = UΣV† 的分解指导网格设计，但不能假设任意腔体都具备这组自由度。

一般 M×N 复矩阵有 2MN 个实参数；仅靠少量壁面开关，通常不足以独立控制全部元素。还必须验证调谐参数到传输矩阵的有效独立性，而不只统计器件数量。

### 3.5 同一空间执行多任务：应怎样定义可编程

固定线性系统不可能仅因为输入被命名为“乘法模式”，就突破它的线性映射类别。

可行路径是：

- 切换载频，选择不同的预设传输函数；
- 改变边界、相移或耦合，重新配置线性权重；
- 启用不同非线性支路或偏置状态；
- 用控制输入改变材料或器件响应；
- 在有记忆的非线性系统中注入任务控制信号。

频率切换可以实现有限任务选择，但不等于任意函数可编程。原文第 186 至 198 行应增加“任务配置参数与可实现函数集合”的定义。

## 四、材料与器件选择

### 4.1 微波路线：适合首个可测量原型

| 材料或器件 | 用途 | 优点 | 主要限制 |
|---|---|---|---|
| 铜、铝及导电镀层 | 屏蔽腔体、反射边界 | 加工成熟，边界可测 | 接缝、氧化、表面粗糙度影响损耗 |
| PTFE 及低损耗微波复合基板 | 微带、相移与耦合网络 | 低损耗，工艺成熟 | 温度系数、加工公差、成本 |
| 氧化铝等陶瓷、高介电常数谐振材料 | 介质谐振器与场约束 | 可缩小尺寸 | 材料损耗、温漂、带宽及集成困难 |
| PIN 二极管、RF 开关 | 可切换边界与路径 | 控制直接 | 插损、偏置引线、寄生与开关功耗 |
| 变容二极管 | 调谐谐振与耦合；非线性响应 | 易购买、易偏置 | 调谐范围、Q 值、非线性和漂移互相制约 |
| 肖特基二极管、混频器 | 检波、混频、非线性计算 | 低门槛验证非线性 | 有限动态范围，寄生、失真与校准 |
| RF MEMS | 可调边界、机械位置或电容 | 可获得较低 RF 损耗 | 驱动、封装、寿命及速度限制 |
| 铁氧体、YIG | 磁调谐、非互易及磁子动力学 | 增加可用物理机制 | 磁偏置与集成复杂，普通低功率响应也可近似线性 |
| BST 等铁电材料 | 电压调谐介电响应 | 可作为可调单元 | 损耗、迟滞、温度依赖 |

首版建议铜或铝腔体、低损耗微波板、可替换的 PIN/变容单元和独立肖特基非线性支路。FR-4 可用于控制板和低要求对照，但不宜直接假设其适合高 Q、高精度计算核心。

最重要的材料指标不是“先进程度”，而是工作频率下的 ε、μ、损耗、非线性系数、温度系数、偏置要求和制造一致性。

### 4.2 光学与集成光子路线：适合后续密度扩展

光也是电磁波，因此集成光子计算属于该构想的技术范围。

| 材料平台 | 适合承担的功能 | 需要注意 |
|---|---|---|
| 硅光子 | 波导、干涉网络、调制及电子协同集成 | 常见体硅缺乏体电偶极二阶非线性；可利用三阶或载流子机制，伴随损耗与动态效应 |
| 氮化硅 | 低损耗传播、延迟线、谐振器 | 主动调制常需异质集成；低损耗不等于低功率强非线性 |
| 薄膜铌酸锂 | 高速电光调制、相位控制、二阶非线性 | 电光调制依赖外部电驱动；光学混频需模式与相位匹配 |
| III-V 半导体 | 激光、增益、吸收和非线性响应 | 噪声、热与异质集成难度 |
| 硫系玻璃 | 三阶非线性、全光信号处理 | 稳定性、工艺与功率承受能力需评估 |
| GST、GSST 等相变材料 | 非易失权重与光学状态配置 | 写入能量、循环寿命、漂移和吸收损耗 |
| VO2 等相变氧化物 | 开关与非线性探索 | 热过程、迟滞、损耗，不能直接等同于高速逻辑存储 |

“非易失权重存储”不等于“通用数据 RAM”。材料要分别满足权重配置、中间状态、频繁数据读写等不同任务。

全光 Kerr 等非线性通常需要足够光强和相互作用长度，或借助高 Q 共振增强。共振增强又会增加带宽、热稳定性和延迟约束。

不能因为采用非线性材料，就预设得到低功耗、精确且可级联的数字逻辑。

### 4.3 微型化不能只靠缩小金属箱体

自由空间波长：

```text
λ0 = c/f
```

3 GHz 时约 10 cm，30 GHz 时约 1 cm。普通传播型介质结构中的波长约按 1/√εr 缩短，但实际导波模式还受几何与截止条件影响。

高介电常数、慢波结构、集总 LC 与近场耦合能缩小单元，但会改变损耗、带宽、寄生和可制造性，并不保持原腔体全部性能。

1550 nm 光学波段有更小的波长尺度，却需要光子制造、耦合与封装技术。微波实验成功后，应重新设计芯片架构，而非按比例缩放箱体。

## 五、推荐的两种原型架构

### 5.1 原型 A：可编程线性电磁计算单元

目标：先证明核心计算由物理网络完成，并测清楚误差。

```text
共同参考时钟 / 相干本振
          ↓
多通道 IQ 调制输入
          ↓
可调多端口腔体或微波干涉网络
          ↓
多通道相干 IQ 接收
          ↓
固定增益、偏置与表示转换
          ↓
结果记录与离线验证
```

先做两输入、两输出；通过后扩展到四输入、四输出。约 2 至 3 GHz 可作为初步器件选型范围，不是最终设计规格。腔体尺寸、端口位置与工作频段需联合仿真。

第一版不要求任意矩阵，先实现恒等、交换、和差、归一化 Hadamard 等明确目标，再测可配置范围。

两条硬件分支各有价值：

- 保留腔体：较贴近原构想，适合研究可调边界和黑箱优化。
- 使用耦合器加相移器网格：参数更可解释，适合证明矩阵编程。

外部电脑可用于设计、校准和事后对照，但部署后的实时路径不应再执行目标矩阵乘法，也不应通过针对目标任务的大型数字逆变换“补出”结果。

### 5.2 原型 B：非线性储备池或逻辑单元

在原型 A 的基础上加入明确的非线性元件与反馈：

```text
输入 → 多径腔体 → 非线性器件 → 多点采样
                ↑              ↓
                └── 延迟反馈 ──┘
```

可采用近似状态模型：

```text
x(t+1) = F(x(t), u(t), θ)
y(t)   = Wout x(t)
```

优先研究非线性时序任务、短期记忆与简单逻辑。

标准储备池通常需要训练后的线性读出。如果 Wout 在数字电脑上执行，应称“物理特征计算加数字读出”的混合系统，不符合原稿关于外部仅做表示转换的严格边界。若坚持该边界，就需用模拟权重网络实现 Wout，并计入它的器件、校准与能耗。

同时，利用多个配置顺序测量得到“虚拟节点”会增加采样时间，不能把有效节点数全部视为真实同时并行通道。

## 六、速度、精度、稳定性和能耗

### 6.1 载频不是计算时钟

对近似单模、加载品质因数为 QL 的谐振器：

```text
谐振线宽 Δf ≈ f0/QL
能量衰减时间 τE = QL/(2πf0)
场幅衰减时间 τA = QL/(πf0)
```

以 f0 = 3 GHz、QL = 1000 为示例：

- 线宽约 3 MHz；
- 能量衰减时间约 53 ns；
- 场幅衰减时间约 106 ns；
- 单指数残留幅度降至初值的 1% 约需 489 ns。

这些是时间尺度估算，不是实测性能或对整个多模系统的保证。

因此，3 GHz 载波不代表每秒完成 30 亿次独立、无残留的计算。高 Q 增加储能与记忆，也可能降低带宽并延长重置时间。

总延迟需包含编码、传播与建立、检测、解码，以及必要的配置与反馈。

### 6.2 精度可能比传播速度更难

理想满幅正弦与理想 ADC 量化条件下：

```text
SNR ≈ 6.02N + 1.76 dB
```

八位约 50 dB，十六位约 98 dB。这只是理解量化尺度的参考，并非电磁计算精度的充分条件；实际还受非线性、漂移、串扰、相位误差与量程利用率限制。

整数幅度编码的等级数随位宽指数增长。位通道编码可减轻单通道多等级要求，但增加通道、进位与同步成本。

对发生强抵消的矩阵输出，应同时报告按满量程归一化的绝对误差，不能只用接近零输出的相对误差。

### 6.3 相干性与环境控制是首要工程条件

原文“两个独立信号发生装置”应改为“可独立调制但共享参考、并验证相位相干的通道”。

两个自由运行的同标称频率源会有相位漂移。共用频率参考也不必然保证每次触发具有相同相位，还需检查本振、PLL、触发和线缆延迟。

需要管理温度、机械位移、电缆弯折、端口匹配与初始状态。对于高 Q、多径敏感腔体，微小参数变化可能引起较大的输出变化。

第一版应优先使用中等 Q、易测量且可重置的系统，而不是追求最高 Q。

### 6.4 腔体记忆不是可靠长期存储

驻波、延迟线和谐振器可保存短暂状态，但有损系统会衰减。无限提高 Q 也会带来速度和稳定性代价。

中间结果可能需要电子锁存、SRAM、相变器件、磁性状态或带反馈的双稳态单元。要成为计算机，还需定义读写、寻址、保持时间和擦除行为。

### 6.5 必须统计整机能耗

至少计入：

```text
总能耗 =
波源 / 本振 + 调制 / DAC + 放大与偏置
+ 调谐与温控 + 接收 / ADC
+ 必需解码 / 反馈 + 必需存储与数据搬运
```

无源核心损耗很低，不等于整机低功耗。仪器原型也不能直接用于推断集成芯片能效。

可分别报告核心能耗、接口能耗和整机能耗。批量计算时可摊销配置成本，但必须同时报告任务切换代价。

同精度、同输入输出带宽和同准确率的 FPGA、DSP、CPU 或 GPU 才是合理对照。输入本来就是射频或光信号的应用，可能比“先把数字数据变成波、算完再转回数字”的任务更有优势。

## 七、建议的实验验收流程

以下数值是建议的初期验收目标，不是已有测量结果，也不是所有任务通用的指标。

### 阶段 0：明确任务与计算边界

写清输入编码、量程、输出编码、误差允许范围、溢出规则、复位条件和可配置参数。将软件训练、校准与实时计算严格分开。

### 阶段 1：证明相干、可重复与基线线性

- 用 VNA 测量端口 S 参数、谐振线宽、损耗和匹配。
- 在多个幅度和频率下测单独输入与同时输入。
- 检查 y(A+B) 与 y(A)+y(B) 的差异，并扣除偏置。
- 用频谱仪检查谐波和互调。
- 记录重复性、温度与重插线缆后的变化。

**目的不是寻找“偶然正确”的算术样例，而是确认现有系统属于哪一类物理映射。**

### 阶段 2：两路和差与小规模矩阵验证

- 固定配置，测试未参与配置优化的输入向量。
- 使用不少于 1000 个随机向量，并补充零输入、极值和强抵消样例。
- 初期可设按满量程归一化 RMS 误差不超过 1% 的目标，同时报告最大误差。
- 测多个独立目标矩阵，记录配置次数、收敛率、任务切换时间。
- 若未达到指标，区分噪声、可编程自由度不足与读出误差。

矩阵可采用基向量输入测得完整传输矩阵；随机测试主要用于补充验证线性度、动态范围和跨时间稳定性。

### 阶段 3：明确来源的非线性实验

- 插入二极管或混频支路，比较插入前后。
- 做双音互调和双变量幅度扫描，拟合乘法区间。
- 测 XOR 或一位全加器，覆盖全部四种或八种逻辑输入。
- 扰动相位、幅度、频率与温度，检查判决裕量。
- 短接腔体、更换为简单合路网络，检验腔体是否确实贡献了能力。

### 阶段 4：多位与级联

只有单级裕量和恢复能力明确后，再做两位、四位与八位。

八位加法应测试全部 256×256 = 65536 个输入对，并另做重复与边界扰动。不能只报告训练集正确率。

数字实验建议先在至少 10^6 次独立操作中统计错误；零错误仅意味着在独立同分布等假设下，95% 置信水平的错误概率上限约为 3×10^-6，不意味着零错误，更不足以证明大型计算机可靠性。

### 阶段 5：系统级对比与集成评估

在同任务、同精度条件下，比较端到端延迟、吞吐量、总能耗、面积与任务切换成本。之后再决定使用微波集成、毫米波、光子或光电混合路线。

仿真建议采用电磁全波工具评估腔体和端口，采用电路仿真评估非线性及偏置，并将实测材料、元件寄生和热漂移纳入模型。纯理想场仿真不能替代器件级验证。

## 八、已有研究说明什么

### 8.1 与“黑箱腔体”最接近的工作

Ma 等发表于 Physical Review Research 的 2022 年研究，实验演示了利用短波长混响波系统实现储备池计算，并通过空间和频谱扰动增加有效储备池规模。[1]

这表明“复杂微波腔体承担物理计算”并非没有先例。但它支持的是特定物理机器学习架构，不是任意整数算术或通用 CPU。

### 8.2 可调腔体可以通过优化形成传输函数

Faul 等的 2024 年公开预印本，演示了混沌腔体背衬的可编程金属超表面，用优化实现滤波与路由。[2]

这与原文的黑箱优化思想高度相关，同时说明：优化通常仍围绕传输函数、可调自由度和物理约束展开。该工作强调的线性特性并不会自动提供乘法与进位。

### 8.3 微波矩阵计算已有明确器件路线

2025 年 Nature Communications 的研究演示了四通道微波集成网络，用功分与可调相位实现可编程酉矩阵变换；其四通道设计采用五层、共二十个相位元件。[3]

这为优先开展矩阵任务提供了直接参考。它不是“任意箱体自然完成任意矩阵”，更不能由单元射频输入功率直接推断整机能耗。

### 8.4 集成光子非线性计算已取得进展

2026 年 Nature 的研究报告了具有片上反向传播训练的集成光子神经网络，在特定分类任务上得到超过 90% 的准确率。[4]

应注意其光调制器、探测、控制电路及 ADC/DAC 等具体实现边界。“无需数字电脑执行目标网络计算”不等于没有电子器件，也不等于实现了精确数字算术。

因此，“波计算”“黑箱物理优化”“多维编码”“同一结构多任务”等广义主张已有大量相邻工作。可能的新贡献需要落到具体结构、算法、非线性机制、编程方式或性能优势上。是否具备专利新颖性需另做专利检索，不能据此判定。
