# EWC真实材料与器件统一规划

日期：2026-11-17

## 1. 规划结论与适用范围

目标：先在仿真中建立可对应实际材料、结构和器件的一位全加器，再决定是否做样机。
本文件是系统选型与建模规划，不是已验证的采购BOM，也不表示现在需要购买硬件。

“需要真实器件”表示实物实现需要该功能，并且性能预测应对应具体型号、结构或有依据的模型。
不要求每个功能各用一颗芯片；集成、共享和复用必须通过连接、时序、负载及供能验证。
有真实型号也不等于有完整仿真模型，有厂家模型也不等于整个系统已经实测验证。

当前证据：

- 第十轮：校准后的一位基带代理模型通过规定的有限角点、历史与漂移测试。
- 第十一轮第一阶段：三维含介质损耗、分布式接收负载的响应提取和独立核验通过。
- 当前电磁源、接收体尚不是验证过的电压/电流端口；壁面仍为PEC，介质参数仍为通用假设。
- 更细网格的有限带宽接收波形仍有约6.7%差异，观察窗口后存在明显残留。
- 实际射频收发链、器件级校准、寄存控制以及完整供能尚未联接验证。

不能把上述结果解释为实物20 ns、一位腔体已实现、四位80 ns或某个硬件价格已经确定。

当前路线定义为“电磁线性叠加 + 有源电子判决/抵消 + 数字状态控制”的混合计算单元。
判决、再生、抵消和必要反馈属于计算核心，不能把它们的计算作用及开销归零。
长期全波、非线性材料、通用计算机和芯片集成是独立后续课题。

## 2. 最小系统边界

先规划两级电磁路径，不默认一个腔体已经能够同时实现两级功能：

```text
稳定参考时钟 → 共享相干本振 → 本振分配
                                │
输入A/B/Cin保持 → 射频调制、增益/相位调整
                                │
                      第一级：三路叠加
                                │
                 接收耦合 → 同步检测 → 进位判决C
                                             │
                                             └→ 再生/调制/反相 → 第二级抵消输入
输入A/B/Cin的独立加权分支 ────────────────→ 第二级：叠加与抵消
                                                       │
                                     接收耦合 → 同步检测 → 和位判决S

C/S → 输出采样与寄存 → 外部读取
校准监测 → 暂停计算 → 已知探测信号 → 测量 → 编程参数 → 恢复计算
电源、偏置、温度与状态监测贯穿全链
```

基线拓扑的逻辑端口数：第一级3个输入、1个输出；第二级3个数据输入、1个抵消输入、1个输出。
合计7个射频输入端口、2个接收端口；不等于7个独立振荡器，也不确定需要7颗调制芯片。
数据源共享后分路、权重调整与独立驱动的取舍，需要验证分配损耗和各端口负载。

这是待验证的参考拓扑，不是第十一轮四体积接口已经实现的拓扑。
若以后采用共腔时分复用，必须另外计入开关、隔离、切换建立、残留和复位等待。

抵消输入由实际C输出驱动，负权重通过明确的相位反转和增益结构实现。
不能在激励中根据A/B/Cin的正确答案提前生成C或S。

## 3. 实时计算链：必须对应真实功能

| 编号 | 模块 | 必须对应的实物功能 | 关键选型参数 | 当前状态 |
|---|---|---|---|---|
| R01 | 参考时钟与本振 | 晶振/参考源、射频振荡器或频率合成器 | 频段、相位噪声、抖动、温漂、锁定时间、供电 | 尚未建实际模型 |
| R02 | 本振分配 | 功分、缓冲、匹配连接 | 插损、幅相一致性、隔离、端口负载与驱动能力 | 尚未建模 |
| R03 | 输入保持与编码 | 稳定数字输入、寄存器或等效保持接口 | 电平兼容、建立/保持时间、更新偏斜、保持期间毛刺 | 当前理想PWL输入 |
| R04 | 射频调制 | 幅度调制、开关或IQ调制器，按编码选取 | 调制带宽、关断泄漏、线性度、瞬态、相位保持 | 当前归一化源 |
| R05 | 路径权重控制 | 衰减器、可变增益器、相位调整或固定匹配网络 | 分辨率、幅相误差、漂移、设置时间、频率响应 | 当前理想系数 |
| R06 | 发射驱动 | 满足实际端口负载的缓冲/放大功能；必要时独立功放 | 输出功率、阻抗、压缩、谐波、带宽、耗电 | 未建模；不默认每路加功放 |
| R07 | 互连与馈电 | 同轴/微带、射频接头、馈电探针或耦合环 | 长度、阻抗、反射、寄生、插损、安装公差 | 未建真实端口 |
| R08 | 两级计算结构 | 金属腔体或其他指定电磁结构，按架构配介质与耦合元件 | 模式、带宽、损耗、互耦、尺寸、振铃、制造公差 | 三维研究模型；非最终结构 |
| R09 | 接收耦合 | 真实探针/耦合环及匹配网络 | 电压/电流定义、阻抗、方向、场扰动、带宽 | 当前分布式有损体积；非接收器 |
| R10 | 接收前端 | 满足动态范围的缓冲或低噪声放大；是否需要由链路预算决定 | 噪声、输入阻抗、压缩、增益、相位、过载恢复 | 未建模 |
| R11 | 同步检测 | 保留有符号幅度的混频/相敏检测功能，必要时IQ解调 | LO相干性、转换增益、DC偏置、IQ误差、检测带宽 | 尚无实际器件模型 |
| R12 | 基带调理 | 低通滤波、偏置、缩放、基带驱动 | 通带/群延迟、噪声、输出摆幅、驱动负载 | 旧RC仅部分代理 |
| R13 | 进位/和位判决 | 两路比较器及所需输出电平再生/转换 | 输入共模、偏置、噪声、过驱动相关延迟、输出逻辑、负载 | 通用Level-1 MOS；非厂商器件 |
| R14 | 进位抵消与反馈 | 实际C输出驱动的再生、调制、负权重和反馈互连 | 实际低/高电平、反馈延迟、相位、增益、负载、稳定性 | 基带因果RC链；射频链未建模 |
| R15 | 输出采样与寄存 | C/S采样、保持和数字接口 | 时钟不确定度、建立/保持时间、亚稳态、输入电平 | 未建模 |

一位单元建议先采用共享参考的相干幅度编码，研究频段以既有3 GHz附近为候选，
不是固定采购规格。载频、调制带宽和计算更新周期必须分别确定。

单独使用多个未锁相振荡器会引入相位漂移，不能因“可独立控制输入”就默认它们自然相干。
普通功率检波器通常不保留信号符号/相位，不能直接代替现有有符号叠加与抵消链。
若只采用I通道判决，需证明相位已对准且误差满足预算；Q通道可用于监测，不能自动省略。

必要功能与具体器件应分开：例如调制器可能已有足够的输出驱动，
无需额外功放；数字衰减器可能无需外置控制DAC。不要为了列清单而重复添加器件。

## 4. 校准、监测与控制：不能遗漏

| 编号 | 模块 | 实物需求 | 在仿真中必须体现 |
|---|---|---|---|
| C01 | 已知校准激励 | 与数据路径共用的可控源，或明确的独立探测源 | 探测幅度/相位误差、加载方式、正常路径是否一致 |
| C02 | 训练/计算切换 | 必要的RF或模拟开关、旁路和隔离 | 导通阻抗、寄生、泄漏、切换毛刺、建立与恢复时间 |
| C03 | 校准采集 | ADC及前端，或满足预算的其他测量接口 | 量程、偏置、噪声、有效精度、采样时间、通道复用影响 |
| C04 | 参数编程 | 数字增益/衰减控制；模拟控制时才配DAC和参考 | 分辨率、实际传输关系、量化、更新等待、漂移 |
| C05 | 校准控制器 | MCU/FPGA或专用控制逻辑及参数存储 | 固定训练公式、完整时间成本、运行中参数冻结 |
| C06 | 漂移与故障监测 | 必要的幅相/温度/供电监测，暂停与重校准控制 | 监测误差、检测延迟、触发期间漂移、失锁与过载处理 |
| C07 | 时序控制 | 输入更新、采样、计算/校准模式和复位 | 实际时钟、同步、偏斜和状态转换，不只理想调度表 |

主数据路径并非一定需要高速ADC：满足要求时，可采用模拟同步检测后直接比较。
校准与监测仍需要可信的测量功能，可复用ADC但需计入测量间隔与切换。
ADC采样率和精度由校准预算与检测动态决定，不因3 GHz载频就默认要直接采样3 GHz。

外部软件/控制器可用于设计、已知信号标定、参数配置和事后验收。
实时运行时不得执行A+B、按正确答案选择输出，或为每组输入另调增益。
若未来确实采用数字检测/滤波，应明确其计算作用、实时延迟与供能，不能隐藏为“免费解码”。

第十轮的±1%有效系数和0.49%条件漂移触发是代理模型预算。
真实链路需把材料、端口、幅相、采集、编程、温度与监测误差映射到这些有效系数。
不能给各环节都分配1%，也不能把相位误差直接当成同数值的幅度误差。
校准能修正某些静态偏差，不会自动消除噪声、带宽不足或所有动态误差。

## 5. 电源、结构与环境：全系统共同需求

| 编号 | 项目 | 需要规划的实际内容 |
|---|---|---|
| P01 | 电源与稳压 | 本振、RF、模拟、数字供电；纹波、瞬态、效率、上电时序 |
| P02 | 偏置与基准 | 比较阈值、基带偏置、ADC/DAC参考；温漂、噪声及启动 |
| P03 | PCB与无源件 | 微波板材、铜厚、阻容寄生、去耦、回流路径、接地和隔离 |
| P04 | 屏蔽与机械装配 | 盖板接缝、紧固、接头开孔、介质夹具、表面处理与重复装配 |
| P05 | 热管理 | 器件发热、温度分布和散热；主动温控仅在必要时引入 |
| P06 | 管理接口 | 参数加载、状态读出和结果输出；若依赖主机在线运行，需明确其角色与开销 |

不能用理想电压源代表整套供电后，仍把局部比较器电流积分称为整机能量。
主动温控、风扇、通信及待机开销若是运行所必需，应计入对应系统边界。

## 6. 真实材料的统一选型

| 部位 | 候选方向，不是已定型牌号 | 需要的数据与制造约束 |
|---|---|---|
| 腔体壁 | 明确牌号与工艺的铝合金、铜；镀层方案单独评估 | 导电率与温度关系、表面粗糙度、镀层厚度、接缝与表面接触 |
| 腔内介质 | 有射频资料的PTFE类或其他明确微波介质；也评估无需介质的结构 | 目标频段介电常数、损耗角正切、色散、温漂、批次与方向性 |
| 射频PCB | 有公开微波参数的具体层压板 | 介电参数测试方法、厚度公差、铜粗糙度、层叠与制造能力 |
| 馈电与接头 | 目标频段可用的同轴/探针/耦合环结构 | 实际几何、材料、安装、端口参考面、频率响应 |
| 固定与屏蔽辅助件 | 实际使用的夹具、胶、螺钉、衬垫 | 电磁场中位置、介电/导电影响、热膨胀、装配重复性 |
| 阻尼/吸波部件 | 仅在残留与带宽权衡后加入具体材料 | 复介电/磁参数与频率、损耗、温升、可用性 |

原来epsilon_r=2.1和conductivity=0.002 S/m的通用介质，不直接命名为某个商业材料。
介电损耗若由损耗角正切描述，等效电导率通常是频率相关的；
仅为单频拟合的常数电导不能未经说明用于整个宽带瞬态。

低损耗不是唯一目标：高Q可能延长振铃，必须一起权衡输出裕量、带宽、稳定时间和驱动功率。
尺寸160×100×60 mm只是当前研究几何，不因易加工就固定为最终方案。

实际金属的微波表面损耗不能简单用毫米网格内的一层任意“有损体”替代。
应选择适用的表面阻抗/导体损耗模型并核验，或使用能解析必要尺度的网格与合适求解器。
若当前工具不支持所需模型，应记录能力限制并改用可执行且合适的工具，
不能继续PEC却宣称真实金属仿真完成。

选型顺序：任务与带宽要求 → 初始材料/器件候选 → 腔体、端口与链路联合评估 →
公差与漂移预算 → 收敛和验收 → 冻结牌号/型号/工艺。不是单向先买材料再凑电路。

## 7. 实验设备与运行器件严格分开

| 类别 | 例子 | 当前是否要购买 | 是否计入运行成本 |
|---|---|---|---|
| 实验验收设备 | 矢量网络分析仪、示波器、频谱/相噪测量、功率计、校准件、温度试验设备 | 不需要；将来可借用或租用 | 通常不计入部署运行功率，计入研发验证成本 |
| 台架信号源/采集仪 | 实验室RF发生器、外部采集卡 | 纯仿真阶段不需要 | 若样机实际依靠它发射/检测，则其功能和供能属于样机运行边界 |
| 仿真测试平台 | 理想输入、标准负载、真值检查程序 | 无需实物采购 | 不当作部署硬件；不得代替被测链路的必要功能 |
| 设计计算机与软件 | 电磁/电路求解、优化、事后分析 | 使用现有资源优先 | 属于研发资源；在线必需主机另行定义 |

无需在仿真中模拟一整台网络分析仪来获得S参数；
但必须有正确的端口激励、归一化、参考面和实际负载模型。
理想激励可用于器件单独测试，不能把理想驱动当作实际收发链性能。

## 8. 四位扩展及通用计算机的后续器件

| 范围 | 新增或扩展的实际需求 | 进入条件 |
|---|---|---|
| 四位串行复用 | 输入选择/移位、真实进位保持、结果寄存、位序控制、必要路由开关 | 一位联合模型通过；验证全部512个A/B/Cin组合及输入历史 |
| 四位并行 | 四套位单元、进位互连、输出采样、共享本振/电源分配和串扰隔离 | 同供电、负载、工作量和正确性口径；不按单比特周期直接外推 |
| 可编程计算结构 | 可调谐元件与偏置、配置存储、模式切换及稳定等待 | 明确调谐自由度能实现哪些实际功能 |
| 多单元网络 | 路由、缓冲、同步、级间匹配和通信接口 | 真实负载与互耦验证，不能仅复制独立单元结果 |
| 通用计算机 | RAM/状态存储、指令与寻址、数据搬运、控制及异常处理 | 单独定义架构；腔体振铃不当作可靠RAM |
| 芯片化 | 工艺、封装、片上/封装内互连、热与供电 | 与实验腔体是不同制造路线，需要重新建模 |

四位加法含两个4位操作数及1位进位输入，完整组合为16×16×2=512；
结果包含4位和及最终进位，不能漏掉溢出输出。

## 9. 每项选型必须交付的证据

所有R/C/P项目在冻结型号或材料前建立一条记录：

| 字段 | 要求 |
|---|---|
| 标识与功能 | 对应本文件编号；说明共享、独立、可选或替代关系 |
| 厂家/牌号/型号/版本 | 可对应实际规格；未定型就明确写候选 |
| 参数来源 | 官方数据手册、材料报告、厂商模型或注明依据的研究数据；记录链接、版本、频率/温度条件 |
| 模型文件与合法使用 | S参数、SPICE、IBIS或电磁几何等；记录校验值、许可及可运行工具 |
| 有效范围 | 供电、频率、温度、负载、信号幅度与工艺条件 |
| 误差与缺项 | 典型/最大值、统计或边界假设、参数不确定度、模型未覆盖内容 |
| 接口 | 电压/电流或功率波定义、参考面、阻抗、逻辑电平、输入输出范围 |
| 时序与供能 | 启动、建立、运行、切换、待机、校准；包含驱动与负载 |
| 制造与供货 | 实际工艺、公差、可获得性；价格单独记录询价日期与来源 |
| 验证 | 单器件基准、独立留出激励、数值收敛和系统验收的结果 |

模型选择按功能需要：

- S参数适合相应偏置、小信号范围内的线性RF接口，不自动覆盖调制瞬态、压缩与噪声。
- SPICE/厂商宏模型适合对应范围内的器件级电路；检查是否真正包含噪声、温漂和延迟。
- IBIS/数字时序模型可用于相应数字接口，但不能替代内部射频或模拟计算模型。
- 数据手册只有典型值时，可建立有注明依据的边界模型，不虚构成厂家全条件模型。

“真实型号 + 理想行为源”可以作为有缺项的阶段模型，
不能以写上型号的方式宣称已完成该器件物理仿真。

## 10. 执行顺序与阶段门槛

### 阶段A：冻结任务与候选链路

明确一位输入编码、输出电平、载频候选、调制带宽、更新时序、供电、
环境与加工公差需求，以及哪些功能属于计算核心。
建立材料和收发/判决器件候选表；目前不承诺20 ns、不冻结采购价格。

交付：接口框图、编号清单、数据来源、模型可用性表、初版误差/时序预算。

### 阶段B：验证物理端口与材料模型

先做有解析或可信参考结果的端口基准，核验电压/电流、阻抗、功率和负载作用。
选择具体材料，加入实际馈电、壁面损耗和关键装配结构。
逐步提取两级多端口响应，检查网格、时间、窗口、因果性、互易性及被动性。

交付：有正确单位与参考面的模型、收敛结果、原始数据与留出激励检查。
第十一轮的归一化分布式接口只作为对照，不能直接跳过本阶段。

### 阶段C：单独验证实际收发与判决链

按实际阻抗与驱动输入检查调制、接收检测、滤波和判决；
检查幅相、失真、动态范围、噪声、过载、负载及供电。
加入校准采集和参数编程，并证明它们能达到明确的有效系数预算。

交付：每模块基准、误差传播、实际路径延迟及完整供能清单。

### 阶段D：一位闭合链路联合验收

联接电磁多端口、实际接收负载、实际C驱动抵消和采样控制。
线性离线响应重放不自动证明非线性负载反馈已解决；
必要时采用多端口电路联接或适当的双向联合求解。

覆盖8个真值状态、64种状态跳转、指定长历史、误差角点、
真实材料与器件范围、动态漂移、启动、校准和模式恢复。
保留第十轮30%/70%输出与稳定窗口判据时，应确认它与所选输出接口兼容；
若接口换为差分或其他逻辑电平，先定义等价验收，不能暗中放宽。

交付：正确性、稳定周期、完整供能、校准代价和条件漂移预算。
网格未收敛、量纲不明确、正常运行按答案调参或必要功率缺项时，不通过进入门槛。

### 阶段E：四位对照与是否值得投入

再比较串行、并行和同位宽数字加法器，计入寄存、路由、时钟、供电、校准和数据搬运。
仿真结果值得投入后才冻结最小样机BOM；不以单比特结果推定整机优于CPU。

阶段通过表示规定范围内的模型证据足够，不是连续全条件数学保证或实物检测替代。

## 11. 延迟和能耗统一口径

延迟分为：启动、单次结果延迟、连续更新吞吐、校准暂停与恢复。
一位结果延迟应由实际关键路径确定，包括调制、腔体、检测、C到抵消反馈及最终采样。
并行分支有重叠时不能机械相加；存在依赖时也不能只取最快一段。

部署功率包含：参考/本振、分配与驱动、调制与权重、接收检测、判决/反馈、
寄存与控制、校准监测、偏置稳压及必要环境控制。
区分负载实际吸收功率与源/放大器耗电，不能重复计量，也不能遗漏RF供能。
运行、待机、校准分别记录；摊销按实际操作数与暂停时间计算。

研发仿真成本、实验仪器成本、单台物料成本与量产成本分开统计。
当前不沿用此前粗略讨论的1万～3万元等数字作为采购承诺，待模型与BOM明确后重新预算。
