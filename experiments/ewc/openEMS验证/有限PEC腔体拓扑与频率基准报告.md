# EWC有限PEC腔体拓扑与频率基准报告

日期：2026-11-18

## 1. 结论与范围

已建立无周期方向、六面有限边界的独立积分Maxwell空间算子，
完成4组网格、每组6个选定模态的本征求解和两条8 ns强迫瞬态轨迹。
独立数组差分核对24个本征场、2000个完整时间步及10项专用测试通过。
现有电磁测试连同本批共50项回归通过，未重跑历史原生openEMS FDTD。

最细24×15×9网格下，六个选定模态最大频率误差0.67075%，
通过本批1%频率子任务门槛。16×10×6网格最大误差1.50460%仍失败。
这不是一般腔体全谱、整个频带传输精度或整机误差预算通过。

**本批是PEC数学基准，不是实际铜腔性能仿真，不是openEMS扩展。**
先建立有限空间拓扑和准确的无损参考，下一步才耦合各壁面铜损耗。
PEC没有焦耳损耗，不能用本批频率、能量或无衰减结果宣称铜腔Q通过。
没有冻结最终腔体尺寸、材料、器件BOM或采购计划。

## 2. 有限网格与边界

研究空气矩形腔长160×100×60 mm，三个方向均为有限边界。
这仅沿用研究尺寸作为可解析基准，不意味着该几何适合两级波计算。

全电场边与磁通面的数组布局：

```text
Ex: Nx × (Ny+1) × (Nz+1)
Ey: (Nx+1) × Ny × (Nz+1)
Ez: (Nx+1) × (Ny+1) × Nz
Bx: (Nx+1) × Ny × Nz
By: Nx × (Ny+1) × Nz
Bz: Nx × Ny × (Nz+1)
```

边变量e为电场线积分，单位V；面变量b为磁通量，单位Wb。
全网格保留节点到边梯度G和面到边旋度C的拓扑关联。
在六个边界面删除切向电场自由度，法向电场边仍存在。
从零边界法向磁通出发，法拉第更新保持边界法向磁通为零。
边缘与角点按同一有限关联处理，没有周期绕回或重复墙面铜支路。

电场质量权重为ε乘双网格面积再除边长；
磁场权重为双网格法向宽度除以μ与面面积。
端点双网格宽度为半单元，均为正。
切向PEC约束通过限制矩阵自由度实现，不通过极大电导或惩罚值近似。
本批仅空气ε0、μ0；尚未验证非均匀介质、开孔和接头。

## 3. 本征频率求解

实际组装并求解：

```text
K = Cᵀ Q C
K e = ω² Me e
f = ω/(2π)
fcontinuum = c0/2 sqrt[(m/Lx)²+(n/Ly)²+(p/Lz)²]
```

每个网格检查(1,1,0)、(1,0,1)、(0,1,1)、(2,1,0)、(1,2,0)、(1,1,1)。
至少两个模态指标为正；全正指标本批只求一个离散横向极化，
不宣称已枚举其全部简并模态。

用满足PEC边界的采样模态作为稀疏求解初向量，
其Rayleigh商用于选定移位目标，再对实际K/Me求本征对。
没有把解析频率写入矩阵；但这属于定向模态求解，不是盲搜索全谱。
静电梯度零空间保留，不删除后冒称电荷自由度不存在。
小网格另做完整稠密广义本征求解，核对首个非零频率和零空间维数。

独立解析离散目标只用于复核：

```text
ωdiscrete² = c0² sum [2 sin(ka Δa/2)/Δa]²
ka = π mode_index_a / La
```

## 5. 瞬态与内部电荷连续性

8×5×3网格，分别dt=5 ps、20 ps，持续8 ns。
从e=b=0出发，以固定随机空间电流分布乘0.4 ns内的sin²脉冲激发；
0.4 ns后源电流精确为零。保存每步完整e、b和源电流，不只保存少量快照。
本批使用同步隐式中点，不是Yee时间跃蛙。

```text
db/dt = -C e
Me de/dt = Cᵀ Q b + Jdrive
ρinterior = -Ginteriorᵀ Me e
dρinterior/dt = -Ginteriorᵀ Jdrive
U = (eᵀ Me e+bᵀ Q b)/2
ΔU = dt Jdriveᵀ e_mid
```

这里Jdrive是右端注入电流，物理传导电流方向须按接口另定义，
不能把公式中的符号无条件移植到芯片或墙面电流。
限定PEC且边界节点势为零的内部梯度满足C Ginterior=0。
因此可以独立核对非零注入产生的内部电荷，而不只检查div(B)。
**未包含PEC表面电荷、约束反力对应的墙面电流及完整外部端口电荷账目。**

独立复核结果最大值：

- 本征场方程相对残差约3.31e-14。
- 本征场内部Gauss相对残差约3.18e-14。
- 2000步电场方程相对残差约7.63e-14。
- 磁通方程相对残差约2.22e-15。
- 内部电荷连续性相对残差约6.24e-16。
- 磁通散度相对残差约1.24e-15；六面法向磁通严格为零。
- 累计能量闭合约2.35e-13。
- 源关闭后最大单步储能增长约8.89e-16（舍入量级）。

这些极小值只表示离散实现一致。
无损PEC源关闭后储能保持而不是铜耗散衰减，
且注入电流会留下静电储能，不能把尾部当成腔体Q衰减。
5/20 ps本批均未完成瞬态物理时间精度验收；稳定和能量闭合不能代替该验收。

## 6. 归档与复现

源码：

- `finite_pec_cavity.py`：有限关联、PEC自由度、定向本征求解与瞬态。
- `run_finite_pec_cavity.py`：正式24个本征解和2条轨迹。
- `verify_finite_pec_cavity.py`：不导入求解模块，以数组差分核对场、频率、内部电荷、能量和哈希。
- `test_finite_pec_cavity.py`：10项拓扑、权重、本征、连续性及非法输入测试。

正式结果在`有限PEC腔体结果/`，含4个本征NPZ、2个完整轨迹NPZ、
summary.json与verification.json，共8个文件。
源文件和原始结果记录SHA-256。
最初试跑的计算完成后，汇总因NumPy整数无法JSON序列化而失败；
修复元数据类型并完整重跑，正式批次返回0，不将失败试跑计为正式完成批次。
测试中tuple乘2触发数组长度错误也已修复，未修改物理门槛。

```powershell
python -B "openEMS验证/run_finite_pec_cavity.py" --output "openEMS验证/有限PEC腔体结果"
python -B "openEMS验证/verify_finite_pec_cavity.py" "openEMS验证/有限PEC腔体结果"
python -B -m unittest discover -s "openEMS验证" -p "test_*.py"
```

## 7. 后续门槛

本批仅补齐有限PEC空间拓扑、选定模态频率和内部电荷连续性基准。
下一步需解除切向PEC约束、建立六面一侧铜阻抗耦合，
检查各法向符号与面积、边缘支路归属、铜状态储能和正耗散。
再验证铜壁损耗Q、频率偏移及源关闭长时间衰减，
区分静电储能、多模态混合和数值时间频移。
实际粗糙度、接缝、材料公差、介质、真实接头及两级多端口继续独立验收。

不得将该有限PEC结果替换已有周期铜边界证据，
也不得组合两种局部通过结论宣称六面铜腔已经通过。
