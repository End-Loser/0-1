# 铜腔带源因果历史验证

## 范围与边界

本批为自建完整积分Maxwell铜腔模型的16 ns限定瞬态。
矩形腔尺寸0.16×0.10×0.06 m，网格36×23×14，六面墙保留全部64项RL状态。
不是原生openEMS功能，不是制造结构或实际电压/电流馈电端口。
分布式外加电流不能替代接头、探针、接收负载及真实器件供能。

预声明六组：111两个连续铜损耗本征方向各做5/2 ps衰减，
以及011/111两极化交叠六脉冲的5/2 ps连续历史。
历史初始全零，脉冲间不重置E/B/铜记忆，12 ns停源后继续到16 ns。
全场求解，三模态投影仅用于探针和定义外加源，不降阶物理状态。
初态是PEC场而非铜极点稳态；短窗衰减须独立测量，不外推长时。

## 方程与前置验证

新增`copper_driven_midpoint.py`继承已批准的完整CG算子，
只在中点电场右端加入完整边电流，不修改原求解器或正在运行的8 μs源码。
独立数组差分核对：

```text
M (E1-E0)/dt - C^T Q Bmid + Jwall = Jsource_mid
(B1-B0)/dt + C Emid = 0
L (I1-I0)/dt = R (Jwall_branch - Imid)
d rho/dt = divergence(Jsource_mid - Jwall)
U1-U0 + dt * copper_heat_rate - dt * Emid^T Jsource_mid = 0
```

七项步进回归已通过：完整未消元E/B/RL/墙流联合线性系统LU对照、
零源与原CG逐值一致、源做功及电荷不得遗漏、反号/墙流篡改拒绝、
错误形状/非有限/复数状态拒绝、未收敛拒绝、负源做功吸收能量。
三项运行器回归通过：源因果边界、交叠加性、不重置的全状态小网格实际步进。
三项独立复核前置回归通过：不同包络公式全历史对照、
严格1%与非有限拒绝、运行中/失败批次不得进入完整验收。
