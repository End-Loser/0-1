# 六面铜壁频域耦合与损耗Q报告

日期：2026-11-18，扩展五线并行验证的电磁主线。

## 1. 结论

已从有限PEC基准建立六面一侧铜阻抗的独立频域积分Maxwell耦合，
完成7个配置、70次完整三维频域求解及独立复核，9项专用测试通过。
不是openEMS原生扩展，不是周期投影或定向一维传输线。
两种最细模态频率相对连续PEC参考误差为0.42313%和0.45565%，
但铜损耗Q误差仍为2.09332%和2.04621%，**均未达到本批1%门槛**。

因此本批通过的是离散六壁耦合、功率账目、局部极点和储能一致性检查，
不是损耗Q精度、真实铜腔或整机通过。
保留粗网格及16项铜核失败，不按频率通过掩盖Q失败。
下一步需要更细空间收敛及独立方法对照，再做源关闭长历史衰减。
没有冻结制造尺寸、BOM或采购，研究腔尺寸仍为160×100×60 mm。

## 2. 全有限场与六壁

复用第一批`finite_pec_cavity.py`的全有限旋度与梯度关联，
但不使用其切向PEC自由度限制。全电场边均参与频域求解，
包括六个边界面的切向边和棱边。第一批源码和哈希不修改。
三个方向均无周期绕回。

使用峰值相量和exp(+jωt)：

```text
s b = -C e
s Me e = Cᵀ Q b + Jdrive - Jwall
[Cᵀ Q C + s² Me + s Gwall] e = s Jdrive
```

Me为正的ε0双网格面积/边长，Q为正的双网格宽度/(μ0面面积)。
端点双网格宽度为半单元，不用大电导近似PEC约束。
边变量e单位V、面变量b单位Wb，驱动变量为边注入电流A。
激励采用已有PEC采样模态的Me加权向量，仅作线性研究源；
其归一化幅度不代表真实发射器功率。

每个壁面单独记录其切向边：

```text
scale = edge_length / surface_dual_width
Zedge = scale × Zsurface
Jrecord = e_edge / Zedge
Jwall(edge) = sum(all face records on that edge)
```

在棱边上有来自两个不同壁面的记录，各自双网格表面宽度为半单元，
电流以并联贡献相加，不能先将两个法向视为一个全宽壁面。
每面每个切向方向的面积权重之和均独立核对为完整壁面面积。
这补齐有限盒体边缘的离散归属，不证明任意锐角、圆角或接缝的物理精度。
法向的拓扑方向由全有限C定义；各壁输入均以正实表面阻抗吸收，
不人工翻转某一面耗散符号来使功率闭合。

## 3. 铜核与支路账目

重读已验收的一侧Foster正RL模型，C11000典型σ=58.58 MS/m。
64项为主线，16项作为材料近似失败对照；R/L是数学状态参数，不是采购器件。
所有网格的实际扫描频点均位于约2.64～2.91 GHz。
本批没有补充粗糙度、温漂、氧化、接缝或制造公差。

```text
Zsurface(s) = sum Rk s Lk / (Rk + s Lk)
Rrecord,k = scale × Rk
Lrecord,k = scale × Lk
Iind,k = Jrecord × Rrecord,k / (Rrecord,k+s Lrecord,k)
PJoule = 1/2 sum Rrecord,k |Jrecord-Iind,k|²
Uwall = 1/4 sum Lrecord,k |Iind,k|²
```

频域同时核对：

```text
Pwall = 1/2 Re sum(e_edge* Jrecord)
Psource = 1/2 Re(e* Jdrive)
UEM = 1/4 (e* Me e + b* Q b)
Qenergy = ω (UEM+Uwall)/Pwall
```

正实性、墙面输入功率与每支路焦耳功率相符，仅验收这些限定频点，
不等于新增六壁因果瞬态耦合已稳定或长时间已衰减。

## 4. 局部极点与独立Q参考

本批选择011和101，分别以Ex与Ey为主的电模态，均有两个正模态指标。
以实际离散PEC频率为扫描中心依据，按连续参考Q选择窄扫描窗口；
每配置9个驱动频点，对模态响应倒数作局部复线性拟合，再求1个拟合峰值频点。
是局部响应极点估计，不是全谱非线性复本征求解。

```text
Amplitude(f) = seed* Me e(f)
1/Amplitude ≈ a(f-fcenter)+b
fpole = fcenter-b/a
Qpole = Re(fpole)/(2 Im(fpole))
```

在exp(+jωt)约定下，衰减极点Im(fpole)>0。
在峰值频点另核对Qenergy与Qpole。
拟合窗口及高Q局部近似仍须后续做宽度/频点收敛，
不能将一个高精度拟合残差当成独立物理Q验收。

连续参考为光滑良导体壁的PEC场一阶损耗微扰：

```text
Rs = sqrt(ω μ0/(2σ))
Qreference = ω ε0 ∫volume |EPEC|² dV / [Rs ∫surface |Ht,PEC|² dA]
```

运行器用解析矩形模态积分公式；复核器用24点高斯积分重新计算体电场、
六面切向磁场和耗散，不导入运行器参考函数。
011参考f=2.913459 GHz、Q=22767.03619；
101参考f=2.668154 GHz、Q=19269.66914。
该参考属于光滑壁微扰，不是制造铜腔测量或完整有限导体体积求解。

参考能量衰减常数Q/ω约为微秒量级；
实际接头、接缝、介质或外加阻尼会改变Q，因此不直接用于硬件速度承诺。
振幅衰减时间常数为2Q/ω，不能与能量时间常数混用。

## 5. 结果与失败

| 网格/模态/铜项数 | 数值Qpole | Q相对误差 | 连续频率相对误差 |
|---|---:|---:|---:|
| 4×3×2 / 011 / 64 | 34997.866 | 53.72166% | 8.49230% |
| 8×5×3 / 011 / 64 | 27449.080 | 20.56501% | 3.74070% |
| 16×10×6 / 011 / 64 | 23853.621 | 4.77262% | 0.94734% |
| 24×15×9 / 011 / 64 | 23243.623 | 2.09332% | 0.42313% |
| 16×10×6 / 101 / 64 | 20167.712 | 4.66040% | 1.01978% |
| 24×15×9 / 101 / 64 | 19663.966 | 2.04621% | 0.45565% |
| 24×15×9 / 011 / 16 | 24704.876 | 8.51160% | 0.42319% |

所有Q误差均未通过1%。三个方向细化使Q误差下降，但本批未达到收敛门槛。
101的16×10×6频率1.01978%仍失败，不四舍五入通过。
16项铜核几乎不改变共振频率误差，却使Q进一步恶化；
说明只检查共振频率不足以检查铜损耗模型。

最细64项峰值频率为011的2.901131270 GHz、101的2.655996502 GHz。
这些偏差同时含空间离散和铜反应性，不把相对连续PEC的全部偏差归为铜频移。
独立PEC离散频率保存在NPZ中，后续可分别比较空间偏差与铜频移。

## 6. 独立复核

复核器不导入铜求解模块，通过独立数组差分、全节点散度、
表面几何、支路阻抗和高斯积分重读全部70组完整场。
复用旧PEC数组助手时按实部/虚部分别作用，保持旧源码不变。
最大独立核对指标：

- 电场方程相对残差约9.96e-15，磁通方程约2.04e-16。
- 全离散节点电荷连续性相对残差约1.03e-13。
- 源输入与六壁功率相对闭合约2.18e-13。
- 支路焦耳功率与墙面输入功率相对差约5.55e-16。
- Qpole与独立Qenergy最大相对差约1.22e-5，即0.00122%。

另作同网格PEC场的表面损耗微扰诊断：
复核器直接从归档驱动向量恢复PEC种子场，以独立数组差分得到磁通，
并按每壁切向磁场分量分离表面电流，用相同频率的Foster实部计算损耗。
7例该离散参考与Qpole最大相对差约0.00373%，
最细011/101的离散参考Q分别为23243.941/19664.051。
它们与完整铜壁Q接近，但仍与连续参考有约2%的差异，
支持64项主线当前主要误差来自空间/表面场离散，而非局部极点拟合。
这是同一空间拓扑下的诊断，不是新增独立连续物理模型，
也不能用该离散参考替换连续参考来将Q失败校准为通过。

全离散节点电荷ρ=-Gᵀ Me e，包括边界节点，独立核对
sρ=-Gᵀ(Jdrive-Jwall)。这是所选有限图模型的电荷连续性，
不是微观金属表面电荷分布、真实接头位移电流或外部器件电荷验收。
上述接近机器精度的核对不能覆盖表中2%至54%的物理参考误差。

9项专用测试覆盖几何权重、六面切向面积、棱边两个并联记录、
全节点散度方向、独立连续Q、导电率缩放、驱动功率、已知局部极点与非法输入。
首次独立复核因旧实数助手不能直接累加复数而失败；
只修复复核器的复线性调用，70个原始解未改，未重跑或调整门槛。

## 7. 文件与复现

源码为`finite_copper_cavity.py`、`run_finite_copper_cavity.py`、
`verify_finite_copper_cavity.py`、`test_finite_copper_cavity.py`。
正式结果`六面铜壁频域结果/`含7个NPZ、summary和verification，共9个文件。
每NPZ保存9个扫描场与峰值场、六壁电流、全部支路电感电流和归一化功率；
源、模型、原始数据及复核助手记录SHA-256。

```powershell
python -B "openEMS验证/run_finite_copper_cavity.py" --output "openEMS验证/六面铜壁频域结果"
python -B "openEMS验证/verify_finite_copper_cavity.py" "openEMS验证/六面铜壁频域结果"

```

测试中的小网格功能求解是软件检查，不重复计入70次正式解。
现有openEMS原生基准不被本模块替换，不重跑历史FDTD、不绕过应用控制策略。
