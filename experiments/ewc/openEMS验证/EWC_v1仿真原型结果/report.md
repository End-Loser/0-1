# EWC 腔体计算仿真原型 v1

> 结论边界：这是**仿真原型**。端口为 delta-gap 边簇、负载为并联电导、检测判决为离线后处理；七包门槛仍为 0/7，不得当作硬件验证。

## 一、这一版做了什么

输入 4 位码，在四个源端口以 +1/-1 幅度（相位 0/π）同时注入铜腔，在六个端口用锁相方式读出复幅度，再对四条基向量做最小二乘解码，由系数符号还原比特。全部 16 组码都实跑，没有抽样。

## 六、明确不声明

- 端口是 delta-gap 边簇，不是真实 SMA/同轴馈口
- 负载是同一算子内的并联电导，不是实体端接
- 检测/判决是锁相读出的离线后处理，没有射频检波器或比较器
- 解码是线性叠加的码本回收，不是通用逻辑门或进位运算
- 单一几何、单频点，无硬件、无 BOM、无温度与老化
- 不能据此声称真实开关速度或系统级精度
- 七包门槛 0/7，`full_system_gates_closed=0`，`goal_complete=false`。
