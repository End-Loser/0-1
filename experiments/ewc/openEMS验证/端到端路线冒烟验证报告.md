## 3. 链路各段实测

### 3.1 端口 → 负载 → 检测（功率账目）

25 个端口行（每例端口读数）全部满足功率闭合：

| 检验 | 实测 | 判读 |
|---|---|---|
| `power_closure = (P_wall+P_load)/P_source` | **0.99999999999999856 ～ 1.000000000000002** | 通过（1±1e-6 门槛，实际达 1e-15 量级） |
| `load_fraction = P_load / (P_wall+P_load)` | **0.980696 ～ 0.996465** | 负载端读数可作判决量 |
| 端口 `abs_s11`（单源例首行） | 0.99497 | 50 Ω 匹配**不可**作门槛，判决只能用比值/相位 |

### 3.2 时域 ↔ 频域跨域一致性（9 个单源例）

校准因子 `alpha`（频域幅度 → 时域锁相幅度）：`|alpha| = 0.9815496`，相位 `-88.263542°`（≈ -π/2，来自中点驱动的导数约定，随源码哈希固定）。

## 4. 限制（逐条抄自 `configurations.json.limitations`）

1. 端口是轴向 delta-gap 边束，不是真实 SMA/同轴馈电；
2. 负载是同一算子内的并联电导，不是实物端接；
3. 检测与判决是 gap 电压的离线后处理，无 RF 检波器或比较器；
4. 单一固定几何、单一频点、十端口簇，无硬件、无 BOM；
5. 无 8 状态 / 24 跳转长历史，无 512 组合 G7 矩阵；
6. 不得用于声称真实 20 ns 切换速度或系统级 0.5% 精度。

**G7 编码额外限制**：源幅度 ±1 是替代相位编码，不是真实数字驱动、进位或串扰；真实四位验收需 G6 通过后另行建立。
