# 电流分离与有限铜损耗基准报告

日期：2026-11-17

## 1. 结论

本批完成24次正式openEMS FDTD运行：12次电流分离、12次铜薄片/PEC对照。
原始数据哈希、独立方程与傅里叶后处理复核通过；另有6项离线单元测试通过。
上一批17次端口结果回归复核通过，历史失败项未删除。

本批解决的是**限定基准中的支路电流定义**，同时发现新的材料模型限制：

- 电流分离12例全部达到1%相对门槛，支路核对最大误差约0.316%。
- 负载避开PMC边界、dx=0.5 mm时，三种负载的中心电压/支路电流对应达到1%。
- 铜薄片产生了非零损耗，但35 μm样例的复数表面阻抗仍有约32%误差，
  不能用于要求准确相位的厚铜腔壁模型。

**完整物理端口、厚铜腔体和真实器件联合仿真仍未通过。**
这不证明铜材料不可制造；它说明当前铜薄片近似不足以承担本项目的幅度/相位验收。

## 2. 电流分离基准

保留上一批240×75.346×10 mm空气TEM结构及50 Ω参考阻抗，
电阻仍为跨平行板的25、50、100 Ω集总分流负载，不是匹配终端或真实接头。

| 参数 | 配置 |
|---|---|
| 轴向网格 | dx=1、0.5 mm |
| 横向网格 | y方向40单元，z方向4单元 |
| 负载布置 | 原始贴PMC边界；另设距两侧各一个y网格间隔的布置 |
| 电流环路 | 半宽2dx、4dx；两个不同z测量面 |
| 时间窗口 | 8 ns |
| 分离核对频点 | 2.5、3、3.5 GHz |
| 原生导出 | 电场E、D场、curl(H)、材料J；不做场插值 |

每例检查4个环路，共48个环路、144个频点/环路组合。
仅有三个分离核对频点，不能将其描述成整个连续频带的1%保证。
8 ns是本开放基准的观察窗，不是计算腔体复位时间或器件操作周期。

### 2.1 总电流不等于电阻支路电流

原生环路积分来自磁场环量，对应导电电流与位移电流之和。
在有限面积环路中，空气电容的位移电流不可忽略。
两倍大小的环路即使包围同一电阻，原始U/I也可能不同。

本批根据实际导出的D场和环路的**原生离散索引**，逐格积分电通量；
按Yee时间交错的离散安培关系扣除位移电流：

```text
I_total = I_conductive + I_displacement
I_displacement(f) = [2j·sin(pi·f·dt)/dt] · D_flux(f)
```

离散电导支路的时间平均项为cos(pi·f·dt)，不是随意拟合的相位补偿。
curl(H)导出使用电场时间标签时，另按半步时间关系与磁场环路对齐。
所有比例由时间步长、网格、介电常数和原生数据确定，没有按正确答案回调R。

集总R由求解器分布为离散电导。
几何归一化取并联边面积/边长度，再串联电阻方向各段；
不能只拿一个中心电场值乘上名义R，忽略实际并联支路的电压分布。

对于原始贴边布置，环路与电阻离散支路的范围不完全相同。
脚本只用独立电场/电导积分恢复环路之外的支路；
对于避开边界的布置，环路已包围全部负载支路，这个恢复项为零。
因此后者的支路电流来自“实测环量减位移电流”，不是用U/R替代测量。

### 2.2 核对结果

| 检查项 | 12例最大值 |
|---|---:|
| 总电流减位移电流，与所包围电导电流的相对差异 | 0.316% |
| 恢复后的支路电流，与负载加权电压/R的相对差异 | 0.316% |
| 改变环路大小/高度后的支路电流相对变化 | 0.082% |
| D与空气epsilon0·E的相对差异 | 6.09e-7 |

加权电压取实际分布电阻各并联支路电压的几何权重，
是一个明确的离散端口定义，不等于厂家接头参考面上的端口电压。

单独检查中心电压与分离后的支路电流：

| 避开边界、dx=0.5 mm的分流R | 支路电流与中心电压/R最大相对差异 |
|---|---:|
| 25 Ω | 0.869% |
| 50 Ω | 0.483% |
| 100 Ω | 0.341% |

原始贴边布置仍有约5%差异，**没有通过**这个中心电压接口检查。
避开边界但dx=1 mm的25 Ω样例仍有约1.739%差异，也保留为未通过。
新布置是新的几何基准，不能将它的通过追溯到原来17次端口测试。

### 2.3 不能直接使用材料J导出

本批有电阻支路电流，但原生材料J频域导出为零。
核对实现发现，该导出读取材料电导率存储，而集总R更新的是离散电路电导；
二者在本路径中不等价。

因此，不能把“J导出为零”解释为负载不吸收信号，也不能用它替代集总支路电流。
本批用E、D、磁场环量和curl(H)交叉核对，保留这一接口限制。

## 3. 有限铜薄片基准

移除集总分流R，在x=150 mm加入原生ConductingSheet。
使用C11000候选的20°C典型sigma=58.58 MS/m，
来源仍为首批归档的Copper Development Association数据及101% IACS换算。
没有将它当成全部加工状态、批次或温度下的保证值。

| 项目 | 配置 |
|---|---|
| 材料 | 铜典型有限电导，非磁性、光滑均匀近似 |
| 对照 | PEC；2 μm铜薄片；35 μm铜薄片 |
| 网格 | dx=1、0.5 mm；z为8、16单元，y为20单元 |
| 核对频带 | 2.5～3.5 GHz，共101频点 |
| 表面阻抗测量 | 原生切向Ez与两侧Hy之差；扣除包围空气位移电流 |
| 3 GHz趋肤深度 | 约1.201 μm |

这是**局部薄片表面响应**核对，不是完整腔体铜损耗、整体吸收能量或铜箔制造验收。
没有用毫米网格假装直接解析微米趋肤层。

### 3.1 两种不能混用的解析量

官方薄片参数的目标是两侧共用面电压的等效薄片阻抗：

```text
gamma = sqrt(j·omega·mu0·sigma)
Z_sheet = gamma / [2·sigma·tanh(gamma·d/2)]
```

一侧厚导体边界的表面阻抗则是：

```text
Z_wall = sqrt(j·omega·mu0/sigma)
```

当d远大于趋肤深度时，以上薄片目标趋近Z_wall/2。
它不是一侧厚铜壁的边界条件，也不等于完整有限厚金属层的双面独立场解。
不能只因为铜箔厚度大于趋肤深度，就无条件把薄片模型贴到腔壁上。

### 3.2 最细网格结果

dx=0.5 mm、z=16单元：

| 铜厚度 | 与解析薄片阻抗的实部相对误差 | 复数相对误差 | 状态 |
|---|---:|---:|---|
| 2 μm | 0.321% | 6.786% | 复数阻抗未通过 |
| 35 μm | 0.593% | 32.145% | 复数阻抗未通过 |

PEC四个网格对照的表面阻抗均为零。
有限铜样例的阻抗实部为正，支持模型中确实有损耗，
但不等于损耗模型或完整供能已经达到整机精度。

35 μm、3 GHz的测量阻抗约为0.007133+j0.004172 Ω；
解析薄片目标约为0.007109+j0.007109 Ω。
由此可见，只检查阻抗实部会遗漏明显的虚部/相位误差。

### 3.3 官方近似参数解释了主要偏差

已固定上游提交`92cd92a8d924c78a93453c25fa541384c2ac1d0e`，
归档参数表、优化脚本与实现文本及SHA-256。
优化目标明确写为：

```text
Ydiff = real(1./Ys) - real(1./Y)
```

它拟合阻抗实部，不是拟合完整复数阻抗。
独立读取参数表并计算其有理模型后，得到：

| 最细35 μm样例检查 | 最大复数相对差异 |
|---|---:|
| FDTD测量与固定版本有理模型 | 0.060% |
| 有理模型与解析薄片目标 | 32.121% |

这说明测量与该近似模型高度一致，而模型自身的复数精度不足，
不是简单继续细化网格就能解决。
本批未逐字证明缓存二进制与该提交一致；参数数值匹配是交叉证据，不冒充二进制来源证明。
未修改求解器参数表，也没有把复数误差门槛改成只看实部。

## 4. 独立复核与交付

新脚本：

- `run_current_partition.py`：电流分离矩阵。
- `run_copper_sheet_benchmark.py`：有限铜薄片与PEC网格对照。
- `native_field_io.py`：压缩VTK XML解码及复数场重建。
- `verify_current_and_sheet.py`：独立重读原始数据、核对方程、分析官方参数。
- `test_native_material_benchmarks.py`：6项离线单元测试。

HDF5 Python扩展在本机被应用程序控制策略阻止；
VTK解码仅使用标准库和NumPy，不解除安全限制，也不自行求解电磁场。

结果位于`openEMS验证/电流分离与铜损耗结果/`：
包含24例JSON/NPZ、汇总、官方薄片模型来源快照和verification.json。
原生XML、完整日志和全部VTK相位文件保存在外部缓存，
各例JSON记录路径和文件SHA-256；缓存删除后需重新运行。

独立后处理未调用运行脚本的分析函数。
电流DFT最大绝对差异小于2.35e-25 A·s；
铜阻抗DFT最大绝对差异小于6.25e-14 Ω。
这些数值只表示后处理一致性，不是物理误差小到这个量级。

复现命令：

```powershell
python -B "openEMS验证/run_current_partition.py" --output "openEMS验证/电流分离与铜损耗结果/电流分离"
python -B "openEMS验证/run_copper_sheet_benchmark.py" --output "openEMS验证/电流分离与铜损耗结果/铜薄片"
python -B "openEMS验证/verify_current_and_sheet.py" "openEMS验证/电流分离与铜损耗结果"
python -B "openEMS验证/test_native_material_benchmarks.py"
```

## 5. 下一步门槛

1. 采用能保留正确复数表面阻抗的一侧厚导体模型，先做平面或传输线解析基准，
   核对幅度、相位、正耗散与收敛；不能只把ConductingSheet厚度设大。
2. 设计匹配终端及实际探针/接头参考面，验证一般三维电压、电流和功率；
   当前均匀TEM与分布电阻支路检查不替代这一步。
3. 前两项通过后，重提取铜腔多端口响应，再联接真实收发、判决和校准器件模型。

目前不冻结BOM、不采购整机、不报告硬件计算速度。
