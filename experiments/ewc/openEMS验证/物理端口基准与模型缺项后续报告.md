# 物理端口基准与模型缺项后续报告

日期：2026-11-17

## 1. 本批结论

已恢复官方openEMS v0.37.0的原生XML命令行求解，完成带单位的空气TEM传输基准。
主矩阵包含9次直接FDTD运行，另有3次加倍时间窗口复核、3次0.25 mm细网格复核，
以及2次0.125 mm附加细网格运行，共17次完成并复核的正式运行。
0.125 mm、25 Ω扩展运行已停止，不计入完成数或通过结论。
最细主网格下，三种分流负载的反射、透射和频域功率闭合误差均小于1%。

**这只是基础传输验证部分通过，不是完整物理端口、铜腔体或真实芯片联合仿真通过。**
负载环路电流的纯电阻对应检查仍失败；尚不能把这个接口直接联接实际比较器反馈链。
本批没有新增厂商器件模型或冻结采购BOM。

## 2. 求解环境修正

原生程序位于外部缓存`%TEMP%/ewc-openems/solver/openEMS/openEMS.exe`。
用独立子进程执行`--help`返回0，输出v0.37.0与相关库版本，并成功运行FDTD。
此前首批记录的工具启动失败保留为历史事实，但该返回码不能直接当成程序自身返回码；
本批没有确定此前失败的唯一根因。

缓存中Python 3.13专用绑定存在，但加载CSXCAD的ParameterObjects扩展时，
Windows返回“应用程序控制策略已阻止此文件”。
本批没有关闭安全策略、解除安全限制或替换受限二进制。
采用原生XML接口配置官方求解器，不自行实现电磁场求解。

## 3. 基准结构与量纲

| 项目 | 配置 |
|---|---|
| 结构 | 240 mm长、10 mm高的空气平行板TEM线 |
| 板宽 | 约75.346 mm，由Z0=eta0·h/w=50 Ω确定 |
| 边界 | x两端MUR吸收；y两侧PMC对称；z两板PEC |
| 激励 | x=20 mm平面，z方向软电场高斯脉冲 |
| 激励频率 | f0=3 GHz，fc=1.5 GHz；fc是20 dB截止定义，不是任意带宽名称 |
| 检查频段 | 2.5～3.5 GHz，共101个频点 |
| 测量面 | x=60 mm和180 mm |
| 集总分流负载 | x=150 mm附近，R=25、50、100 Ω |
| 主矩阵 | dx=2、1、0.5 mm；横向y为80单元，z为4单元 |
| 时间 | 主矩阵8 ns；复核16 ns |

50 Ω是传输线参考阻抗；负载是跨两板的**分流电阻**。
50 Ω分流电阻并不是线路终端的50 Ω匹配负载，因为其后仍有一段传输线。
该几何也不是实际SMA接头、馈电探针、有限宽无侧壁板线或计算腔体。

V使用原生电压积分探针，单位V。
I由两相邻原生Hy探针在电压参考面上取平均后乘板宽，单位A；
此积分只在已限定的横向均匀TEM模式下成立，不能套用到一般三维腔体。
电、磁探针分别使用自身时间戳作傅里叶积分，不把Yee时间交错忽略。

脚本按峰值相量口径构造a=(V+50I)/2、b=(V-50I)/2。
脉冲傅里叶积分的量纲为V·s、A·s，因此本报告中的功率为归一化频域比例，
不是器件直流耗电、连续波实际瓦数或整机每次操作能耗。

## 4. 解析对照与主矩阵结果

分流电阻与后续50 Ω线路并联，等效阻抗为R并联50 Ω。
分流位置的反射系数为Gamma=-50/(2R+50)，透射系数为1+Gamma。
反射还包含从测量面到分流位置的往返传播相位；
透射包含两个测量面之间的传播相位。

源与材料配置不读取这些解析答案，答案只用于仿真结束后的核对。

最细主网格dx=0.5 mm、y=80单元，整个检查频段的最大值：

| 分流电阻 | 反射复数绝对误差 | 透射复数绝对误差 | 归一化功率闭合误差 | U/I与纯R的相对差异 |
|---|---:|---:|---:|---:|
| 25 Ω | 0.00894 | 0.00857 | 0.00895 | 10.43% |
| 50 Ω | 0.00486 | 0.00453 | 0.00721 | 18.87% |
| 100 Ω | 0.00269 | 0.00243 | 0.00498 | 35.12% |

前三列以单位入射量归一化，0.01为本基准门槛。
它们**不是**相对于反射或透射自身幅度的1%误差，也不是计算有效系数的±1%预算。
尤其在反射较小或抵消接近零时，不能用绝对归一化通过替代逻辑误差验收。

功率闭合核对：
1-|反射|²-|透射|²-负载吸收比例。
负载吸收比例使用独立的负载电压与原生电流环路测量；
另外的V/I行波功率恒等式只是代数自检，不当成独立守恒证据。

dx=2 mm时，25 Ω样例反射误差约0.0355；
到dx=1 mm为0.0170，到0.5 mm为0.00894，表明轴向细化有实际改善。
横向网格固定时不能据此声称全部三维几何已收敛。

进一步把y细化至160单元、dx细化至0.25 mm，三种负载的最大反射误差降至0.00440、
最大透射误差降至0.00432、最大归一化功率闭合误差降至0.00381。
纯电阻U/I相对差异仍为5.19%～18.30%，所以完整检查仍失败。
0.125 mm仅完成50、100 Ω两个样例，其纯电阻U/I差异分别仍为4.88%、9.32%；
不能把两个样例的传输通过外推成完整三负载细网格矩阵通过。

## 5. 时间窗口与独立复核

8 ns与16 ns比较，三种负载中最大的反射复数变化约4.80e-6，
最大的透射复数变化约1.64e-6。
这只支持该开放TEM基准的频域观测窗口稳定，不说明高Q腔体在8 ns内复位。

独立复核脚本不调用运行脚本的分析函数：

- 重新读取原始探针，检查归档SHA-256。
- 使用矩形求和DFT加显式半权端点修正，交叉检查运行脚本的梯形积分DFT。
- 从并联阻抗重新推导反射与透射解析参考。
- 检查探针采样间隔、有限数值和保存的复数响应。

首次不含端点修正的复核中，主矩阵和时间复核12次运行的DFT差异小于6.75e-8，
但0.125 mm、100 Ω样例为1.026e-6，超过既定1e-6复核阈值。
显式计入有限窗口首末采样的半权项后，全部17次运行的最大复数差异小于8.63e-12。
阈值没有放宽；修正的是后处理端点处理，不是电磁响应或负载未通过结果。
17次正式运行的原始数据哈希、频域响应及解析参考复核通过。
这是独立后处理复核，不是第二个独立电磁场求解器或实物测量。

## 6. 未通过项与物理含义

负载的原生电流环路按安培环路积分取得电流，有限包围面积会包括位移电流；
分布式集总元件、探针离散和端点处理也可能贡献偏差。
因此环路I与“纯电阻支路电流”不是可以无条件互换的量。

本批观察到U/I具有明显虚部，且网格细化后差异减小。
这支持进一步检查探针包围范围、支路电流及寄生效应，
但**没有**证明全部偏差只由位移电流造成。
不能把实测U/I直接重命名成厂家50 Ω电阻，或按解析答案回调R来宣布通过。

完整端口检查保留为未通过。下一步需要：

1. 取得支路导电电流与包围面的位移电流分别对应的独立证据，明确参考面和寄生模型。
2. 用匹配终端、改变终端阻抗和不同激励方向复核一般电压/电流端口，不只验证TEM场积分。
3. 单独做有限导体表面基准，才将铜壁加入腔体。

## 8. 文件与复现

运行脚本：`openEMS验证/run_native_port_benchmark.py`。
复核脚本：`openEMS验证/verify_native_port_benchmark.py`。
结果：`openEMS验证/物理端口基准结果/`，含各批summary.json、cases.csv及NPZ探针/频响数据。
`细网格复核`只包含0.25 mm三种负载；`附加细网格`只包含0.125 mm的50、100 Ω。
中断的0.125 mm、25 Ω原始中间文件留在外部缓存，不作为完整结果交付。
原生XML、完整日志和原始探针在外部临时缓存，summary.json记录绝对路径与SHA-256；
缓存清理后需重新运行，不能仅凭哈希恢复原始文件。

在项目根目录复现主矩阵：

```powershell
python "openEMS验证/run_native_port_benchmark.py" --output "openEMS验证/物理端口基准结果/主矩阵" --transverse-cells 80
python "openEMS验证/verify_native_port_benchmark.py" "openEMS验证/物理端口基准结果"
```

运行程序正常结束意味着结果已保存；是否达到门槛以summary.json中的通过标志为准。
`finest_transmission_and_power_1percent_pass=true`只表示绝对归一化传输子检查通过；
`finest_analytic_1percent_pass=false`明确保留纯电阻对应等完整检查未通过。

官方配置参考为发布包内AddProbe.m、AddLumpedElement.m、SetBoundaryCond.m和Parallel_Plate_Waveguide.py。
电流与模态规则另核对了上游ProcessCurrent、ProcessFieldProbe、ProcessModeMatch实现；
上游源码用于理解接口，未修改求解器，不因阅读master源码而声称其与缓存二进制逐字一致。
