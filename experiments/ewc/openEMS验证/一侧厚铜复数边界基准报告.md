# EWC一侧厚铜复数边界基准报告

## 1. 本批结论

本批完成18组独立一维频域线性有限元（FEM）配置、3次ngspice AC计算、
54次独立稀疏解交叉核对及8项单元测试。不是新增18次openEMS FDTD。

在2.5～3.5 GHz、均匀光滑非磁性铜的限定模型内：

- 35 μm截断深度、256单元、58.58 MS/m时，一侧半空间复数阻抗最大相对误差0.12608%，最大相位误差0.07224°。
- 64项正参数Foster模型复数误差0.005481%，最大相位误差0.000992°；ngspice与其响应一致。
- 2 μm截断域虽能准确求解自身边界问题，但与半空间约差10%，不能无条件当厚壁。
- 35 μm/64单元、16项Foster及50 ps双线性频率检查未通过1%；保留失败项。

这证明已有适合下一步耦合研究的局部复数阻抗候选，
不证明铜腔三维场、实际接头、时域闭环或完整计算机通过。

## 2. 材料和边界定义

采用此前已归档的C11000铜20°C典型电导率58.58 MS/m；
另用58 MS/m作数值对照。两点检查不是材料容差、温漂或批次保证。
本批未取得新供货保证、报价或真实器件宏模型。

采用exp(jωt)约定，μ=μ0、ε=ε0。一侧半空间目标为：

```text
s = jω
γ = sqrt(s μ0 (σ+s ε0))
Z∞ = sqrt(s μ0 / (σ+s ε0))
```

选取具有正实部的平方根分支。铜在该频段的位移电流很小，但公式保留它。
表面阻抗单位为Ω；按平面局部模型也可称每方块阻抗。
3 GHz典型趋肤深度约1.201 μm。

有限计算域定义：

```text
E'' = s μ0 (σ+s ε0) E
-E'(0) = s μ0 H0，H0=1 A/m
E(d) = 0
Zd = Z∞ tanh(γd)
```

背面E(d)=0是数值截断边界，不是自由背面铜薄板。
35 μm足够深，但仍须解析趋肤层，不能凭厚度大就使用粗网格。
此前两侧ConductingSheet厚极限为Z∞/2，不能与本批一侧Z∞混用。

## 3. 有限元矩阵和收敛

每组计算101个均匀频点，共18组配置：
2种电导率 × 3种深度（2、8、35 μm） × 3种单元数（64、128、256）。
采用线性单元、一致质量矩阵和带状线性求解器。
解析阻抗不参与矩阵组装或边界激励，仅在求解后比较。

以下为58.58 MS/m结果；误差为频带内最大相对复数误差：

| 深度 | 单元 | 相对有限域解析误差 | 相对半空间误差 | 半空间1%检查 |
|---|---:|---:|---:|---|
| 2 μm | 256 | 0.000522% | 10.0294% | 未通过 |
| 8 μm | 64 | 0.10539% | 0.10528% | 通过 |
| 8 μm | 256 | 0.006587% | 0.006479% | 通过 |
| 35 μm | 64 | 2.01618% | 2.01618% | 未通过 |
| 35 μm | 128 | 0.50431% | 0.50431% | 通过 |
| 35 μm | 256 | 0.12608% | 0.12608% | 通过 |

35 μm误差在单元数倍增时约下降4倍，符合线性FEM的二阶收敛。
256单元的深度网格为136.719 nm。58 MS/m对照结果同样保留在CSV/JSON中。
18例中16例通过有限域解析1%检查，10例通过半空间1%检查；
两种检查的分母和物理目标不同，不能混合统计。

功率采用H0=1 A/m的归一化表面激励：

```text
Pin/A = 0.5 Re(E(0) H0*)
Ploss/A = 0.5 σ integral |E|² dx
```

单位W/m²，不是EWC实际操作耗电。离散功率闭合只说明同模型能量一致。

## 4. 保留幅相的无源等效模型

以良导体近似Z(s)=sqrt(μ0/σ) sqrt(s)为目标，
对其正权重积分表示进行对数求积，构造串联的并联RL支路：

```text
Z(s) = sum Rk s/(s+pk)
Lk = Rk/pk
Rk > 0，Lk > 0，pk > 0
```

正R/L结构给出局部连续时间正实、无源网络。
它是边界核的数学等效网络，不是实际采购电阻、电感BOM。
比较仍采用包含ε0的一侧半空间公式；不把近似目标偷偷换成仅实部。

| 项数 | 主频带复数误差 | 幅度误差 | 相位误差 | 0.5～6 GHz复数误差 |
|---:|---:|---:|---:|---:|
| 16 | 4.64199% | 2.91883% | 2.65331° | 4.73949% |
| 32 | 0.081614% | 0.078385% | 0.045924° | 0.090239% |
| 64 | 0.005481% | 0.005200% | 0.000992° | 0.006704% |

16项模型未通过，不因所有参数为正就声称它精度足够。
扩展频带401点仅检查数学频响，不保证实际器件在该带宽工作。
Foster参数本批仅针对58.58 MS/m；改变电导率须重新生成、验证。

ngspice-47使用1 A AC测试源，串联各并联RL支路，直接读端口复数电压。
16、32、64项与独立公式最大相对差异分别约
2.87e-12、1.66e-11、9.60e-13。
这是同一等效网络的求解一致性，不是物理误差小到该数量级。

## 5. 离散时间和三维接入限制

本批只检查双线性映射s=2j tan(ωΔt/2)/Δt后的频响。
64项模型与半空间的最大复数差异：

| Δt | 误差 |
|---:|---:|
| 1 ps | 0.004013% |
| 5 ps | 0.045254% |
| 20 ps | 0.813319% |
| 50 ps | 5.570551%（未通过） |

此表不是已实现的时域状态递推，也不是三维CFL、耦合稳定性或瞬态闭环验收。
20 ps局部频响通过1%也不代表能直接使用该步长：还需给空间离散、端口和器件误差留预算。
有限项模型在极高频趋于有限阻抗，而真实sqrt(s)继续增长；
不能将本频带通过解释成任意阶跃、宽带瞬态均通过。

缓存openEMS v0.37.0的SetBoundaryCond.m列出PEC、PMC、MUR、PML。
现有缓存头文件检索尚未确认可直接输入一侧复数表面阻抗的接口。
该检查不足以断言openEMS整个项目绝对不支持；本批也没有实现新扩展。
不把Foster文件直接交给ConductingSheet来冒充已接入。

后续实现门槛按顺序为：

1. 确定支持因果表面阻抗的求解路径。若开发openEMS扩展，明确切向场、
   外法向、E/H交错、网格面积及边界状态存储；独立FEM不能自动替代现有三维求解器。
2. 实现每个切向方向的无源状态更新，先在平面反射/传输线中验证复数阻抗、
   吸收功率、源关闭后的能量衰减及网格/时间步收敛。
3. 对比解析平面反射及显式有限导体参考；检查频带外激励、截断边缘和角点。
4. 再接入铜腔，检验曲率相对趋肤深度的适用性、接缝、粗糙度与馈电端口。
   一般连接器与多端口还必须单独验证；局部边界通过不能跳过它们。

本批不以修改安全策略获取Python绑定，不将正参数网络当成三维耦合稳定性证明。

## 6. 独立复核和复现

新增代码：

- `run_thick_copper_boundary.py`：FEM矩阵、Foster参数及ngspice运行。
- `verify_thick_copper_boundary.py`：不导入运行脚本，逐单元稀疏组装，
  在每例2.5、3、3.5 GHz重新求解；独立高斯积分核对功率；
  重读R/L、netlist、原始AC输出、扩展频带和双线性频响，核对SHA-256。
- `test_thick_copper_boundary.py`：8项离线测试，覆盖收敛、深度极限、
  分支、耗散、正参数、失败阶数、时间步失效和非法输入。

54次独立解的场相对差异最大2.602e-13；
方程相对残差最大2.686e-13；
独立积分功率闭合最大4.663e-15。
这些是数值实现一致性，不是独立实验或铜材料真实精度证明。

正式结果在`openEMS验证/厚铜边界基准结果/`：
18个FEM NPZ、3个模型NPZ、CSV、模型参数、summary.json及verification.json。
原始ngspice netlist、日志、dat位于
`%TEMP%/ewc-openems/thick-boundary/foster_{16,32,64}/`，
summary记录完整路径与哈希；缓存删除后需要重跑。

```powershell
python -B "openEMS验证/run_thick_copper_boundary.py" --output "openEMS验证/厚铜边界基准结果"
python -B "openEMS验证/verify_thick_copper_boundary.py" "openEMS验证/厚铜边界基准结果"
python -B "openEMS验证/test_thick_copper_boundary.py"
```
