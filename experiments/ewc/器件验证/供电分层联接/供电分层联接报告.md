# 供电分层联接验证报告

## 结论

九次求解均生成达到终止时间的完整波形：一个理想轨缓冲对照通过末窗口接口筛选，八个真实稳压配置失败。七个整机验收包仍未整体关闭。

独立复核已重现所有输出误差与原失败标签，九组代数KCL闭合。四组全部外部电容记账通过，五组至少一个电容全时间积分超过原1%门槛，不能以末窗口KCL通过替代全时间记账。真实缓冲两组的供电轨为负，超出匹配手册的推荐工况，不用于推断真实芯片幅度性能或器件故障。

## 电路与范围

- 原厂TPS7A20、REF5050、OPAx320-Q1库字节不改，ngspice 47及库、前批证据SHA已核对。
- 理想6 V上游、0.05 Ω源阻抗、1 μF输入电容；双轨目标5/3.3 V、各1 μF输出电容及0.05 Ω ESR、电阻负载1000/330 Ω。
- 参考由6 V上游独立供电，输出1 μF并1 Ω ESR；三缓冲使用100 kΩ分压、1 nF输入去耦、100 pF输出电容。
- 缓冲负载为电阻与理想合成源构成的回灌夹具，不是THS4551/TLV3501完整实际输入链，也不是RF链。
- 默认2 ms、最大100 ns时间步；启停组8 ms。接口窗口为终止前300～100 μs，属于毫秒级末窗口筛选，不替代原纳秒级调理门槛。
- 默认工作点已建立；爬升及使能使用理想源/行为关系，不是实物安全门控或复位。

## 独立记账

从封存网表读取电阻、电容值；CSV核对列、行数、有限值、严格递增时间和末时间，不调用运行器测量函数。

```text
Ireg5out = Iload5 + (Vr5 − Vc5)/ESR5
Ireg3out = Iload3 + ΣIbuffer_supply + (Vr3 − Vc3)/ESR3
−Iup = Ireg5in + Ireg3in + Irefin + Cin dVin/dt
Irefout = Idivider_or_reference_load + (Vref − Vcref)/ESRref
Idivider_top − Idivider_bottom − Ibin = Cbin dVb/dt
Ibout − Ifb − Iexternal_load = Cbout dVo/dt
```

反馈和正输入动态电流均纳入。外部电容按全时间梯形积分核对电荷，归一化为`C × 最大绝对节点电压`，不是相对微小纹波的误差；窗口残差门槛1 μA，积分门槛1%保持。

全部电容记账通过：`dual_steady`、`dual_load_step`、`dual_reference`、`buffer_ideal_control`。

| 未通过配置 | 未通过电容 | 最大积分相对误差 |
|---|---|---:|
| dual_enable_cycle | c5/c3 | 5.0274% |
| dual_ramp | c5/c3 | 2.0644% |
| dual_reference_ramp | c5/c3 | 2.2893% |
| buffer_real_rails | bout2/bout3 | 1.1237% |
| buffer_real_ramp | bout1/bout2/bout3 | 3.6753% |

这些积分失败是当前导出波形的数值记账失败；尚未完成细时间步复核，不单凭失败判断芯片故障、物理电荷不守恒或根因。

每个外部电容的初始、最终储能及变化，理想上游和理想轨各自供能积分已记录于JSON。理想信号源/使能源未测量，TPS模型未含静态地电流和温度；没有把上游与下游重复相加，没有形成完整系统能耗。

## 模型有效性

匹配[OPAx320-Q1手册](https://www.ti.com/lit/gpn/opa320-q1)，SLOS884B，第4～5页：推荐供电1.8～5.5 V，输入共模约`V−−0.1`至`V++0.1 V`。绝对最大边界不是功能保证。

独立核对缓冲供电与两输入引脚全时间及末窗口范围；该检查不涵盖所有器件额定值。理想轨对照通过本项，两个真实轨缓冲配置末窗口均不在推荐及所检查的绝对范围。爬升从零开始的样本不能当作正常线性工作样本。
