只作候选验证，不冻结BOM、不将Q1资格当作本项目实物全温验收。

原THS4551、TLV3501、REF5050、TPS7A20及ngspice47哈希保持不变。

额外±0.1%分压比扰动为敏感度假设，不是已取得真实电阻批次数据。
慢启动目标5 ms，源从上电前即有效；无有效隔离/复位模型，不称安全启动通过。

## 2. 28次试验

7独立配置分别执行顶层包含、作用域隔离、Gear-2及Gear-2+名义nodeset，
共28求解器调用。10份完整波形，4通过/6失败/18不完整。
通过的4份全是理想参考供电对照重复，不能算4个真实子项通过。

| 配置 | 实际结果 |
|---|---|
| 理想参考/供电对照 | 四轮均通过；原1 mV、5 mV、30 ns门槛保持 |
| REF5050+直接分压 | 四轮均失败，最大幅度误差约125.054 mV，共模约111.554 mV |
| REF5050+三Q1缓冲、理想器件轨 | 前两轮在约208.068 ns中断；Gear两轮完整，但幅度误差1.84194 mV超过1 mV |
| 缓冲+真实5 V/3.3 V轨，10 ps | 四轮均无法得到完整初始工作点/波形 |
| 同配置5 ps | 四轮均不完整，不能证明时间步收敛 |
| 真实轨+分压±0.1% | 四轮均不完整，不能证明容差通过 |
| 真实轨慢启动 | 四轮均不完整，安全启动未通过 |

直接分压的两参考节点在负载下导致名义0.1 V阈值变为
约−0.16530～−0.01163 V，极性都不稳定。
理想参考对照揭示两节点最大需吸收约8.254/7.254 mA，
不能将高阻分压当作零输出阻抗参考。
Gear完整缓冲波形仍有阈值动态范围约0.03868～0.16149 V；
四转换逻辑及延迟通过不抵消幅度失败，共模最大约2.2903 mV。

## 3. 数值边界与独立复核

发现原库私有模型名`DVN/_S1/_S2/ESD_SW/R_NOISELESS`重用，
用包含原字节库的局部子电路隔离；折叠包装后外部网表等价检查通过。
隔离并未改善失败，不能把名称重用宣称为已证实根因。
Gear-2保持默认容差，增加名义nodeset只作迭代初猜，
不用`.ic`或`uic`强制状态。后三轮外部电路和原厂参数均未修改。

标准库CSV独立还原每个有效转换、全窗口误差及连续R/C记账，
实际加载参考替代理想值进入源支路核对。
完整波形窗口RC KCL残差最大约1.53e-10 A；电轨电流账目通过。
四轮日志、摘要与原模型哈希严格核对；两条不完整缓冲原始轨迹留TEMP，
记录最后时间和哈希，不把返回码0或部分波形当作完整仿真。
12项回归通过，含原库保护、包装等价、错行数/测量篡改拒绝及失败保留。
