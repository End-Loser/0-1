# 第六轮：基带判决再生与供电能耗验证

日期：2026-11-17。目标：把第五轮的软件理想阈值判决推进到有限供电、有限负载的晶体管电路，并检查连续切换。

## 1. 结论

本轮找到一个**在所测通用器件模型和工况下能正确判决并恢复标准电平的基带候选电路**：

- 288/288项静态门状态通过。
- 36/36项阈值两侧±25 mV边界点通过。
- 20 ns状态周期、1 pF输出负载的连续测试：32/32次判决通过。
- 20 ns状态周期、20 pF负载：32/32次通过。
- 5 ns状态周期、20 pF负载：只有9/32次通过，不能用于可靠计算。
- 用200、100、50 ps最大时间步交叉检查，名义判决不变，供电积分变化很小。

**这不是整机四则运算通过，也不是实物“准确无误”的证明。**
两个通道仍分别接收预先保存的第五轮第一、第二阶段投影坐标；第二阶段没有使用本轮进位输出形成反馈。
射频接收、波再发射、时钟、寄存器和算术状态控制尚未联合求解。

## 3. 候选电路

每通道9个MOS：

```text
输入源 → 500 Ω / 1 pF输入RC
       → NMOS差分对 + PMOS电流镜负载
       → 两级CMOS反相器
       → 输出负载
```

NMOS尾偏置器件的栅极由120 kΩ/27 kΩ供电分压驱动，替代原来的理想50 μA尾电流源。
3.3 V供电时偏置电压约0.6061 V；尾电流随器件参数及尾节点电压变化，不被硬性固定。
两个通道共享分压器，分压器静态功率约74.08 μW，已计入供电积分。
模型仍使用理想供电电压源，没有电池内阻、供电纹波或PCB供电网络。

| 项目 | 假设 |
|---|---|
| 电源 | 3.3 V；另测3.0 V静态 |
| NMOS | VTO=0.4 V，KP=200 μA/V²，W/L=10 |
| PMOS | VTO=−0.4 V，KP=100 μA/V²，W/L=20 |
| 体效应/沟道调制 | GAMMA=0.4，PHI=0.7，LAMBDA=0.03 |
| mirror、cmp节点电容 | 各0.1 pF |
| 中间反相器节点电容 | 0.2 pF |
| 输出电容 | 名义1 pF，重负载20 pF |
| 输出电阻 | 100 kΩ到地 |
| 内部泄漏电阻 | 1 GΩ到地 |

这是通用Level-1 MOS参数，不是具体工艺PDK或商用比较器模型。没有经过提取的内在电荷和结电容参数；动态主要由外加固定电容决定。
温度场景采用明确的通用参数规律：

```text
|VTO(T)| = 0.4 V + 输入失配 − 1 mV/K × (T − 300 K)
KP(T) = KP(300 K) × (T/300 K)^−1.5
```

SPICE的全局器件温度固定为26.85°C；脚本对各模型显式应用上述规律。
PHI、漏电、结电容等温度依赖没有完整建模，不能当成真实器件全温度特性。

## 4. 波坐标接口与判决规则

第五轮直接FDTD输出的无量纲投影坐标x，转换成假设的保持基带电压：

```text
Vinput = 1.0 V + 0.4 V × x
进位阈值 = 1.6 V，对应x=1.5
和位阈值 = 1.2 V，对应x=0.5
```

基线提高到1.0 V，为NMOS输入差分对预留共模裕量。这个电压转换接口尚未实现真实相干检波。
第五轮最小投影裕量0.4193943换算约167.758 mV，但这不是完整接收机的误差预算。

输出不只是跨过中点就算正确：

- 预期0：输出必须≤0.3Vdd。
- 预期1：输出必须≥0.7Vdd。
- 静态内部节点也必须处于0～Vdd范围内，允许1 μV数值余量。
- 预期进位、和位来自门状态真值，不用输出数据反推目标。

## 5. 静态结果

每个电路工况包含两个FDTD条件×8输入状态×2判决通道，即32项。
FDTD条件是名义介电常数和εr+1%，不是本轮重新进行电磁推进。

| 工况 | 门状态通过 |
|---|---:|
| 名义300 K、3.3 V | 32/32 |
| 全部器件270 K | 32/32 |
| 全部器件330 K | 32/32 |
| 供电降至3.0 V | 32/32 |
| 输入管VTO增加6.5 mV | 32/32 |
| 输入管VTO减少6.5 mV | 32/32 |
| 输入管KP增加10% | 32/32 |
| 电流镜一侧KP增加10% | 32/32 |
| 仅输入管升至330 K，其他300 K | 32/32 |
| **合计** | **288/288** |

9工况×2参考阈值×阈值两侧25 mV，共36个额外边界点，36/36通过。
它们是离散测试点，不是完整阈值扫描，也不代表任意叠加失配、任意温差都能通过。
各扰动分别施加，没有完成同时叠加的最坏情况或蒙特卡洛统计。

288项中低电平最大约6.597×10⁻¹⁰ V；高电平最小约2.99424 V，后者包含3.0 V供电工况。
如此接近电源轨的输出是简化模型的结果，不能当作实物电平精度。
单通道连同分压器的静态供电功率范围约0.1303～0.7678 mW；不是两个通道的瞬态总功率。

## 6. 连续切换与建立时间

状态顺序：

```text
000 → 001 → 011 → 010 → 110 → 111 → 101 → 100
上述序列重复两次
```

每次瞬态仅由初始工作点启动一次，之后状态连续，未在各状态间重新初始化。
输入过渡时间1 ns；输出在每个状态周期90%处采样。
两通道×16个状态周期，共32次采样。
本测试顺序没有覆盖所有可能状态跳转。

建立时间定义：从该状态开始，到输出进入对应30%/70%有效区间且在本周期剩余采样点均保持有效。
它包含输入过渡及输入RC时间，不是厂商定义的纯比较器传播延迟。

| 工况 | 判决 | 最长观测建立时间 | 平均供电功率 | 总供电能量 |
|---|---:|---:|---:|---:|
| 20 ns周期，1 pF，最大步200 ps | 32/32 | 6.12819 ns | 1.85188 mW | 0.592603 nJ |
| 20 ns周期，1 pF，最大步100 ps | 32/32 | 6.12255 ns | 1.85186 mW | 0.592596 nJ |
| 20 ns周期，1 pF，最大步50 ps | 32/32 | 6.12197 ns | 1.85180 mW | 0.592577 nJ |
| 20 ns周期，20 pF，最大步100 ps | 32/32 | 12.04362 ns | 9.42830 mW | 3.01706 nJ |
| 5 ns周期，20 pF，最大步50 ps | **9/32** | 22次周期内未建立 | 19.20483 mW | 1.53639 nJ |
| 20 ns周期，仅输入管330 K，1 pF | 32/32 | 6.38300 ns | 1.88043 mW | 0.601738 nJ |

20 ns测试总时长320 ns；5 ns测试总时长80 ns，所以两者总能量不能直接当作每次运算比较。
5 ns失败项不能因为存在少数成功建立时间就认定可靠。
完整波形见`circuit_continuous_waveforms.png`，绿色采样点通过，红色失败。

## 7. 数值步长核验

ngspice使用自适应时间步；200/100/50 ps是**最大步长**，并非严格固定采样间隔。
波形比较在较粗数据的时间坐标上插值细数据。

| 比较 | 进位波形最大差 | 和位波形最大差 | 供电能量相对差 |
|---|---:|---:|---:|
| 200 ps与100 ps | 2.08717 mV | 1.90388 mV | 0.00113263% |
| 100 ps与50 ps | 1.84997 mV | 1.79834 mV | 0.00321999% |

三档判决均32/32通过，支持本次采样结论对这些步长不敏感。
能量差并不严格单调，不能宣称高阶收敛；这些差异也不是器件建模误差或实物误差界。
`verify_spice_regeneration.py`独立检查数据形状、时间单调性、最大步长、真值、输出阈值、采样插值和能量积分。
核验PASS表示归档一致，包括真实记录的5 ns逻辑失败，不代表所有工况功能通过。

## 8. 能耗与速度应怎样解释

供电源电流采用SPICE符号约定：

```text
P(t) = −Vdd × I(Vdd,t)
E = ∫ P(t) dt
P平均 = E / 仿真时长
```

名义50 ps步结果：

- 两通道320 ns合计0.592577 nJ，即592.577 pJ。
- 平均约1.85180 mW；峰值约25.70493 mW，说明不能只按静态偏置估算动态供电。
- 按16个周期摊分约37.0361 pJ/周期，**只对应两个独立基带判决通道的这组输入序列**。
- 20 pF负载同样摊分约188.566 pJ/周期，输出充放电明显提高能耗。

积分包含两个判决/缓冲通道、偏置分压器和输出负载。
不包含理想输入源、理想参考源、RF发射接收、本振、寄存器、时钟、控制、温控及供电转换损耗。
320 ns序列末尾仍有已充电电容，积分不等于全部不可逆耗散；改变序列、最终状态和启动过程会改变能量。

20 ns周期可以写成50 M个状态周期/秒，但**不是50 M次整数运算/秒**。
两个通道同时由已知坐标驱动，不代表完整两阶段全加器可以20 ns运行。
本轮最长约6.12 ns的名义建立时间也不能直接换成整机频率。

因此第五轮的100 ns/全加器单元、0.2 W活动核心及四则运算时间/能量，仍然只是整机条件预算。
本轮数据改善了一个子模块的证据，不足以把整机预算替换成1.85 mW或37 pJ/算术运算。

## 10. 下一步验收门槛

下一步应先接入**本次实际进位输出驱动第二阶段抵消**的连续因果链，并加入保持/采样时序。
随后检查全部输入状态及转换、复位、不同负载、同时叠加误差和时间步变化，再验证多位进位。
RF相干检波和波再发射需要单独的器件模型与能量边界，不能继续用理想电压接口代替后称整机完成。

当前可以确认“存在值得继续验证的判决再生候选”，不能确认“完整电磁四则计算机已稳定准确运行”。
