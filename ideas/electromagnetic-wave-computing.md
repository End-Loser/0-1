## 核心主张

在一个经过设计的封闭电磁空间中，让多路具有特定编码的电磁波同时进入，并发生传播、叠加、干涉、反射、谐振与耦合。如果在相同输入、相同物理环境和相同初始状态下，接收端能够稳定产生相同输出，且该输出符合预先定义的计算规则，那么可以把这一物理过程定义为一种计算操作。

进一步的主张是：通过改变输入编码（频率、振幅、相位、偏振、时间、空间模式）或结构参数，同一个物理空间可能执行不同任务，例如加权求和、减法、乘法、逻辑判断或矩阵运算，从而形成可编程的电磁模拟计算器或物理计算加速器。

**范围限定**：这是一个关于“受控物理映射能否稳定、可重复、可编程”的研究主张，不是“已经实现通用数字计算机”的结论，也不是“必然优于 CMOS”的性能主张。

## 背景与动机

传统计算机主要依靠晶体管逻辑门，通过电子信号的状态变化逐步完成数字计算。本构想探索另一条路径：不要求预先解析电磁波内部的全部物理过程，而是重点研究输入、物理演化与输出之间是否存在稳定、可重复、可编程的映射。

与相关方向的差异：

- 相比纯模拟计算：强调多维编码与可编程性，而不只是固定传递函数。
- 相比储备池计算：强调封闭电磁腔体作为物理演化介质，并尝试让同一结构承担多种任务。
- 相比微波 / 光子矩阵计算：更强调“黑箱式”筛选与输入—输出判据，而不预设某种具体算子结构。

这些差异是研究取向，不代表已经证明更优。

## 事实、推断与猜测

### 事实（据本项目归档记录）

- 已开展二维 FDTD、三维 openEMS、ngspice 器件 / 校准以及射频端口的数值验证，并保留报告与结果摘要。
- v1 仿真原型 20 例实跑：在设定端口、负载、步数与离线锁相判决下，时域与频域均达到 16/16 比特一致（30000 步版，频域最大解码残差 `6.17e-03`）。
- 三维铜腔的部分数值子项通过 1% 判据；多个边界、端口和器件子项未通过或缺少输入。
- 七项整机验收门槛为 0/7，`goal_complete=false`；未制作硬件样机，未进行实物测量。

### 推断

- 受控电磁结构实现小规模、固定或可调的线性 / 模拟映射，具有明确的仿真与工程路径。
- 要构成通用数字计算机，还缺少存储、可寻址状态、指令控制、级联、扇出、纠错和系统级能效等关键环节；当前构想在这些方面不充分。
- 微波路线可能是首个可测量原型的合理选择；光学 / 集成光子路线更适合后续密度扩展。

### 猜测 / 待验证

- 同一腔体通过输入编码切换多种计算任务，是否能在保持精度的同时实现。
- 物理并行性是否能在同任务、同精度、含输入输出与能耗的对比中优于数字基准。
- 非线性材料、器件或腔体耦合能否提供足够稳定的非线性，而不牺牲可重复性。

## 支持证据与反例

### 支持性证据

- v1 仿真原型在四位码全组合上的比特一致性，说明特定线性映射可以在仿真中稳定解码。
- 二维 FDTD 的加法、相位相减、固定矩阵乘向量等结果，给出了可复现的数值路径。
- 端口、材料、校准方向已建立可核查的输入清单与失败记录，便于后续复现与纠错。

### 反例与限制

- 50 Ω 端接时最好 `|S11| = 0.4409`，端口匹配未达标；柱高扫描未过零。
- 混合历史双窗 Q 差曾达 `1.451% / 1.482%`，高于 1% 判据；四阶任意初态出现 `10.74% / 6.36% / 1.43%` 的偏差。
- DAC 原库调用无波形、ADL 共模案例无合格 DC 点、厂商工具待审批等，说明器件与模型链仍有硬缺口。
- 六组 8 μs 长时算例未完成；现有结果不能外推为长时稳定或硬件可重复。
- v1 的“16/16”不关闭任何整机门槛，不构成硬件、速度或能效证据。

## 验证或证伪方法

建议按以下顺序推进，并把“运行完成”“数值收敛”“物理指标适用”“整机通过”分开判定：

1. **阶段 0 — 任务与边界**：固定输入编码、参考面、负载、采样窗、误差判据和能耗边界；预注册阈值，禁止事后修改。
2. **阶段 1 — 相干、可重复与基线**：验证单源与多源叠加的线性基线、相位噪声、温度漂移和重复性。
3. **阶段 2 — 小规模映射**：两路和差、固定矩阵乘向量、可调加权；与独立数值参考和数字基准对比。
4. **阶段 3 — 非线性与逻辑**：明确非线性来源（材料、器件或混频器），验证单级逻辑与再生能力；记录失败角点。
5. **阶段 4 — 多位与级联**：检查进位、扇出、电平恢复、时序与错误率；训练数据与验收数据分开。
6. **阶段 5 — 系统对比**：在同任务、同精度、含输入输出与能耗的口径下，与数字基准比较；功能通过与性能优劣分开报告。
7. **硬件阶段**：在仿真闭合后制作可测量原型，进行实物重复性、温漂、接头与材料批次验证。

**可证伪条件**（示例）：

- 在预注册判据下，同一输入的输出无法稳定重复；
- 所需非线性必须依赖外部有源器件才能实现，且其成本 / 能耗抵消了物理计算的优势；
- 级联后错误率随位数指数上升，无法通过电平恢复或纠错控制；
- 在同任务同精度对比中，系统级能耗或延迟不优于数字基准。

任一条成立，都应缩小主张范围或修正构想，而不是修改判据。

## 最小可行实现（MVE）

如果读者希望基于本想法实现代码或实验，建议不要从“八位加法器”或整机开始。下面每一项都可以独立成为一个 Issue / PR，按门槛从低到高排列。

### MVE-1：复现二维 FDTD 线性映射（纯软件，最低门槛）

- **目标**：用 `flaport/fdtd 0.3.5` 复现两路输入叠加、相位相减和固定矩阵乘向量的基线。
- **入口**：`experiments/ewc/开源FDTD验证/run_stage2.py` 及同目录报告。
- **判定**：在相同网格、源和边界下，输出与归档报告在预先写明的容差内一致；记录偏差来源。
- **适合**：有 Python / 数值仿真经验的人；不需要硬件。
- **产物**：可重复脚本、对比报告、失败样例。

### MVE-2：复现三维单模铜腔（需要 openEMS）

- **目标**：复现 36×23×14 网格下 011 / 101 / 120 模式的频率与 Q，并复现 011 细网格完整 8 μs 窗口。
- **入口**：`experiments/ewc/openEMS验证/` 下的 `run_finite_copper_cavity*`、`run_*longtime*` 与对应 `verify_*` 脚本。
- **判定**：频率与 Q 在 1% 判据内；若失败，记录网格、边界、材料或窗口原因。
- **适合**：电磁仿真、RF 结构设计；需要足够内存与机时。
- **产物**：收敛曲线、与归档值的差异表、失败条件。

### MVE-3：3 GHz 铜腔 / 波导实物（需要硬件）

- **目标**：加工一个单模腔或波导段，测量 `S11` / `S21`、重复性与温漂；先验证无源线性映射，不急于做逻辑。
- **需要**：矢量网络分析仪、信号源、加工与夹具、接头、参考面校准。
- **已知缺口**：接头内部几何（Amphenol 132139 / 901-9211）、RT/duroid 5880 批次介电与损耗、50 Ω 匹配（现有仿真最好 `|S11| = 0.4409`）。
- **判定**：给出带参考面、校准、误差和失败条件的测量报告；目标值需在实验前预注册。
- **适合**：RF / 微波实验、天线与腔体工程。
- **产物**：加工图纸、装配记录、原始测量数据、误差预算。

### MVE-4：材料与端口表征（可与 MVE-2 / 3 并行）

- **目标**：取得 3 GHz 频段的批次介电常数、损耗角正切、铜箔厚度与粗糙度；测量接头内部结构或取得厂商 CAD。
- **判定**：参数带来源、批次、测量方法与不确定度，可直接传入场模型。
- **适合**：材料、测量、供应链。
- **产物**：参数表、测量报告、与现有模型的差异分析。

### MVE-5：单级非线性 / 逻辑演示（需要明确非线性来源）

- **目标**：选择一个可重复的非线性机制（例如混频器、二极管、非线性介质或有源器件），演示单级 AND / OR / XOR 或一位判决。
- **要求**：明确区分“电磁腔体本身的计算”和“外部有源电路的计算”；报告增益、噪声、带宽与功耗。
- **判定**：在预注册的输入集合上稳定判决；记录失败角点与温度 / 偏置敏感性。
- **适合**：RF 电路、器件、非线性光学。
- **产物**：电路 / 器件模型、测量或仿真报告、误差与功耗预算。

### MVE-6：一位 / 多位集成（依赖前五项）

- **目标**：在 MVE-1～5 的合格输入上，验证进位、级联、扇出、错误率与能耗；与数字基准在同任务、同精度、同输入输出口径下比较。
- **判定**：给出正确率、最差延迟、完整能耗和失败样本；功能通过与性能优劣分开报告。
- **注意**：在这一步之前，不应把任何子项宣传为“整机完成”。
- **适合**：系统集成、数字验证、计量。

## 风险与边界

1. **研究阶段**：本条目是公开工作记录与仿真验证，不是同行评议结论，也不是官方认证。
2. **仿真—实物差距**：材料、加工公差、接头、温度与测量链可能显著改变结果；当前没有硬件证据。
3. **工程成本**：长时三维仿真、器件模型获取、校准与供能链可能成为主要瓶颈，而非物理原理本身。
4. **许可与来源**：第三方论文、数据手册、模型与工具保留各自许可；仓库不复制未授权材料。
5. **误读风险**：子项通过、比特一致或局部误差达标，都不等于整机完成；引用时必须同时引用边界与反例。
6. **安全与滥用**：本构想用于计算与仿真研究，不涉及攻击、诈骗、破坏或绕过授权；其他用途需自行评估合规与安全风险。
