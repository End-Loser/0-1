# 想法条目

这里存放经审核后公开的想法、问题、批评和反例。

提交前请阅读 [投稿与审核指南](../.github/CONTRIBUTING.md)，并在 issue 中说明：

- 核心主张和适用范围
- 背景、动机和来源
- 支持证据与反例
- 可验证或可证伪的方法
- 偏差、风险与已知限制
- 作者、许可和当前状态

每个条目应尽量区分事实、推断、猜测和观点。条目通过审核后发布到此目录；投稿不代表已经被维护者认定为真理。

建议文件名：`topic-short-title.md`。
